# Club three-family craft reproducibility

Owns only this tool directory, the matching craft docs/public pack, and the scoped Club furniture runtime hooks. Frozen sources are from `0118dfc`; `capture-baseline.mjs` executes exact source and captures one actual lounger, the console carcass without functional controls, and one actual speaker.

```sh
node tools/world/djc-furniture-craft/capture-baseline.mjs
```

Only after the coordinator grants the exclusive heavy window:

```sh
/usr/bin/python3 tools/world/djc-furniture-craft/run.py --allow-heavy
```

The wrapper checks live resources, atomically owns `/tmp/bobby-world-phase2-heavy.lock`, limits Blender to three threads and removes only its own lock. The build reads accepted umbrella helpers and local licensed wood photographs without modifying them. Native source preserves named independent parts and separate baseline/presentation collections. Runtime GLB uses three named family roots, material batching and one Y-up conversion. A fresh import is checked and rendered under the same rig including clay for each family, at960×768 and16CPU samples.

Focused runtime tests:

```sh
node --import ./tools/world/alpha-mine-tests/register.mjs --test src/components/world/djc-furniture-visual.test.mjs
```

Same-package QA comparison uses `?qa=1&djcFurniture=legacy`. Normal loading is distance lazy at90m from the Club center slice and bounded at180m; asset loading/error fallback is the exact original separated source. The main release coordinator owns browser validation, final build and promotion. Technical export and offline render review do not imply gameplay/performance or user visual approval.
