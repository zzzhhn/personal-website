## Background

DJC is a browser-native reconstruction of the physical workflow of a modern dual-deck DJ controller. The goal is not to draw a static replica: the jog wheels, mixer, pads, waveforms, effects, recording path, keyboard layer, and library controls are connected to an actual Web Audio engine.

## Controller Experience

- Switchable RX3 and FLX4 layouts with interactive jog wheels, transport, cue/loop controls, performance pads, mixer channels, Beat FX, and live waveform feedback
- Four persisted material skins — Carbon, Silver, Noir, and Midnight — that recolor the plate and legends while preserving control semantics
- Keyboard performance mapping for both decks, continuous fader and trim movement, SHIFT secondary functions, remapping, conflict detection, and an always-available shortcut overlay
- Optional HQ stem separation through Demucs Web, plus independent stem EQ controls for both decks

## Audio and Performance

The audio path is designed around browser constraints rather than assuming native DJ software APIs. Tempo changes use a complementary crossfade window with overlap and smoothed depth changes to reduce modulation artifacts. BPM analysis is moved to a Web Worker, while gesture bounds are cached and canvas/LED rendering is dirty-checked to reduce main-thread work.

Recording selects the first supported container at runtime instead of assuming WebM/Opus, which keeps export functional across Safari and Chromium. Browser-specific APIs such as output latency, vibration, and output-device selection are guarded before use.

## Interaction Fidelity

The backspin model uses smoothed release velocity, stale-input decay, a minimum throw threshold, bounded velocity, and a calibrated exponential slowdown. This produces a natural ramp into reverse motion and a smooth handback to normal playback instead of an instant reverse kick.

Physical keyboard mapping is based on `KeyboardEvent.code`, so shortcuts follow key position across Shift and input methods. Composition events are ignored, full-width punctuation edge cases are covered, and continuous controls remain usable without requiring MIDI hardware.
