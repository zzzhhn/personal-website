## Background

Built as assignment 2 for the Tencent AI-HR bootcamp: an AI companion that helps university students track and reflect on their career growth. The core bet is that a companion is only useful if it *accumulates* — so every conversation feeds a persistent knowledge graph instead of evaporating when the chat ends.

## Growth Knowledge Graph

The signature feature is a four-layer pipeline that turns unstructured conversation into structure:

1. **Extraction** — an LLM pass pulls entities (skills, experiences, goals, people) from each conversation
2. **Merge** — new entities are deduplicated against the existing graph rather than appended blindly
3. **Clustering** — Louvain community detection groups related nodes into themes
4. **Insight** — observations are derived from graph structure (centrality, cluster growth, orphan nodes), deliberately avoiding LLM-fabricated causal claims

Resume upload (PDF / docx) parses into the same graph, so a student's documented history and their chat-discovered interests live in one connected picture, rendered as an interactive force-directed graph.

## Companion Experience

- Persona-driven chat with multi-session management, message edit / regenerate, and session sharing
- 3D mascot 锅宝 rendered via model-viewer, with idle blink and breathing animations
- BYOK (bring-your-own-key) multi-provider LLM support through AI SDK v6
- Full bilingual interface (zh / en) and real authentication with email verification

## Engineering

Next.js 16 App Router + Prisma on Neon PostgreSQL, deployed on Vercel at friend.bobbyzhong.com. 140+ tests across the extraction pipeline, graph merge logic, and auth flows.

## 项目背景

知遇源自腾讯 AI-HR 训练营 Assignment 2，是一位帮助大学生记录并反思生涯成长的 AI 伙伴。项目的核心判断是：真正有价值的 Companion 必须能够持续积累。因此，每次对话都会沉淀至持久化知识图谱，而不是随着 Chat Session 结束而消失。

## 成长知识图谱

标志性能力是一套将非结构化对话转化为结构化认知的四层 Pipeline：

1. **实体抽取**：每轮对话后，由 LLM 提取技能、经历、目标与人物等实体
2. **去重合并**：新实体先与既有图谱比对并合并，而非直接追加造成信息碎片
3. **社区聚类**：使用 Louvain Community Detection 将相关节点组织为主题群落
4. **结构洞察**：基于中心性、Cluster Growth 与 Orphan Node 等图结构信号形成观察，明确避免由 LLM 编造因果关系

PDF／DOCX 简历上传后也会解析进入同一张图谱，使学生的正式履历与对话中逐步发现的兴趣、能力共同构成连贯画像，并以交互式 Force-directed Graph 呈现。

## Companion 体验

- 人格化多会话对话，支持消息编辑、重新生成与 Session 分享
- 3D 吉祥物“锅宝”通过 model-viewer 渲染，并具备待机眨眼与呼吸动画
- 基于 AI SDK v6 提供 BYOK 多模型服务商支持
- 完整中英文界面，并提供邮箱验证等真实认证能力

## 工程实现

前端采用 Next.js 16 App Router，数据层由 Prisma 与 Neon PostgreSQL 提供，部署于 Vercel 的 friend.bobbyzhong.com。实体抽取 Pipeline、图谱合并逻辑与认证流程共覆盖 140+ 自动化测试。
