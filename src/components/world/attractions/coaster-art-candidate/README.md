## 实机问题及本轮回应

已读取 `runtime/coaster-overview-day.png`、`runtime/coaster-overview-night.png`，对照批准的 `coaster-night-v2.png`。实机仍有大块空草、单一白柱主塔、薄设备盒、不可辨的青色轨道灯；因此上一轮几何测试通过不能作为美术通过。

候选包含九组不规则切面岩台，围绕塔基、设备楼、倒置回路及前侧花园组织；近景二十一棵成组切面树、五十四团低灌木，保留任务前场与上车路径。主塔增加错层平台、深色服务核心、铜管束和向塔后侧偏置的宽冠；回旋楼增加层圈、屋顶设备、侧柜和灯槽；后场机房增加设备台基与冷凝机组。新增暖光步道、花池与站台厚檐细节。

轨道灯从每六段中的一小段改为双侧连续折面灯带，保留伸缩缝。使用平面条带而非增加高边数圆管，青色可见表面积从约 137.13 m² 增至 742.92 m²（约 5.42 倍）；局部环顶保留粉色标记。这个面积指标用于解释可见尺寸变化，不能证明最终画面亮度或视觉通过。

夜间补光仍烘入顶点属性。新增局部暖光与轨道青光的静态照射，不增加实时灯；既有两个无阴影实时点灯、全局曝光、雾、bloom、材质 shader 均不修改。静态补光只在生成几何时计算，不增加每帧光源循环。
