# 骤变回路：集成交接

2026-10-27。实现位于 `codex/world-intent-coaster`，基线 `69b14e0`。本交付为可集成源码与轻量逻辑／几何验证，浏览器视觉、实际手感、碰撞试玩与性能仍待主 session 验收。

## 挂载与所有权

```tsx
// 在现有 Canvas + Physics 内，以世界坐标直接挂载，不再叠加 position。
<WorldIntentCoaster active={withinActivationRadius} />
// 在 Canvas 外，现有世界 DOM HUD 同级。
<WorldIntentHud />
```

两者都是默认导出并使用 `React.memo`。HUD 的浅比较 selector 只发布语言、昼夜主题、区域可见性、附近目标和 UI 阻断状态；园外位置变化不触发 HUD 重渲染。主岛、道路、全局挂载、角色胶囊和相机仍归主 session。

`active=false` 保留低细节轨道／塔架、停站列车轮廓，移除装置交互、碰撞及本地音效持有者，逐帧回调在分配对象之前返回。重新激活保留本机进度。卸载释放自建几何和 CanvasTexture；没有下载、远程字体、新依赖、额外相机、复制角色或后台计时器。

共享的 `attraction-ride.ts` 来自主 session，**不属于此提交**。此设施发布 `seat`、`yaw`、`orientation`、`cameraPosition`、`cameraTarget`、`firstPerson`、`fov`，使用 `useFrame(..., -60)`。`orientation` 的本地 +X 前向、+Y 向上，与三个车厢使用同一个轨道 frame。座面为轨道 frame 的 `up * 0.72`，对应车厢座垫顶面。

上车要求已开门、站台接触成立、角色可用且着地、没有车辆／坐姿／内容卡／矿石携带或工具动作。步行可用性与着地状态复用现有 `mineActor` 发布，无需修改角色代码。共享桥的 active 或 revision 被外部改变时立即停止本设施骑乘，不能结束后来取得桥所有权的其它设施。

## 场地与骑乘

- 设施沿用中心 `[50,1,-175]`、70×84 m 场地、南入口 `[50,1.08,-128]`。访客桌位于南侧前场，主线已为前场清草。
- 轨道约 **317.32 m**，闭合，轨面最高约 **30.62 m 世界高度**。一列三节车，参数运动，无第二套车辆物理。
- 节奏：0～5 秒离站；5～31 秒爬升；31～35 秒到高点；35～38 秒静止；38～45 秒骤降；45～68 秒反弯；68～79 秒灯廊；79～94 秒减速回站。
- 默认追尾，可选第一人称与舒适观景。舒适模式收窄 FOV，目标使用水平前向，减少俯仰变化；没有屏幕抖动或逐灯实时光源。
- 退出脚底位置为 **`[45.8,1.08,-150]`**，位于本设施生成的水平站台碰撞面内。主 session 仍负责运行时占用检查。
- 站台地面范围：x 41.5～52.5，z -160.5～-143.5，表面 y=1.08。上车接触点 `[47.2,1.65,-150]`。
- Esc／手柄 Start 暂停，手柄 B 退出由主 session 接入；HUD 始终提供骑乘中的回站按钮。暂停、隐藏、非有限 delta 与超过 0.25 秒的恢复间隔不累计进度。

## 模型、碰撞与预算

- 轨道双钢轨、轨枕、塔架、斜撑、站棚、围墙合为一个 vertex-color 标准材质几何；局部发光线为第二个批次。所有牌面共用一个本机 Canvas atlas，三处装置底座合批，每台把手用实例化。
- 活跃结构 33,864 三角形，远景结构 14,108 三角形，三节车合计 756 三角形。三处小景底座最多约 800 三角形，其余动态小件较少；这是几何计数，**不是实测帧率或渲染调用证据**。
- 由 JSX 结构估计活跃状态约 17～18 个可见 mesh draw，远景 5 个；本设施不新增实时光源、阴影投射或后处理。实际调用、内存及帧率由主线运行时测量。
- 23 组大塔架的立柱与基座使用同一生成函数提供模型和固定碰撞。另有围栏、双扇门、站棚柱、顶部遮挡塔柱、桌台、宝箱和水平站台碰撞。高空轨道与细斜撑没有逐段物理碰撞。
- 生成支架时避开下层其它轨道；采样测试覆盖非相邻轨道大于 4 m 的中心距、角色头部包络、支柱不切车身，以及三种镜头视线不穿站棚。未声称替代逐帧视觉／实际碰撞验收。

## 10 principles re-check

| 原则 | 本实现中的决定 |
| --- | --- |
| 意图对齐 | `intent-tasks.ts` 原请求／澄清／答案保持不变 |
| 认知负荷 | `WorldIntentHud` 只显示当前小景与一个主要操作 |
| 状态可见 | `WorldIntentDevices` 展示七标记、六锁、箱盖、钥匙、双门；`WorldIntentSigns` 显示产物 |
| 可纠错 | 错误不扣既有进度，重试不限次；重开只影响本设施 |
| 可供性 | 可见把手、请求筒与铃都有接触范围和 E 键注册 |
| 设计隐身 | 全流程可沿世界物件走动操作，无强制答题弹窗 |
| 无需手册 | 入口给出六题门槛，装置提示请求及当前可达动作 |
| 尊重时间 | 没有强制排队；装置反馈即时，乘坐可随时结束 |
| 无暗模式 | 七题任选六题、原始存档保护与本机保存边界均明确 |
| 单一主要动作 | 当前站点操作／开箱／钥匙／门／上车逐步呈现 |
