# 转镜头、移动、跨区域性能专项 · 2026-11-14

## Status

已交付第一轮有证据的性能优化，运行时46e6e81，基线facdc92（已含Alpha岛、工厂和五模块）。**跨区域卡顿显著减少，首次加载后马上转镜头仍未完全解决。** 不把局部成果称为整个项目性能通过。

## Result

1. 小地图静态海岸/道路不再随每次玩家位置更新重复拼接字符串。44个真实数组/10447点输出逐字节一致，动态marker/航点/语言仍更新。
2. Club/街灯/工厂保留固定点光源槽，原不生效时强度为0。避免跨边界时全场Standard材质因灯数变化重新组合编译，有效时位置/强度不变。
3. 遮挡淡化材质按mesh复用，淡出后切回原材质，副本90秒闲置/128个闲置上限/换源/换几何/卸载清理。实际绕营地观察17个副本创建、17次复用，0运行错误；射线、透明范围与曲线未变。
4. 对相机附近60米材质分任务使用Three的parallel shader compile。每任务最多一个mesh，不锁住操作或延后ready；不支持扩展则跳过。全场一次性预热导致首次转向9.88秒的失败候选已明确拒绝。

模型、贴图、材质资产、DPR策略、阴影分辨率、海浪/人物/物理源共264个受核文件保持逐字节相同。**没有靠降画质、减少近景模型或关阴影解决。**

## Verification

生产版，1920×1080 CSS、DPR2、High，实际2560×1440绘制缓冲，太阳阴影2508。真实鼠标转圈/W移动；跨区前QA单次到达路线起点，之后真实走入走出工厂。最终计时关闭CPU profiler、GL调用封装及截图；早期截图约1秒的人为停顿已单独标记，不纳入收益。

顺序不是完全随机冷缓存实验：A1/A2来自前一轮BAAB，受限预热B1/B2随后执行；OS/驱动缓存与其它用户应用未重置。不能把单个最坏帧的差值当普遍保证。JS heap结束读数约1082/1154MiB→629/612MiB，但GC时机不同，仅作辅助线索，不当成精确内存节约比例。

- 类型检查771文件0errors/0warnings；production build8页成功。
- 缓存生命周期8项通过；旧实现对同测试7项失败。地图同源序列化对照和严格helper类型通过。
- 工厂取料中暂停/退出/返营与重新挂载实际通过。
- WebKit实际Alpha树、风闸、完整缆车、Esc冻结、退乘W、放灯和夜景通过；该轮首次ready约37秒，所有资源约48秒，启动仍需继续优化，未宣称Safari/M3性能通过。
- 8组同镜头昼夜对比的相机、曝光、缓冲和阴影尺寸相同，主协调看图确认没有明显降质。火焰/水/植被相位不同，不作像素相同声明。
