# 真实加载进度与城岛点亮

## 实施边界

依 PRD §2.1，加载地图复用 `WorldMap` 的同版海岸线、道路与地标，以灰和彩色两层、从 `CAMP_CENTER` 向外的圆形裁切显示进度。保留暖纸色与衬线标题。不新增音效、菜单或互动。

`DefaultLoadingManager` 在 lazy runtime 导入前接入，记录真实 onStart/onProgress/onLoad/onError；模块准备、资源读取、场景首帧分别驱动阶段文案。资源数量可继续发现，因此界面不显示百分比或资源计数，地图/进度条在核心可操作前不显示完成。`SceneLifecycle` 原第三帧 ready 判定保持不变，不等待全岛额外资产。

仅验证一次无 QA 的冷启动普通入口、1920×1080、CDP 100 Mbps、本地 dev 画面和真实按键走动；dev 时长不作为正式 8 s/首包验收。生产同版验收由主线程执行。

## 验证

- 2026-10-24，唯一一次普通入口 `http://127.0.0.1:4344/world/`，1920×1080，独立浏览器上下文、禁用缓存、CDP 下载/上传各 12,500,000 B/s（100 Mbps），未添加 QA 参数。
- 观测到 70 次 UI 状态变化（含地图几何就绪、真实资源回调与首帧阶段）、三个文案阶段；截图捕获视觉目标 0.04 → 0.30 → 0.54 → 首帧阶段 0.94。这些是视觉揭示比例，**不是字节百分比**。总数增加时实测比例会回退，最终补了 `Math.max` 的视觉进度高水位，使已点亮区域不熄灭；该补丁没有引入定时器或等待。遵守一次冷启动要求，补丁后未另跑冷启动。
- 覆盖层退出本地耗时 5,683 ms；只作本地 dev 记录，**不作为生产 100 Mbps 的 8 s 或首包验收**。
- 真实按住 W 1 秒，雷达位置从 `[-41.9942,34.9949]` 到 `[-43.9431,32.4313]`，位移 3.2202 m。测试未传送、未挂 QA、未调用交互/车辆指令。
- 加载两层全部观测使用相同 viewBox；SVG defs 无重复 ID，加载图隐藏玩家，页面无横/纵溢出。地图框 `460×490.73 px`，位于 `[730,229.23]`，1920×1080 内完整显示。
- Astro 检查：247 files，0 errors / 0 warnings / 134 hints。未跑整包、路线、全交互、Blender 或 inventory。
- **Console 全零未通过**：无 JavaScript pageerror；一次现有 `world_enter` 分析请求 `/api/events` 返回 404，并产生一条 Console error。`src/lib/analytics.ts` 的正常入口现有行为，本批未改或屏蔽。需主线程在真实生产服务确认端点。
- 原始脚本、截图、70 次观测、日志：`/Users/bobby/Desktop/3D-personal-world/evidence/street-integration/loading/`。原始 `coreLoading` 字段是测试尾声动态导入另一个 Vite 模块实例的默认 store，不能用作运行状态证据；小报告已剔除此字段并明确限制。第四张采集在截图期间覆盖层刚好退出，故看图用前两张有效加载图。

## 看图判断与边界

已亲看 [营地先亮](loading-step-camp.jpg)、[向城区扩展](loading-step-town.jpg)、[可操作画面](loading-playable.jpg)：地图先呈低饱和轮廓，营地暖色先显露，再向城区方向扩展；标题/提示沿用现有暖纸色、衬线和深海背景，留白完整，没有数值跳动。没有新增场景网格、材质、灯光或 3D draw call。加载期间多两张 SVG 是 DOM 开销，未声称正式首包不增。
