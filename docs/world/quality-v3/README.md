## 补验与证据边界

`tools/world/playtest/gaps.mjs` 只用真实 WASD/Shift/Space/E 驱动。隔离起点用明确记录的 QA fixture，不冒充连续走完全图。`motionProbe()` 是 QA 查询，读取实际蒙皮鞋底、物理地面、视觉轮胎与实体相交，以及镜头遮挡状态，不施加物理力。

首次基线已复现原版坡道鞋底最多 5.03 cm 穿入坡面。Walk+Space 与 Run+Space 物理起落成功，仍不代表 Jump 原生 clip 或美术动作通过。

首次车测中后两车碰到前车遗留位置，修复测试布置；第二次侧碰起点部分车体超出营地平台，导致落坡，继续修正为从营地内部接近实际树干边界。这两份失败原始记录保留，不把无接近/没上车的案例称为碰撞通过。

近处遮挡旧实现仅处理城区建筑，营地树冠和帐篷遗漏。新增只在人物视线附近淡出的通道，不把共享实例的整片树林一起淡出；继续检验实际截图和移动恢复。
