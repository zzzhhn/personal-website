## 2. Bobby 试玩发现的必修 Bug：四季缆车（及通用渡运/雪橇）上下车「倒着走」

- **复现现象**（截图见私有交接仓库 `current/20261115/bug-cable-backward-walk.jpg`）：在 Alpha 山岛「四季缆车」下站木栈道靠近吊厢处按 `E` 登乘，HUD 显示 `四季缆车 · 走向座位` 时，向导面朝右侧旗杆（东），身体却向左侧吊厢（西）倒退平移。
- **已定位的精确代码根因**（`src/components/world/rides/transport-driver.ts`）：
  1. **路径折返问题（第 36～38 行 `capture()`）**：`this.enter` 直接拼接为 `[this.from, ...boarding]`。当玩家站在登乘栈道中前段（比 `boarding[0]` 更靠近车门）按 `E` 时，`this.from -> boarding[0]` 指向远离车门的反方向，导致路径先向后退回 `boarding[0]` 再折返走向 `boarding[1..n]`。应改为从 `this.from` 平滑接入前方最近且满足净空守卫（`movementGuard`）的登乘节点，避免无谓倒退折返。
  2. **朝向锁死首段切向（第 60 行 `approach` 与第 65 行 `walk-out`）**：
     - `approach` 当前写为 `yaw = mixAngle(this.fromYaw, heading(this.enter[0], this.enter[1]), smooth(q * 4))`，全程锁死在首段 `[0] -> [1]` 的方向，没有随 `alongPath(this.enter, k)` 当前所在折线段的实时切向更新；一旦折线转向或首段反向，后半程就会出现「脸朝反方向倒着走」。
     - `walk-out` 第 65 行 `yaw = heading(this.leave[0], this.leave[1])` 同样只取首段切向，多段折线出站时后半段也会斜滑或倒走。
     - 注意核对 `heading(a, b)` 的角度符号与 `WorldActors` / `WorldGuide` 的 `+X` 前向、`atan2(-(b[2]-a[2]), b[0]-a[0])` 约定是否一致（当前第 6 行写的是 `atan2(a[2]-b[2], b[0]-a[0])`，刚好等价于 `atan2(-(b[2]-a[2]), b[0]-a[0])`，符号正确，问题出在只取首段和折返起点）。
- **修复与验证要求**：
  - 统一修复 `cable`、`ferry`、`sled` 三种 `TransportDriver` 在任意合法交互半径起点按 `E` 时的 `approach` 与 `walk-out` 路径接入及逐段切向平滑朝向，确保向导始终面朝实际移动方向自然迈步。
  - 补充单元测试覆盖「站在 `boarding[0]` 前方/侧方按 `E` 不倒退、折线各段 `yaw` 与瞬时位移速度向量夹角 `< 15°`」，并用真实浏览器在缆车、渡船、雪橇实地按键截图复核。
