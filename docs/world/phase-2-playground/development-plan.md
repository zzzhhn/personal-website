# Alpha 因子矿开发计划

2026-10-25 · 对应 [PRD-alpha-factor-mine.md](PRD-alpha-factor-mine.md) · 设计基线 `8310f66`；已对齐主线采用的参考图与三白名单本地重放方向。

## 先完成哪件事

做出一块值得挥镐的开采面，再把它发展成完整设施。原型必须尽早证明“找得到、敲得爽、拿得稳、投得出去”；完整交付还必须证明“看见的结果有真实出处”。模型、动作、声音、空间与证据都属于完成条件。

Bobby 已授权设计后开发。主线审阅本方案后可组织实施；本设计线只拥有 `docs/world/phase-2-playground/`，不修改运行时代码或他人资产。设计基线供追踪，执行线从主线当时指定的整合提交起步，保留已集成的动作、驾驶、美术和资源休眠改进，不回退到 `8310f66` 覆盖后续修复。

## 分批资产清单

以下编号用于交接，不锁定最终文件名、打包方式或建模方法。工具与人体接触资产优先；批次内保留一套共享尺度与材质关系。

| 编号／批次 | 资产与用途 | 交接时必须具备 |
| --- | --- | --- |
| AM01／样板 | 一块主岩面、可开采缝和连续矿纹 | 完整与破损状态能衔接，装饰与可敲面可分，真实碰撞可覆盖 |
| AM02／样板 | 镐子 | 握持点、双手姿态参考、镐头接触点、收纳姿态；实际人物侧视／正视比例 |
| AM03／样板 | 手持探测器 | 握把、探头朝向、指针或强弱读数区；静音可读，不依赖新全屏 UI |
| AM04／样板 | 三种白名单矿石与少量碎片 | 对应 REVERSAL_5、ROC20_RANK、LOW_STD_20；各自可辨，身份与外观分开；手持尺度、落地稳定姿态、材质家族标记 |
| AM05／空间 | 主山体模块、上层裂缝、下层开采面 | 独立设施轮廓；普通相机顶空；背面与侧面可见处完成，不只做正面布景 |
| AM06／空间 | 连接局部 0／3／6 m 的缓坡、回廊、小桥或侧回路 | 可通行宽度、边缘处理与对应碰撞；能双向走，不靠强制跳跃过关 |
| AM07／空间 | 前庭地面、入口、工具架和归还承托面 | 取放位置、可停留空间、道路接点；项目入口与游玩入口不互相阻塞 |
| AM08／池边 | 池体、投石边、两处托盘与来源近读位 | 投放目标、回收位置、时间方向；可站立边与水面位置可核对 |
| AM09／池边 | 结果路径的空间载体 | 能按真实时间和值生成或承载曲线；标尺不依赖贴死的一张收益图 |
| AM10／表现 | 脱矿、碎屑、水花、常亮完成灯与矿线线索 | 有界寿命与数量；不同状态有清楚含义；减弱动效仍保留反馈 |
| AM11／表现 | 探测脉冲、落空／接触、破裂、搬运、落水音 | 音源与许可清楚、接触事件可对齐、音量关系可调；复用主线音频生命周期 |
| AM12／内容 | 双语铭牌、来源信息、项目与经历入口 | 阅读距离与内容来源清楚；不把文字烘焙成无法切换语言的单一贴图 |

人物动作包应含：取／收工具、持探测器步行与转向、挥镐预备到接触再回收、拾矿、抱矿步行与放下、投石预备与释放。可以复用许可明确且适合现有角色的动作，但不能用手握空气、模型直接吸附或角色根节点跳变掩盖缺失衔接。

资产交付同时附单位、局部轴、原点、尺寸和必要挂点；脚下／地面原点、握持点、矿头接触点、石头释放点、托盘承托面均需能在运行时核对。若变更角色骨架或挂点，先由主线协调人物线，避免全套资产各自猜方向。

为碰撞、可动节点、材质与预算归类提供清楚语义。静态岩体、可破损部分、动态矿石、水花和结果载体分清；模型允许必要的简化碰撞与层级细节，不能把视觉空洞整个封成实体。原生工程、导出件、来源许可和导出说明由资产线保管，不把大文件塞进本设计目录。

## 协作接口：规定含义，保留实现选择

### 场地与现有世界

主线决定选址和道路接点。按 PRD 的前庭、三层矿线、回廊和池边相邻关系试放，不要求全部旧展位一起迁移。新设施替换旧 Alpha 演示的职责后，不得仍把旧玩具曲线留作可混淆的“另一个真回测”；保留项目和经历直接入口。

可涉及的触点包括 `layout.ts`、布局派生数据、`WorldRuntime.tsx`、项目导航和相应碰撞。它们是待协调触点，不在本设计线所有权内；不为接一个设施重写岛屿、人物或车辆框架。

### 工具与人物行为

运行时需要能表达：徒手、探测、开采、持矿、投掷与查看结果。它们是行为语义，不要求在全局 store 增加六个布尔变量。工具状态、矿石身份和一次动作的有效接触／释放应有清晰所有者，避免用多个互相矛盾的状态表示同一时刻。

现有 `WorldInteract.ts` 可作为入场取物、就近提示与投放接点的基础，但其水平距离和高度门限不能证明挥镐实际击中。执行线选择合适的接触方法，保证朝向、可达性、实际击打目标和产矿身份一致。

人物线提供动作能否取消、何时接触／释放、握持姿态和必要的身体转向语义；交互线按这些事件提交一次产矿或投放。事件名称和同步方法可自选，不能在每帧重复发任务，不能把外部网络等待锁进动作动画。新的按键或手柄映射由主线整合，复用当前交互焦点规则。

### 因子与结果

| 交接对象 | 至少需要的语义 | 由谁证明 |
| --- | --- | --- |
| 因子登记 | 稳定身份、版本、可读假设、精确表达式、允许参数、需要的数据与方向 | 数据线核对真实代码／结果；设计线协助可读命名 |
| 结果请求 | 因子及完整配置身份、证据模式、避免重复提交的身份 | 运行时与数据执行线按实际能力适配 |
| 真实结果 | 时间轴和值、策略定义、数据来源／区间／截至日、计算时间、版本与警告 | 数据线用可复核样本审计；需要时与独立计算比对 |
| 任务状态 | 待处理、运行、有效结果、拒绝、缺失、失败，以及可恢复动作 | 数据线说明实际服务状态，运行时不猜百分比 |
| 取消和离开 | 取消展示／停止本地观察，与真实服务任务是否取消分开 | 适配器说明取消能力；不靠前端关闭卡片冒充服务取消 |

上述是内容契约，不是已存在的端点、JSON Schema 或 BRAIN 权限承诺。结果包和新算结果都必须匹配完整因子／数据／配置身份。服务端凭据不进入前端、模型或图片提示。不得向公开仓库加入私有研究结果来让样板“看起来真实”。

首版仅接受三白名单，用已有 Python kernel 在本地显式选择面板与共同配置，生成新结果及 manifest。记录引擎提交、数据身份与哈希、实际来源／截至日／区间／资产数、成本与仓位、训练测试日期、生成时间和结果哈希。规格字段声明不等于实际面板覆盖，必须读实际运行输出；不启动完整 Alpha Agent、数据库、LLM 或 BRAIN 来完成三次确定性回测。

数据、衍生结果和结果 manifest 都留在 gitignored 本地；代码和通用规格可同步。先验证忽略规则再写入，并检查公开构建／部署不会因静态目录收集而打包本地结果。不要将原始面板拷入网站 `public/`；适配方式由主线选择，必须限制为本地可用结果，不开放任意文件读取或远程计算。`unavailable` 是显式状态，禁止失败后自动用合成市场曲线替代。公开展示权仍由主线跟进，不阻挡 4341 本地体验。

### 音频、特效和性能

扫描反馈只在玩家实际探测时活动；挥镐、水花等临时效果有界并可回收。设施不重复创建全局帧循环或音频上下文，不为显示待结果增加高频轮询。模型与数据可按需加载，失败可重试；不强制游客先下载整套新设施才能在营地走路。

暂停／隐藏后停下无需运行的扫描、物理演出和音频；恢复不补算积压动作。离开时解除设施拥有的注册、订阅、音源和临时对象，不释放仍共享的 GLTF 资源；服务任务按适配器能力处理，展示重入不会生成新任务。保留 `8310f66` 已集成的暂停渲染与音频持有／释放路径。

资产预算由性能线按实际候选和主线基线落实，旧 `WorldQuality.ts` 的分类与计数是接入线索，不是新设施已经通过的成绩。优先处理重复材质、过多透明层、无界碎屑和不必要全场更新，同时保住敲击、水花、矿纹与空间层次。

## 验证、交付与停止条件

验证围绕 PRD A1～A10。必要的自动检查应覆盖有意义的错误：跨层误击、重复产矿／投放、矿石与结果身份错配、真实与模拟混淆、暂停恢复和所有权清理。不要为模型摆放或每个状态编写只复述实现的测试。

运行验收使用整合版本的普通入口：走完整路线、静音找矿、上下层选矿、投偏取回、比较两份结果、失败后重试、开详情返回、离开再进入。保留运行截图和短证据索引，分别记录技术、视觉、数据与趣味反馈。渲染图和概念图不能替代操作；脚本验证不能冒充首次访客或实物手柄观察。

重任务前执行资源预检，并按协作说明取得自己的临时锁。复用已有服务与依赖，不多开浏览器、Blender、图像服务或常驻监控。测试／构建完成后停止自己持有的临时服务，保留用户页面和他人任务。

每批交接包含提交、确切资产／代码路径、可试玩接点、验证条件、未完成项和下一批接口。主线审阅后集成；各线不擅自推主分支、合并或部署。效果不足就针对对应环节迭代；本地结果不可用时保持清晰缺失状态并修复真实路径，不擅自切成合成首版，不反复尝试私有接口或用随机曲线填补。

当最终资产、动作、空间、真实结果与恢复路径均有证据，且主线完成整轮体验判断后，可结束 pilot 实施。Bobby 的实际反馈可以继续推动调整；它不被技术检查代替，也不构成已授权开发前的新审批步骤。
