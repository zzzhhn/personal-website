# 北岩肩色块与落石收尾候选

基于 `92f06c2`，分支 `codex/coaster-drop-landscape`。依据已批准 `coaster-day-v4.png`，只读对照主线 `world-v22-rock-ground-day.png`、`world-v22-rock-ground-night.png` 及 `world-v22-rock-ground-contact.json`。参考完整性检查通过；实际视觉验收仍由主线完成。

## 改动

- 北岩肩由逐面涂色改为共享顶点材质场。坡度先在相连面之间按面积汇总，矿物、风化色和草土覆盖依空间位置及层理变化，三角面换边不再产生独立色缝。
- 只对北岩肩和这四处岩床使用局部顶点色接线，保留原始平直分面法线、北岩肩底面顶点和碰撞拓扑。没有更改全局材质、照明或其他地形的配色。
- 主体岩床造型、位置和种植岩台保持。小碎岩复用原十个顶点、十六张面，把平行上盖改成偏斜收窄的断裂脊，一端降到近地面；每个底角跟随实际地面下埋，避免整块悬在最高采样点上。
- 保留 ST1／ST2／G19 资产、风动、LOD、实例容量和原落根／净空筛选，不修改轨道、WorldRuntime、相机或 4341。

## 剩余差距

大尺度地形的原有几何及平直分面法线没有重塑，斜光下仍会看见大型三角面的明暗转折。本轮减少的是额外的整面材质跳色，不能凭颜色连续测试宣称拼纸观感已经消失。

岩床与草土仍是低面数模型及顶点色，没有增加贴花、纹理或地被资产。现有低处叶顶点静态抽样最低仍可嵌地约 0.159 m，未通过变更树灌木资产修饰。碎岩的倾斜轮廓与落地关系、植物周围色彩衔接及昼夜观感须用同机位实景复核；此候选没有用户视觉接受声明。提交后停写。
