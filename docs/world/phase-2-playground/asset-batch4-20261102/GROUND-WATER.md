# 地表与海面材质交接

2026-11-02。基线为 `362e68d`，当前分支 `codex/world-craft-batch4`。沿用已获接受的切面海湾风格、Art Lock 调色和既有 PBR 来源。使用 integrate-design 与 blender-material-craft；这两组是可编辑的运行时 shader，未启动 Blender、浏览器、构建、图片服务或其它重型作业。未提交，主执行统一集成。

## 范围与实现

仅修改 `WorldTerrain.tsx` 的 `createGroundMaterial` 与 `WorldWater.ts` 的 `createWorldWaterMaterial`，附一个定向 Node 测试。保留地形与碰撞、草系统、布局、水位、CDLOD、四组 Gerstner 波、surf 几何、风与海时钟、角色扰动及透明清晰区契约。

地表的实际问题是三组反复采样虽然旋转了纹理 UV，却直接混合未旋转的法线通道，导致颜色凹凸与高光方向脱节。新 `tileNormalMix` 把法线 XY 转回共同采样框架，并保留粗糙度 B 通道与原有弱高光设定。仍是每种材质三次颜色加三次法线采样，共 18 次贴图读取。

草扫描的覆盖范围从每格 2.5 m 改成约 1.85 m，让近景叶片的尺寸更收敛。沙每格约 1.56 m、泥每格约 2.08 m 不变。复用扫描颜色相对均值的亮度作为覆盖分布，略微收紧混合边缘，使草丛、泥与沙的表面细节交错；这不是高度图或几何置换。颜色、法线、粗糙度共用同一组归一化覆盖权重，零权重始终为零，远处覆盖退回原权重。无贴图的 `?groundPbr=0` 回退材质完整保持基线。

海面原有三组法线波长约 3.5／2.9／1.8 m，尺度相近。第三组改为约 0.40 m 小波，降低振幅，并在像素覆盖 0.09 m 前完全退场，保留前两组和所有大波几何。没有新增三角函数或噪声采样。浅水和泡沫区降低这一组合的法线强度，角色扰动仍在衰减之后叠加。

岸边泡沫原有最小覆盖 55％，容易读成连续奶白条带；最低覆盖降至 12％，复用现有 breakup 打开间隙。浪尖泡沫的原有 fBm 改在风向／横风坐标上采样，形成较长的破碎片段，而不是相似宽高的斑块。继续沿用共享岸距、swash 与 surf 相位，不追加一套独立岸线运动。泡沫粗糙度向 0.92 混合，使它与半光泽水面分开；未更换海水与泡沫颜色。

## 同包 A/B

主执行网页复验补记：R1 新分支在地形边缘出现黑缝，同包 legacy 没有。根因路径为 derivative helper 外推产生负权重，新增 fractional pow 进入非法域，随后经 sandWeight／groundBump 的导数传播。R2 仅在新分支先对权重非负化并安全归一化，cache key 更新为 `island-terrain-v7-coverage-helper-safe-pbr`；252个实际CPU边界外推样本全部有限。R2石群、内陆地表和真实岸线同机位日夜复验中黑缝消失，原生／GLB／水材质未重制。最终图与性能见 RESULT.md；R1结果不混入最终性能表。

默认展示新材质；在同一候选包 URL 加 `natureCraft=legacy` 并完整刷新，展示 `362e68d` 的旧材质。已有其它参数时用 `&natureCraft=legacy`。开关在创建材质时读取，不是运行中热切换。移除该参数再刷新回到新材质。

legacy 分支不是重新搭建的近似版本。测试用真实 Three `ShaderLib.standard` 调用新旧 `onBeforeCompile`，逐字比对地表与海水的完整 fragment／vertex shader、uniform 名称与 cache key。新分支的 cache key 与 legacy 分开，避免程序缓存混用。

## 成本与已验证证据

- 命令：`node --test tools/world/nature-craft/ground-water.test.mjs`。4 项通过，执行约 0.44 秒。
- legacy 两组完整 shader 与固定旧提交逐字一致；默认无贴图回退也逐字一致。
- 新分支两组 vertex shader 与旧提交逐字一致；海面角色清晰区、接触泡沫与 alpha 代码逐字一致。两个材质函数之后的源文件内容与基线相同。
- 地表仍为 18 次纹理采样；新增主要是已有样本的法线二维变换、覆盖权重的 3 个标量幂运算与归一化，没有新增噪声调用。
- 海面噪声、fBm、纹理、sin、cos 调用数与旧版相同；新增方向点积、浅水／泡沫的法线衰减和泡沫粗糙度插值。
- 新增纹理、网络资源、光源、draw call、几何与 pass 均为 0。共享岸距纹理读取次数不变。没有以此推断 GPU 成本为零。
- `git diff --check` 通过。测试会执行材质构造与 shader 拼接，但没有 WebGL 编译、图像或帧率验收能力。

## 主执行还需验收

在真实 renderer 对同包新／legacy 冻结相机、日夜时间、曝光、天气、质量与画布大小，记录以下结果后再决定是否接受：

1. 草／泥和草／沙接缝的玩家近景，确认细节尺度、边缘交错与颜色连续，没有过硬轮廓；近景地表的法线方向应与扫描细节一致。
2. 沙滩面向海岸，检查泡沫不再形成几乎连续的奶白条带，同时仍与既有湿沙推进／回撤相连。确认新方向不会在弯岸形成机械条纹。
3. 低视角和高视角的海面运动，日／夜各看近处 0.4 m 小波与远处褪去，确认无闪烁、摩尔纹或过强碎高光；泡沫粗糙度不能成为灰色脏斑。
4. 人物下水与移动，保留清晰区、扰动及接触泡沫的实际表现。虽然相关代码未变，仍需集成验收。
5. 同缓冲状态测同长度帧窗，记录资源压力与异步加载状态。尤其确认地表覆盖幂运算与新法线变换的 GPU 增量可接受；本轮没有帧率结论。

资源受限下严格只做上述轻量实现与验证；无网页截图、WebGL 编译、实际视觉通过或用户最终验收声明。若弯岸泡沫的风向片段过整齐，优先只调该一处坐标比例，不改岸距／波浪／布局契约。
