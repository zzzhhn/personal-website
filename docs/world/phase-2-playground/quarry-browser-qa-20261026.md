# 矿区解锁后实机验收

2026-10-26，继续使用已有 Chrome 用户窗口和 4341 页面。源码基线为 `f3a8dd1`，本次实际浏览器发现并修复的问题提交为 `8aeb2ae`。没有新建浏览器、下载历史录像或启动新的协作构建。测试通过正常键盘与页面按钮操作；调试页的可见诊断面板只用于读数，没有通过隐藏状态推进游戏。

## 实测发现和修复

1. 花草实例存在，但 GPU 未绘制。花色分支把 `vec3` 赋给了实例颜色的 `vec4`，真实 WebGL 编译报错。改为只写 `vColor.rgb` 并更新 shader cache key。重新加载后，草、阔叶与白花可见；人物经过的踩踏读数与形态反馈存在。没有新增更新循环、材质批次或实例上限。
2. 西侧坡道桥下的相机扫掠合法，但头盔仍会充满视野。将人物绘制隐藏范围从仅防穿入扩展到近距离遮挡范围，并保留恢复滞后，减少边界闪烁。只控制人物绘制，不改变碰撞体、角色位置或墙体材质。相同桥下位置修复后视线通畅，后退离开桥底后人物恢复显示。

相机回归 6 项通过，含最终矿区碰撞体上的 720 个镜头位置，0 失败、0 跳过。最终生产构建成功，2 页，约 4.97 秒。此前 143 项整合回归、21 项最终资产补测及 322 文件类型检查仍是原版本证据，没有冒称本次全量重跑。

## 普通输入完成的流程

- 从入口拿取工具，跟随探测器到下层矿线，扫描、完成三次有效击打、捡取短期反转矿石。
- 搬运到 A 池位并投矿，实际线上计算返回 752 个历史观测。没有用本地预置结果替代请求。
- 世界图面显示净值曲线和测试段指标。池边按 E 打开聚焦检视；日期滑块支持方向键、Home、End。首个观测为 2023-05-02，两条归一化净值均为 1.000；最后为 2026-04-30，A 为 0.409、SPY 为 1.749。左移一日显示 2026-04-29，A 为 0.407、SPY 为 1.732。
- 测试段为 2025-09-25 至 2026-04-30，界面显示净收益约 −28.0%、最大回撤 −28.5%、IC −0.009、换手率 114.9%。这些是测试段指标，不是完整历史曲线的收益。
- 展开来源，确认 Alpha Agent 线上计算、固定多空分组、训练划分、费用及历史成分股口径可读，并注明不是 WorldQuant 官方计算。
- 聚焦时按 W，角色位置不变。按 Esc 只关闭检视，焦点回到检视按钮，角色位置与结果保持。
- 完成回测后，从地图设置选择回到营地，实际回到营地且工具仍挂载。离开矿区后诊断面板不显示池数据，所以本次没有把“返营后回测缓存仍在”写成浏览器实测；这部分已有状态保留自动回归。

最后关闭临时开发服务，将最终生产构建发布回原 4341 静态预览。普通 URL 不带诊断参数，入口、场景、勘探仪、花草与地图菜单实际加载；本次生产加载未捕获新 error，仍有 Three.Clock 和 Rapier 初始化参数的弃用 warning。页面留在暂停菜单，避免等待用户时持续渲染。点击继续探索即可游玩。
