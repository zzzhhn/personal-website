# 工厂底盘工位性能验收，2026-10-31

**候选修复：只加速静态厂房结构的相机遮挡查询。** 工位没有输入时，相机仍发出四条视线遮挡射线。第一次生产实测中，`factory-structure` 的四次原生 Mesh.raycast 合计每帧中位数 17.7 ms，同样被查四次的屋顶接近计时器下限。加工并不是触发开销的必要条件。

`factory-structure-raycast.ts` 给不可变的 64,694 三角结构建立 CENTER / indirect BVH；`WorldFactory.tsx` 只在该 mesh 上使用加速射线，卸载释放索引。未全局替换 Mesh 原型，不碰物理碰撞、画质、灯光、渲染索引、菜单或模型。将已由 drei 锁定并安装的 `three-mesh-bvh@0.8.3` 声明为直接依赖，npm/pnpm 均不新增包版本。共享工作树中此组件原已有未提交修改，本次精确增量见 [WorldFactory.patch](WorldFactory.patch)。

## 采样口径

- 使用 Astro 正式 production build，而非 Vite DEV。既有 dist 没有该采样入口；[独立配置](bench.config.mjs) 在临时 dist 增加 [fixture](fixture.astro)，渲染原 `src/pages/world.astro`，复用原工位相机、遮挡、物理和生产渲染器。不向正常页面注入探针。构建摘要与产物 SHA 见 [builds.json](builds.json)。
- 同一前台 IAB 标签，浏览器窗口与 canvas CSS 1280×720，绘图缓冲 1920×1080，DPR 1.5、MSAA 4、balanced，晴天固定 12:00，正常 frame 工位、shot=null、相机收敛于 [-236.5,6.2,5]。四分之一像素仅用于诊断。每次冷加载都等待资源、工位激活和机位收敛，窗口另有暖帧。
- 静止指工位与加工输入静止，世界动画照常。加工使用真实 stepFactoryOperation、press 与出料行程，计入 ready→cycle→outfeed→done，不伪造 FPS，不写访客存档。此为隔离操作夹具，未覆盖完整访客制造链路。
- [probe](bench-probe.mjs) 记录实际主场景 render 起点间隔、R3F 全局 before-effect 到 render 的 CPU 墙钟跨度、render 提交墙钟跨度、厂房射线计时与实际绘制。GPU 通过 EXT_disjoint_timer_query_webgl2 每五帧异步抽样一次，剔除 disjoint，查询包住 renderer.render（含阴影）；不是仅片元时间，CPU 和 GPU 时间不可相加。FPS 使用有效起点间隔的总时间；P50/P95 为 nearest rank。原始逐帧数据保留在本目录的 JSON。
- 原 DEV/IAB 的 315 帧、18.73 FPS、362 draw、931,783 三角为历史线索。本次使用当前整合候选的生产夹具，首轮 365 draw、1,153,075 三角，不能把两个数字之差归因为去掉 HMR。

## 代价、视觉、暂停与复现

- 测试产物的 lazy WorldFactory chunk 从 80,837 到 122,766 字节；同一 gzip 算法压缩后 31,238 到 44,694 字节，增量 13,456 字节。是首次载入的体积代价，不是逐帧开销或实测网络传输量。
- 同一真实几何在浏览器采样结束后另建一次相同索引，耗时 **34.4 ms**；树节点与间接面表 **743,564 字节（726 KiB）**，不含 JS 包装、临时构建峰值，也不重复计入原渲染索引。[原始结果](pair-cross-index-cost.json)。Node 独立构建 30.44 ms；这是一次性成本，非逐帧。
- [定向测试](structure-raycast.test.mjs) 在真实厂房的工位近线、横穿结构、有限 near/far 和反向 miss 上，以单／双面材质比较原生与索引：126 组、110 组有命中、16 组无命中；每一个命中面 ID、距离和世界交点一致，原始索引逐元素一致。[日志](targeted.log)。
- 同一暖页先后回看[原生画面](pair-cross-visual-stock.jpg)与[索引画面](pair-cross-visual-index.jpg)：机架立柱、压头、角色与传送带的遮挡关系及窗边光照保持一致。世界动画未冻结，不承诺逐像素相等；同尺寸 JPEG 的全画面 RGB 各通道平均绝对差 0.034–0.038 / 255，任一通道差超过 12 的像素占 0.062%。[差异统计](visual-comparison.json)。不作为用户审美验收。
- 暂停后等 1.5 秒再观察 1.5 秒：同页交叉轮、诊断轮和 A1/A2 均 0 次主渲染；跨加载 B 单轮为 1 次有限绘制。所有轮恢复后均完成 12 个实际新渲染帧；测试标签最终已暂停并关闭。[交叉轮原始结果](pair-cross-pause-resume.json)。
- [正常生产构建和严格类型检查](normal-build.json) 均 exit 0；普通产物含原 /world/ 和首页，不含测试路由。没有安装依赖、改正常入口或替换 integration 已有 dist。未提交、推送或改 4341。
