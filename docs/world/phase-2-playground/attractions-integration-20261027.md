# 北岸双设施集成记录

## 范围与分工

用户于 2026-10-27 批准正式落地国投证券清点园区与字节跳动意图过山车，并扩建主岛。以 `ibd-intent-coaster-20261027.md` 的玩法为依据，调整原先独立设施岛的部署方式：两座园区位于与旧主岛连通的北岸海岬。

- Astra「Phase 2 · Play 优先的地图与小游戏方案」：三棚清点场、实体工具和物料操作、装卸、差异核查及重玩。
- Astra「Phase 2 · 字节意图过山车」：三个意图装置、七题六锁、宝箱钥匙与园门、轨道列车与乘坐。
- 统合 session：地形、道路、地图、草木预算、全局角色与镜头、救援、挂载与最终试玩。

设施使用模拟物料与原创任务，不能把模拟结果叙述为真实公司经营、审计或内部产品数据。旧 WorldQuant 矿区、Alpha Agent 交易所和 DJC Club 保持原归属。

## 共享空间与运行契约

`attraction-layout.ts` 是空间基准。清点场中心 `[-88,1,-177]`，55×45m；过山车中心 `[50,1,-175]`，70×84m。地面坐标以足底为准。北岸道路接上旧环路，旧建筑与设施坐标不移动。

新增海岸采用地形高度场的并集，渲染与物理使用同一网格。平坦内部使用 2m 粗网格，海岸保留细分。自动草地排除厂棚、车站、道路；北岸草候选保留率为原候选的 32%，并复用原有风动树的实例化和 LOD。

`attraction-ride.ts` 是逐帧姿态桥。过山车发布座面位置、角色世界朝向与镜头位置。`WorldActors` 暂停角色胶囊，`WorldGuide` 复用已有坐姿接触校准。退出时用实际 Rapier 世界重新检查站台落点，失败返回营地；回营地请求优先取消乘坐。该桥不触发每帧 React 状态更新。

清点场 76m、过山车 88m 范围内激活设施交互；远处保留静态轮廓。完整构建和浏览器验收串行执行，不启动额外浏览器实例。

## 10 项交互原则复核

| 原则 | 本轮具体处理 |
| --- | --- |
| 意图匹配 | WorldIbdYard 的设备就地操作；WorldIntentCoaster 的站点对应实体任务 |
| 认知负担 | HUD 仅显示当前设施、当前操作；清点证据与意图进度分属独立状态 |
| 状态可见 | 吊运、开箱、锁、门、列车通过场景动作反馈进度 |
| 容错 | 清点可复核重玩，意图题可重答；骑乘可退出，仍保留全局回营地 |
| 可供性 | 可操作设备注册到统一 E 键交互表，保持同一提示方式 |
| 以体验为主 | 厂棚、轨道、物件承载玩法，HUD 服务于眼前动作 |
| 易上手 | 南入口和沿路指示牌引导，设施入口保留宽阔步行空间 |
| 尊重时间 | 六个不同任务即可开箱，第七题可选；暂停不累积骑乘时间 |
| 明确规则 | 模拟资料标识，答题门槛可见，错误不扣除已完成的不同题目 |
| 主操作明确 | 当前设备的 E 键操作为主要动作，回营地始终作为恢复入口 |

## 跨组件约定

| 项目 | 约定 |
| --- | --- |
| 中英文 | 名称、提示、HUD 随 world store 的 lang 切换 |
| 字体 | 沿用 world.css，场景中文标牌使用 Songti SC/serif 回退 |
| 布局 | 设施 HUD 独立，挂载于 WorldApp；场景位于现有 Physics 下 |
| 地图 | WorldMap 使用真实地形水线，增加设施占地、入口与道路 |
| 时间与暂停 | 继续使用 isWorldRunning；页面隐藏暂停，恢复不补播 |
| 资源 | 共享原有依赖，不下载历史录像或大型素材，不增加镜面反射后处理 |
