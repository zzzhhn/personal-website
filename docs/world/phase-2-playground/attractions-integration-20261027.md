# 北岸双设施集成记录

## 范围与分工

用户于 2026-10-27 批准正式落地国投证券清点园区与字节跳动意图过山车，并扩建主岛。以 `ibd-intent-coaster-20261027.md` 的玩法为依据，调整原先独立设施岛的部署方式：两座园区位于与旧主岛连通的北岸海岬。

- Astra「Phase 2 · Play 优先的地图与小游戏方案」：三棚清点场、实体工具和物料操作、装卸、差异核查及重玩。
- Astra「Phase 2 · 字节意图过山车」：三个意图装置、七题六锁、宝箱钥匙与园门、轨道列车与乘坐。
- 统合 session：地形、道路、地图、草木预算、全局角色与镜头、救援、挂载与最终试玩。

设施使用模拟物料与原创任务，不能把模拟结果叙述为真实公司经营、审计或内部产品数据。旧 WorldQuant 矿区、Alpha Agent 交易所和 DJC Club 保持原归属。

## 共享空间与运行契约

`attraction-layout.ts` 是空间基准。清点场中心 `[-88,1,-177]`，55×45m；过山车中心 `[50,1,-175]`，70×84m。地面坐标以足底为准。北岸道路接上旧环路，旧建筑与设施坐标不移动。

新增海岸采用地形高度场的并集，渲染与物理使用同一网格。平坦内部使用 2m 粗网格，海岸保留细分。自动草地排除厂棚、车站、道路；北岸草候选保留率为原候选的 32%，并复用原有风动树的实例化和 LOD。

`attraction-ride.ts` 是逐帧姿态桥。过山车发布座面位置、角色世界朝向与镜头位置。`WorldActors` 暂停角色胶囊，`WorldGuide` 复用已有坐姿接触校准。退出时用实际 Rapier 世界重新检查站台落点，失败返回营地；回营地请求优先取消乘坐。该桥不触发每帧 React 状态更新。

清点场 76m、过山车 88m 范围内激活设施交互；远处保留静态轮廓。完整构建和浏览器验收串行执行，不启动额外浏览器实例。

## 10 项交互原则复核

| 原则 | 本轮具体处理 |
| --- | --- |
| 意图匹配 | WorldIbdYard 的设备就地操作；WorldIntentCoaster 的站点对应实体任务 |
| 认知负担 | HUD 仅显示当前设施、当前操作；清点证据与意图进度分属独立状态 |
| 状态可见 | 吊运、开箱、锁、门、列车通过场景动作反馈进度 |
| 容错 | 清点可复核重玩，意图题可重答；骑乘可退出，仍保留全局回营地 |
| 可供性 | 可操作设备注册到统一 E 键交互表，保持同一提示方式 |
| 以体验为主 | 厂棚、轨道、物件承载玩法，HUD 服务于眼前动作 |
| 易上手 | 南入口和沿路指示牌引导，设施入口保留宽阔步行空间 |
| 尊重时间 | 六个不同任务即可开箱，第七题可选；暂停不累积骑乘时间 |
| 明确规则 | 模拟资料标识，答题门槛可见，错误不扣除已完成的不同题目 |
| 主操作明确 | 当前设备的 E 键操作为主要动作，回营地始终作为恢复入口 |

- 87 项定向测试通过：设施规则、意图解锁、列车时钟、轨道和灯廊相机、连续坡道／护栏／屋顶碰撞、地图地块、既有安全落点与回营地回归。
- `WorldApp.tsx` 与 `WorldRuntime.tsx` 完整引用闭包的定向 TypeScript 检查通过。Astro production build 通过；仍有既有的大 chunk 与动态／静态混合导入提示。
- 扩建地形实际生成 344,138 个物理三角形，9,459 个细网格块，20,725 个粗网格块。设施占地 2m 采样及道路中心／双边 1m 采样未发现缺失、浸水或异常隆起。
- Chrome 真实键盘清点：领取货单和工具、吊开前卷、分别读标识／转台／检查两面、两箱开箱检查、两托实际装载、核对运单均可执行。最终整轮复验采用高廊路线，升闸动画完成后明确显示「发货完成」。差异批次、退换与过早发货拒绝由状态测试覆盖，未逐批重复浏览器全流程。
- 实际发现原薄盒坡顶会把角色推回坡下。改为连续焊接碰撞壳后，角色从 `[-112.02,5.92,-191.03]` 向东转弯并走到 `[-94.33,5.92,-180.90]`，两处观测完成，再沿原坡道回到地面。已补护栏、入口牌移侧、三棚六块屋顶碰撞和昼夜 HUD。
- Chrome 意图链：错误工具不加分、同题不重复计数，六个不同任务解锁宝箱，开箱／取钥匙／开门／上车按顺序完成。完整 94 秒回路自动回站；Esc 暂停后不会追赶被暂停的时间。
- 实际发现灯廊追尾相机高于顶棚。修复为沿轨道收近后，夜间 78 秒截图在灯廊内部看见角色与前方出口；乘坐控制移至右下角，不遮住列车。夜间中途退出回站后能走动，重新上车后「回到营地」解除骑乘且能继续步行。
- 乘坐中的座面接触误差约 1e-11m；三辆停放车辆在乘坐前后位置不变且各有四个轮胎接地。手柄逻辑已审阅，但本轮没有实体手柄验收。
- 旧营地回归和 Club 泳池西岸可到达。候选页未读到 console error。普通生产入口不包含 QA 控件。

## 性能证据与边界

单一 Chrome DEV 回路观察窗采集 5,145 帧／86.434 个活跃秒；最近 1,800 帧 p50 约 16.7ms、p95 约 17ms，超过 25ms 帧占 0.233%，最大单帧 310.9ms。该窗包含暂停、视角与质量状态变化，`changedDuringWindow=true`，只能作为本机观察，不能用于前后性能对比或稳定 60fps 承诺。结束时可见场景 36 draw calls、104,821 triangles，balanced，无额外后处理。

机器内存压力处于警告且磁盘不足 20GiB，因此浏览器、构建串行，复用一个 Chrome 标签。新设施没有额外纹理下载、反射通道或逐帧 React 姿态发布；远处只保留静态几何。更长时间、多设备、所有视角及差异批次完整试玩仍待后续覆盖。视觉和游玩质量仍需用户验收。
