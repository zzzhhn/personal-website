# 首降代表性岩床断层改形

基于 `dff746c`，分支 `codex/coaster-drop-landscape`。本轮只拥有局部岩床工厂、对应测试和本交接文件。

## 改动

沿用用户已批准的 `coaster-day-v4.png`，对照主线 `world-v21-drop-ground-day.png`、`world-v21-drop-ground-night.png` 和 `world-v21-drop-first-person-day.png` 中的规则台阶问题。

- 保留原四处岩床的候选位置、选址门限和净空采样；西侧已有树木、灌木落根的岩台保留。
- 其余岩壁改为高低交错的斜向断层、偏移岩片和凹入顶缘，打断连续等高台阶。新增边界点用于裂口和斜面轮廓，不作均匀曲面细分。
- 每处最多放三片闭合、低矮的倾斜碎岩，优先落在原岩床较低的一侧；遇到陡坡、无地面或净空不足时省略。
- 可见面与接触面继续来自同一缓存岩床数据。`coasterDropHeight()` 和现有风动植被布局自动采样新表面，未改动 ST1／ST2／G19 资产、实例容量、LOD 或风动路径。
- 未修改 terrain 接线、轨道、相机、灯光、Runtime 或 integration。

## 验证与成本

主线释放 `/tmp/bobby-world-phase2-heavy.lock` 后，先做资源检查，再原子取得锁串行运行；每个短窗口结束即释放。测试时 memory pressure 为 2、磁盘剩余约 10.14 GiB，没有并行重活。

最终源码通过 25 项定向测试：局部岩床 4 项、现有植被 10 项、thrill-landscape 3 项、worker transfer 4 项，以及地形闭合／站点路径／设备岩台／岩肩造型 4 项。未跑耗时的全三角面逐轨道距离测试或完整构建。

- 代表性岩床及碎岩没有退化三角面，每条边恰好有两张方向相反的面；真实地形保持闭合且朝外。
- 实际可见面与 Rapier 接触抽样 50 点，最大差约 0.000223 m。2,400 个全程样本的车体、头部和三种预设视线，以及两档支架基础净空通过。
- 四树六灌木保留，共享风动路径、22／26／36 种类容量和原筛选门限未变；根部与真实岩面接触最大差约 0.00000443 m。3,600 个独立行程样本的动叶包络、公共路径、两档支架避让通过，817 步花园胶囊行走全部贴地。
- 第一轮发现一片碎岩挤入已有树木的根部采样区，导致四树变三树。将碎岩径向外移系数从 1.12 收到 1.04 后，原四树恢复；没有放宽植被筛选规则。

## 未验项

这是一组代表性岩床改形，没有重做周围全部大平面。源码和接触测试不能证明造型已达到参考图质量；昼夜近景、首降视角及原植被落根观感由主线后续独立验收。现有叶顶点静态抽样最低可嵌入地面约 0.159 m，测试不宣称所有低处叶片都与岩面分离，近景仍需检查。本线没有启动浏览器、完整构建、图片服务、Blender 或下载，没有改动 4341。此增量只作为下一候选，提交后停写。
