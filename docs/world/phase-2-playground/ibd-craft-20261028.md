# 国投货场近景细化

基线 `7db9605`。沿用用户已批准的 IBD v1 日夜参考，保留三棚、吊运、两箱拆检和侧向装车的布局。此轮重点是玩家靠近时能辨认的机械构件和动作反馈，不将局部模型改善称为整座设施已还原参考。

## 改动与取舍

旧钢卷端面是互不相连的黑环，损伤由面前的色片表达；工具和十个控制台缺少明确差异，货车轮轴与车头方向也不一致。改成连续卷绕端面、可测量的背面凹陷、朝向货物的手电与可辨卡尺、分用途控制台、完整货车窗框／轮毂／底盘。钢材与涂装、木材的粗糙度分开，仍遵守本世界的克制金属感。

模型细节保留在原货物包络和工作面上，吊运路线、胶囊站位、叉口、滚筒横穿口不挪动。增加轮廓与连接层次，不使用额外纹理、透明玻璃或实时反射。整个货场仍共用原有合并材质和静态 draw；不因每颗螺栓新增对象或碰撞体。

两个 subagents 分别提供 IBD 专属音效实现和近景模型约束审查；性能 session 另行复核音频生命周期。其审查指出独立音频 context、手柄首次播放及无关状态订阅问题，故音效集成必须先收敛到共享有限音源管理，不直接推广初稿。

## 设计原则复查

| 原则 | 本轮决定 |
| --- | --- |
| 意图对齐 | 手电朝货物，量爪／转轮／装车杆与原动作一一对应 |
| 减少认知负担 | 不增加说明卡，保留同一条现场带路路线 |
| 状态可见 | 既有取走工具、开箱、翻面、吊运与盖章状态保留；有效完成追加材质短音 |
| 可恢复 | 原作业取消、退换和本机进度逻辑不变 |
| 可操作性 | 不增加无作用的门、侧栏或新按钮；保留所有可达站位 |
| 设计隐退 | 细节围绕可检查和可移动的实体 |
| 无需手册 | 首单仍按接货、工具、钢卷、拆箱、装车、放行逐步引导 |
| 尊重时间 | 短音只随有效提交播放，不新增循环或等待步骤 |
| 无暗设 | 不增自动播放音乐或改变现有音量 |
| 单一主操作 | 近场 E 与 HUD 共用原 action；不添加并列确认流程 |

| 跨模块约定 | 处理 |
| --- | --- |
| 中英与字体 | 转台提示与手轮模型对应；拥堵提示改为操作台外侧；保留货单、字体和语言开关 |
| 布局与导航 | 不改 HUD 宽度、地图入口、返回营地或设置层 |
| 数据 | 原模拟货物、证明、异常与退换记录保留，不捏造工业鉴定或实习成果 |
| 主题 | 复用世界时间和 IBD 日夜材质；不改全局曝光 |
| 性能 | 不新增纹理、渲染对象、实时灯或独立音频循环，实测预算另记 |
