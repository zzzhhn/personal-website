# 矿区花草与夜间踏面：源级候选

2026-10-26，基于 `3870aef`，分支 `codex/world-quarry-flora-readability`。按 `integrate-design` 阅读了 [实机 QA](quarry-browser-qa-20261026.md) 与 [指定参考图](alpha-pilot/references/quarry-art-direction.png)。本轮是源级和轻量测试交接；没有浏览器、Blender、完整构建或实际 GPU／听感验收，不宣称达到参考图精度或获得用户视觉认可。

## 修改判断

参考图的地被以有共同冠心的宽叶丛、长短交错的草心和成簇小花形成近中远层次。当前候选先解决每株只有几根孤立尖片、单个平花头的问题，再保留原有稳定的距离稀疏策略。直接增加散布数量会增加覆盖与过绘，却不能修正单株轮廓；本轮未选这条路径。15 三角形是这一版候选的预算，不是视觉质量的替代门槛，实机仍需判断是否足够。

- **矿区草丛**：五片变八片，五片较低外叶包围三片高心叶，顶高约 0.20 至 0.42 m；实例已有的朝向和尺寸变化继续生效。
- **阔叶**：七片宽叶沿根到叶尖的折线形成两侧折面，低矮成熟叶包围抬高的内冠，另有一片未展开的心叶。原型范围约 0.58 × 0.60 m，高 0.23 m。
- **花序**：一个平花头改为两个错高的小花头，位于约 0.34 和 0.43 m，各三片宽杯状花瓣；两根茎和一片基生叶仍连在根冠附近。
- **风与踩踏**：继续使用共享风时钟、实时角色推力、原踩踏贴图及恢复逻辑。相连花瓣／茎使用同一相位；草丛各叶使用独立但固定的相位。没有新增更新循环。
- **范围**：`quarryFloraStyle` 的 3 选择矿区草形，0 保留矿区外原草形；1、2 仍为阔叶和花。原 `quarryFloraKind` 对美术工具继续返回 0／1／2，原 `leaf`、`bloom`、`colour` bank 键不变，新增 `tuft` 与打包的 `detail`。候选坐标、布局、资产生成源均未改。

## 实例、批次与每帧成本

| 项目 | 基线 | 本候选 |
| --- | --- | --- |
| 每实例几何 | 45 顶点／15 三角形 | 同上，三个矿区轮廓等长 |
| 植被材质与批次 | 一种材质，一个实例批次 | 不变；没有新增材质组或透明贴片 |
| High | 上限 2450，最多 36,750 三角形 | 不变 |
| Balanced | 上限 1800，最多 27,000 三角形 | 不变 |
| 近／远筛选 | High 14／34 m，远端 keep 0.30；Balanced 10／26 m，远端 keep 0.25 并乘 0.7 | 不变；最近实例优先，最后 6 m 高度渐隐 |
| 全株距离／视锥 culling、实例上传 | 既有 `useFrame` 与场景 `onBeforeRender` | 没有新增遍历或常驻任务 |
| 静态几何属性缓冲 | 3780 B，不含实例 kind 缓冲 | 4320 B，增加 540 B |
| 实例矩阵／颜色／kind 缓冲及踩踏纹理 | 固定容量 | 不变 |
| 顶点属性槽 | 13，含矩阵 4 槽和实例颜色 1 槽 | **仍为 13** |
| 灯与阴影灯 | 既有设置 | 新增 0 |

最终真实几何属性列表：`position:vec3`、`normal:vec3`、`color:vec3`、`aBlade:vec3`、`aLeafPosition:vec4`、`aBloomPosition:vec4`、`aBloomColor:vec4`、`aFloraKind:float`，共 8 槽；再加 `instanceMatrix:mat4` 4 槽和 `instanceColor:vec3` 1 槽，共 13 槽。不存在单独的 `aQuarryPosition` 或 `aFloraDetail`。

矿区草 XYZ 复用叶位置、花位置、花色的 `.w`；`aBlade.x` 原高度值已可由所选位置推导，因此改存 0 至 490 的精确 Float32 整数。其低六位存三类叶缘位置，高三位存八档相位；原岛外草的 `.y` 相位、`.z` 叶缘不变。代价是少量顶点 `floor`／`mod` 和分支；这是减少属性槽的取舍，不是“GPU 零成本”的结论。新原型在最大实例缩放、最大风和完全踩倒的保守组合下仍在原 1 m culling 球内，测试覆盖了这一边界。

## 局部夜间可读性

`WorldMineMaterial` 只改变现有矿区材质副本，引用同一个 `night` uniform 对象。没有全局曝光／环境光改动，没有新灯、新材质实例、新纹理或每帧订阅；矿区入口、矿线和木栈道调用范围不变，`WorldAlphaMine.tsx` 无须修改。

补偿是 `diffuseColor.rgb × (0.72, 0.82, 1.0) × night × roleFactor`，加入局部 emissive 辐射项。它是很弱的、保留原色的夜间环境反射近似，不是真实光照模拟。踏面因世界法线朝上而比侧面保留更多补偿；世界朝上方向由 `normalMatrix` 和 `viewMatrix` 求得，避免跟随相机方向变化。

| 材质角色 | 侧面系数 | 向上踏面系数 |
| --- | --- | --- |
| 地面 | 0.026 | 0.026 |
| 石材／矿线宿主 | 0.018 | 0.052 |
| 木材 | 0.012 | 0.038 |

`night` 沿既有 0 至 1 渐变，白天该项为零。保留原有材质钩子、颜色、纹理、石材风化及木纹，不给矿物颜色或池图面加补偿。矿区 wood 从普通 craft 程序变为矿区专用程序，全局最多增加一个木材 shader 代码变体；材质实例数与绘制批次不增加。实际 program 数、片元开销和是否显得平／发光，必须由主线 GPU 检视。

## 请主线串行实机验证

1. **白天近看 1 至 3 m**：工具架到池边的花草，绕到背面并压低视角。检查宽叶折面、茎与花瓣是否相接、双头是否可辨、是否仍过于尖片化。已有 preview 中靠近工具架的花／草约在矿区局部 `(-6.92,0.015,-5.47)`／`(-6.75,0.015,-5.57)`，阔叶约 `(-2.77,0.015,-9.17)`，仅作导航线索，非本轮 GPU 观测，资产更新后以实际位置为准。
2. **中远景 8 至 15 m／20 至 34 m**：在西坡平台看向池边，再缓慢倒退和转镜头。检查八片草冠和双花头是否形成层次、颜色是否噪杂、渐隐和屏幕边缘是否跳变。切 Balanced 复查，不用降低档位掩盖 High 问题。
3. **真实风／踩踏**：走穿同一丛后停步观察恢复，沿高低平台边缘走，确认脚下压倒而上层植被不被跨高程压扁；风中花瓣接点不可裂开。暂停等待后继续，时钟与踩踏不得积压补算。固定 QA 机位不是动画验收替代。
4. **局部夜间**：暂停菜单切 Night，确认两秒渐变后能休眠；继续后从工具架沿西坡到下层矿线 `(-6.4,1.3,-20.85)`，看台阶顶面、侧面和路缘。转向中层矿线 `(-8.6,4.3,-25.45)` 与池边，确认不只是图面或发光矿石可见。补偿不得让整片石头显得自发光、抹掉层次或把木栈道染成灰白。
5. **昼夜／周边回归**：Night 切回 Dusk，矿区外营地和原草形、矿区木纹与石层原色应保留；池图面、HUD、检视与网络路径由主线拥有，本轮未编辑。若图面夜间不可读，向主线单独反馈，不在此分支跨界修改。
6. **预算读数**：在主线只读 renderer 统计中记录同机位、同档位的 calls／triangles／programs，以及 `grassDebug` 实例数、候选数和上传次数。静态上限不变不等于实测 frame time 不变；正式验收需分别记录视口、DPR、昼夜、暖机与系统负载，不能捏造 CPU／GPU 降低比例。
