# v31：国投钢卷持灯照检

沿用已批准的国投视觉方向。本轮改善地面钢卷检查的动作与完成条件，没有重新规划园区。

## 实际变更

- 前卷、后卷的地面照检由角色先转身，再抬手持灯扫过卷面，最后收手。手电挂在 G24 真实右手掌节点上，替换原先悬空平移的组合工具。
- 同一固定物理时钟负责动作。检查要经过当前动作的实际双掌渲染姿态，再完成收手，才能提交原有货物证据。机制计时器不能提前完成照检。
- 中途取消、离地、角色不可用、切换批次和缺少有效渲染姿态不会授予检查证据；暂停和后台状态不推进动作。
- 原有翻卷、吊移、货物身份、结论选择和高廊固定观测仪的规则保留。光束沿真实钢卷的外层卷面扫动，并在翻出的背面凹痕区域结束。
- 这是手工编排的双臂 IK 动作，未引入或声称新增动捕。此次也没有把钢卷规格检查扩展成独立的手动测量小游戏。

## 验证

- 27 项角色骨骼、动作状态、照检控制器和逐槽取放测试通过。
- 34 项几何、装卸路径、安全联锁、导览和恢复测试通过。
- 补强“前卷未移走时不能绕过后卷遮挡”的控制器断言，所属 4 项测试再次通过。
- 严格 TypeScript 检查通过，入口覆盖 WorldActors 和 WorldIbdMechanisms。
- 生产构建通过，耗时 6.51 秒。
- 浏览器使用现有 Chrome 标签页和流畅画质。QA 只用于初始接货台定位，之后步行取工具、前卷照检、走到手轮翻卷、返回照检、签认并进入吊移步骤。
- 前卷正面照检的实际渲染手掌误差约 4.75e-8 m；这一数值只证明节点对齐，不代表主观动作质量评分。
- 背面检查先取消，页面明确保持“未记为完成，可重试”。重试后在动作 1.15000006 秒处暂停，两次读取相同时间且未确认，恢复后完成收手并出现“两面完好／背面损伤”判断。
- 同一侧面相机记录午后和深夜持灯截图，手电、手臂和照检状态均可辨认。浏览器控制台没有错误。
