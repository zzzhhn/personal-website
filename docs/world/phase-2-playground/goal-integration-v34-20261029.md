# v34：交易所工作台的造型、材质与局部光

沿用用户已通过的 Alpha v2 建筑风格与空间布局。本轮细化实际操作的柜台与设备，不改历史数据、回合规则或建筑占地。开工前已通过 `check-visual-reference.mjs --for-implementation`；验收复用现有 Chrome 标签和 4343 候选服务。

## 实现

- 中央圆台由细条装饰改为 24 组有凹凸层次的胡桃木框、内嵌面板和收边。面板位于原柜台外沿以内，仍由原来的连续柜体提供碰撞。
- CRT 终端、键盘、取票机、清算机底座与工作台使用单级平面倒角，保留本世界的切面风格。键盘补实际按键，终端增加侧面通风槽和电源钮。交互拨杆、压印块、铃绳握柄也使用相同倒角，原接触锚点与动作时序不变。
- 建筑仍为一个不透明静态批次，用逐顶点属性区分石材、木材和铜件的粗糙度／金属度。保留共享夜间发光通道，场景卸载时释放新增材质。
- 两盏绿罩工作灯位于终端旁。灯罩内衬和小范围台面暖光沿用夜间通道；台面亮区在创建几何时写入静态顶点，只覆盖灯下向上的工作台高度范围。这是有界的局部照明近似，不是带遮挡求解的实时光照。
- 没有增加实时灯、阴影灯、纹理、倒影、定时器或逐帧扫描。柜台与设备细化仍合并进原静态几何。

## 开销与交付

建筑本体与玻璃共 27936 个三角面，相比 v33 的 23976 增加 3960；静态模型仍为两个批次，加原图集共三个。实体碰撞 18112 面，支撑碰撞 120 面。新增动态握柄只是原网格替换，不增加网格数。

本机开发版取票后步行、调仓和封单期间采样 100.096 秒、6002 帧，最后 1800 帧的 p50 为 16.7 ms、p95 为 18.1 ms；全窗口最大 36.6 ms，超过 33.33 ms 占比 0.033%。末帧 93 draw calls、447658 三角面。此窗口包含操作间停留和诊断读取，属于该场景局部测量，不代表全地图或其它设备的表现，也不是 CPU／GPU 单项耗时。采样期间没有并行构建。

资源预检曾出现内存警告，可用磁盘约 9 GiB，故复用单标签并串行工作。生产构建前停止 4343 开发服务，v33 保留回滚。生产目录 `/tmp/bobby-world-v34-20261029`，`world/index.html` SHA-256 为 `b83b3a3f39fc3b22a103017edfc0b53d9c80f51421c49c683162b49da7642e91`，4343 候选 HTTP 内容与构建文件逐字节一致。
