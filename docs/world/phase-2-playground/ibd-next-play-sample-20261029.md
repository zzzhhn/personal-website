# 国投下一块交互样板：逐槽检查

状态：源码审阅后的开发建议，尚未实现。v23 已修好连续黄箭头和玩家自主判断，不再重复扩写这两部分。

## 现状与下一步

`src/components/world/attractions/ibd-yard-game.ts` 的 `contents` 在一次操作后同时记录身份、数量、规格及箱内质量。`ibd-yard-geometry.ts` 已有四槽及 M6／M8 轮廓、空槽，却合并为一个网格；`WorldIbdMechanisms.tsx` 的检查工具仍只是物件旁的动作提示。

先把一箱做成可操作的工作台：开盖后选任意槽，拿出样件，用滑动卡规夹量，放回原槽再选下一件。空槽可直接探看。夹爪未接触或夹偏时不给读数；四槽检查完才形成现有证据，接上自主判断、退换与装车。没有倒计时，顺序自由。

角色左手托件，右手推动卡规；手与样件、夹爪与杆身都应接触。每个槽保留检查标记，重复夹量不重复计数。取消或离开时样件回原槽，已完成检查保留；换货后按新货号清除旧结论。不要把夸张模型尺寸解读为真实毫米，也不宣称这些具体动作是用户实际工作细节。

## 最小完整实施范围

- 逻辑沿用唯一货号，新增槽位检查状态；读数必须来自夹量成功事件。已有运输、判断和取消恢复规则继续生效。
- 角色新增独立国投动作层，复用矿区双臂 IK 的处理方式，保留矿区动作。短样板检验站位、手掌挂点、工具净空与脚底稳定，不称为新增动捕。
- 分工可独立分成模型拆分、状态与输入、人物动作三项；主线整合后实际操作一箱，覆盖漏件、规格错、取消、换货、反复检查和完整装车。

## 有意义的园区扩展

样板成立后再接货架分拣支线：用手推车把核验后的托盘送往两个可选月台，短路受堆货遮挡、长路宽敞，玩家自行选路线。沿用同一货号与真实装载事件，到货才计完成。扩建的面积承担运输和选择，不铺空仓库。

与经历的联系限于核对数量、规格、质量及实物与单据。具体道具和路线属于游戏化设计。
