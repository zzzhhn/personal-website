# 矿区试玩反馈修订

依据 Bobby 的两张现场截图和八项反馈，沿用 WorldQuant 矿区、Alpha Agent 交易所的归属。基线为 `dcd6700`。本轮由原人物、美术、玩法三个 session 与统合 session 协作，不替换已接通的线上计算契约。

## 体验决定

- 摄像机近墙、洞顶和桥下必须遵守物理路径，不通过把岩体变透明来掩饰镜头进入岩体。
- 低处有真实步行出口；另外在地图设置内始终提供返回营地。返回只清角色瞬态，保留工具、矿石、矿脉、回测池及已验收线上结果。
- 矿区真实地面与地图共用自然轮廓。连续矿脉用于引导探索，具体可采点仍由探测装置确认；矿脉不是三个独立发光目标。
- 植被有高低和形态差异，继续使用现有风、人物扰动和踩踏系统，不增加静态草贴图或独立更新循环。
- 回测池在世界里保留悬浮图面。曲线、时间轴、测试段指标共用一张深度测试图面和稳定底色，避免不同对象被岩体分别遮挡或融进天空。
- 池边空手交互或探测器按钮打开聚焦检视。检视使用已收到的结果，支持逐日日期滑块、A/B 叠加、当前池位指标、来源说明；不触发重复请求。
- 聚焦时暂停角色输入、物理与持续渲染、相关音频。原生 dialog 管理焦点，Escape 先返回池边，不同时弹出地图。

## 数据和性能约束

仍仅使用三种白名单因子，线上单请求队列、去重、25 秒超时、最多三个访问内缓存不变。曲线是完整历史、首日净值 1；收益、IC、回撤和换手率来自返回的测试段。没有对应交易日时显示实际前一观测，不插值造价格。A/B 使用统一纵轴；比较中 SPY 虚线明确标注所属池位。

空间图面只在结果、标尺或语言变化时生成纹理，释放时销毁纹理和材质；浮动仍使用已有风时钟。检视图使用 SVG 与原生范围输入，不加入图表依赖、计时器或后台轮询。SVG 路径按数据和展示范围缓存，拖动日期只更新游标与读数；打开时优先选择玩家当前池位。

修复世界页未定义的 `--sans`，复用原有 Geist／中文系统字体栈，避免矿区字号简写因缺少变量而失效；没有新增字体下载。

## 模型复核

主线实际看了三轮模型预览。第一轮近景仍像平墙上贴椭圆矿包、植被均匀；第二轮外缘和成簇植被改善，但大面积灰色矿面仍与岩壁材质分离，均退回修正。最终活动矿面直接取用宿主三角面的顶点色、相同颗粒／法线材质及米制 UV，大部分边缘内埋，仅保留约 0.62×0.49 米的小破碎面，长分支矿纹留在岩壁上。静态／动态颗粒和法线 PNG 载荷哈希一致，三态击打点保持不变。

静态模型为 70,513 三角形、6 个材质批次、2,186,512 字节；动态矿面为 4,428 三角形、1,072,016 字节。动态文件增加了共享材质所需的颗粒与法线纹理，不能仅用三角形下降声称整场景性能已改善。植物继续每簇 15 三角形，原实例上限不变。
