# v27：国投逐槽检验的接触音效

v26 的取样、卡规和归位动作只有整箱完成时的通用声音。本轮把反馈移到三个已经通过角色接触验证的状态变化：拿到样件、夹爪贴合并读到规格、样件放回原槽。取样使用现有工具短音，夹量使用金属短音，归位使用衰减较快的木托接触音，局部音量分别为原素材的 0.58、0.72、0.60。整箱最后一次归位不会再叠加一声完成音。

这些是现有合成素材，并非录制的 Foley。按钮点击、未夹准、空槽观察、重复回调、取消和回到营地不制造物理接触声。按货物身份、轮次和版本确认变化，保留距离衰减；距离改变时不会把局部较低音量重置为满音量。

继续复用 ParkAudio 的同一音频上下文、SFX 音量和静音、八个同时播放音源上限、24 个缓存键及 1 MiB 缓存上限。没有新增素材下载、音源类型、轮询、帧循环或定时器。暂停或退出后丢弃音效，不在恢复时补播。已批准的 36 秒音乐和未批准的 40 秒候选均未修改。

## 验证

- 56 项相关测试通过，覆盖完整发货、逐槽接触、错误夹量、空槽、取消、距离、共享音源预算及生命周期。严格 TypeScript 检查和音频构建前检查通过。
- 复用现有 Chrome 标签，先暂停再载入候选。用可见 QA 按钮定位接货台和 A 箱，实际领取货单、走到工具台领取工具，然后操作两个槽的取样、夹量和归位。没有注入角色或检验状态。
- 第一个槽故意保留 0.54 的夹爪间距，得到未贴合提示，音频缓存没有新增；调到 0.46 后读到 M8 并生成金属 PCM。浏览器诊断只证明音频链路运行与回收，不代表真实设备上的听感认可。
- 中途一次仅简化类型分支的源码修改触发 HMR，适配器的素材变体计数重新开始，因此第一槽归位复用已有缓存。随后第二槽在未热更新的情况下完成，单独验证归位素材。详见同目录 `qa-20261029/ibd-v27-contact-audio.json`。
