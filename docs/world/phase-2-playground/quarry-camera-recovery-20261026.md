## 修正与范围

- `camera-collision.ts` 共用球形扫掠检查镜头枢轴、第三人称轨道、第一人称眼点及水面／震动修正。包络半径按实际近裁剪面、FOV 与窗口比例计算，至少覆盖近裁剪面的四角。镜头只立即收近、缓慢退远；不强制最小碰撞距离。
- 删除原先从候选镜头上方 40 米向下找最高 surface 并抬升的位置修正。多层矿道的上层板面会被误当下层地面；这条修正在扫掠之后执行，可能把镜头直接抬穿顶板。
- `WorldOcclusion.ts` 排除 `assetId=alpha-mine` 的遮挡淡出，矿壁保持不透明。其余建筑／植物的局部淡出保留。截图不能单独证明身体穿墙，当前也不把代理扫掠检查等同实景视觉验收。
- 极窄空间能把镜头压进自身头盔。`WorldActors` 在最终镜头定位后，按 G24 的身体／头盔包络和近裁剪半径关闭专用父组绘制，并用 12 厘米恢复余量防止闪烁。子角色仍求解骨骼和矿石 socket；没有使用会清掉动作的 motion.hidden，也没有逐帧 React setState。离开近身范围即恢复，固定证据镜头也恢复。QA camera 新增 `guideHidden`、`nearPlaneRadius`，nearPlaneOverlaps 使用同一包络。
- Esc 菜单增加次级按钮“回到营地”，主操作仍是“继续探索”。`campReturnRequest` 由 `WorldActors` 的同步 store 订阅处理，暂停期间无需等待物理或渲染帧。复位至既有 CAMP_SPAWN，清速度、角速度、力、扭矩、座位、车辆归属、卡片、池边聚焦、动作、输入、跳跃／跨栏／上下车瞬态以及镜头状态。当前车辆停在原处，不搬到营地。
- 复位只取消未完成挖矿动作。已释放但尚未完成投递的矿石按既有取消契约回到手中；保留工具、矿脉、携矿、暂存矿石、回收台、池位与本次访问的线上结果／请求。没有重载页面或清结果缓存。
- `poolInspect` 被视为输入／物理／角色／镜头暂停，状态切换清输入和退出指针锁。Esc 优先关闭池边聚焦，其次关闭卡片，再切换地图菜单。按键重复不反复切换；旧按键重复与非中性手柄不会在复位后重新激活。

## 菜单设计核对

| 原则 | 本次决策 |
|---|---|
| 意图一致 | 在已有 Esc 菜单放置回营地，遇困时无需寻找场景物件。 |
| 认知负担 | 一个恢复按钮加一行保留进度说明。 |
| 状态可见 | 同步恢复并显示已有 toast。 |
| 容错 | 保留矿石和研究，不要求破坏性确认。 |
| 可操作性 | 使用真实 button，加载未就绪时禁用。 |
| 设计隐去 | 复用原菜单，返回后关闭菜单。 |
| 无须说明书 | 动作名称直述目的。 |
| 尊重时间 | 暂停中也立即执行，不等物理时钟。 |
| 无暗黑模式 | 不重载、不清进度，保留条件写在按钮旁。 |
| 单一主操作 | 继续探索保持 world-primary，回营地为次级。 |

| 布局 | 复用 world-dialog-actions 纵向布局，world.css 仅增恢复按钮样式。 |
| 导航 | 无新页面、侧栏或路由。 |
| 数据 | 不增行情副本；读数／结果不重置。 |
