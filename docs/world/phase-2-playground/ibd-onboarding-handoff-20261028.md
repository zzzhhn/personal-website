## 本次行为

首次进入场地，默认显示一个当前作业点：地面箭头、站位圈、现场短标签。靠近并被全局交互系统确认可达后显示 E / Y；HUD 的动作按钮也要求同一个可达站点。目标范围内其他 IBD 交互让位，避免隔壁转台或秤抢走 E；范围外仍可自由探索。

接货台新增白色货单，接单后出现收讫标记。工具台放有手电和卡规，实际拿取完成后工具从桌面消失。已检货物显示状态圈，异常为橙色，核验一致为绿色。拆箱、转卷、吊移、装卸和升闸仍由原有真实机构动画执行。

首单推荐动作共 19 次：接货、取工具、前卷正面、转台、背面、吊移前卷、后卷正面、转台、背面、A 称重、A 拆箱、A 核内件、B 称重、B 拆箱、B 核内件、A 装车、B 装车、核对、升闸。

引导完全从现有货物证据、移位、开箱和装载状态推导，没有第二套教程进度。先走高廊会跳过已完成检验；先开箱不会强制回去称重；异常会引向退换及新货复检；提前装车会引向卸回补检。关闭或恢复带路只更新独立的 visit preference，不改货物和证据。离开后回到场地保留访问进度。下一批与重做入口保留；首单结束的主按钮是接下一批。

## 主会话仍需做的实际试玩

1. 新访问从正常入口或回传点步行进入，不看文档、不用传送与状态注入，只看现场短标记完成接货、拿工具和第一卷正面检查；记录找到第一个动作所需时间及停顿位置。
2. 全程用 E 或手柄 Y 完成 19 次真实动作，确认推荐目标与全局提示一致；现场标签在棚内、高廊遮挡、日夜和常用摄像机角度下均可读，不挡物体关键变化。
3. 观察接货标记、工具消失、卷转面、吊车移卷、箱盖开启、内件槽位、入车和升闸。若玩家不知道“发生了什么”，仍需返工反馈。
4. 中途关闭带路，自由走高廊/开箱/误装，再恢复；离开再回来；完成后接下一批和在货单详情重做。确认进度不因切换引导丢失。
5. 跟随每条地面箭头实际走通，特别是后卷、转台和两个台秤；测试动作过程中行走或暂停、相邻交互抢占、狭屏 HUD、中文/英文。新增引导没有 per-frame animation，仍需实际帧率检查。

通过这些检查才能判断新玩家是否无需长文完成作业链。本次自动测试不证明新手理解、视觉质量或用户审美验收。

## 10 principles re-check

| 原则 | 本次具体处理 |
| --- | --- |
| 意图对齐 | guide 从真实当前状态选一个可执行动作 |
| 认知负荷 | HUD 主区只展示当前装置、动作和一句提示 |
| 状态可见 | pending 不推进目标；机构动画和短结果共同反馈 |
| 容错 | 自由探索后恢复、误装卸回、替换后重检 |
| 可操作暗示 | 货单/工具真实可取，圈与 E 对应实际交互 |
| 设计隐退 | 箭头落在现场，详细证据折叠 |
| 无需手册 | 自动化验证动作链可完成，首次理解等待实际试玩 |
| 尊重时间 | 接单即时完成，长动作保留“正在作业” |
| 无暗门 | 关闭带路不改变批次或证据 |
| 单一主动作 | 目标可达时一颗主按钮，相邻装置不抢 E |

## Cross-cutting conventions audit

| 项目 | 处理与边界 |
| --- | --- |
| 双语 | 所有新短提示、按钮和现场标签支持 zh/en |
| 字体 | HUD 沿用现有 sans/serif token；现场 canvas 使用本机 sans，不拉新字体 |
| 布局与主题 | 沿用 IBD aside，新增样式受 ibd 前缀限定，支持日夜主题 |
| 导航与输入 | 不改全局侧栏、控制器、WorldActors 或共享接口 |
| 数据字段 | 展示的是实有状态与秤读数，不生成完成度或模拟证据 |
| 资源 | 一张 768×160 现场标签纹理；路径合并一个 mesh；只在步骤/语言/可达变化时重建，无新定时器和逐帧 React 状态 |
