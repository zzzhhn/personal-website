## 编曲选择

保留 E4-G4-A4-G4／D4-C4 的问答，避免整段只轮流播同一种短提示音。felt 是较慢软起音、衰减不同的有限共鸣；pluck 只在句间少量回答；pad 分声部进入、保持低泛音；bass 只出现在部分回答，第三段前退出。温暖、不尖锐是设计目标，尚未通过听感确认。

| 段落 | 秒数／小节 | 材料发展与留白 | 实测 RMS |
| --- | --- | --- | ---: |
| A | 0～12／1～4 | 原 B 问答，第三小节无新音，第四小节只留回答 | −29.292 dBFS |
| B | 12～24／5～8 | 同节奏上行到 B4 后回落，Dm7 回答、Fm 借用色彩、G7 收拢，少量弹拨回应 | −27.957 dBFS |
| C | 24～30／9～10 | 撤掉旋律与低音，只留较低 E3-G3 片段和薄和声，再留空 | −39.461 dBFS |
| D | 30～36／11～12 | 缩成 E-G 与 D-C，G7 解到 Cmaj7，尾音跨接下一轮 C 和声 | −31.097 dBFS |

C 比 B 低约 11.5 dB，减法没有被归一化或限制器补平。保留呼吸区，不叠连续鼓／帽子、环境噪声或新副旋律。此曲并非三段 12 秒 B 的机械拼接，也未调用旧 48 秒音频或其录音。
