## 实际实现

- 三棚原柱体保留碰撞包络，可见部分改成腹板和翼缘；屋面下有连续工字椽、檩条、脊盖、闭合膝节点板、锚栓与墙檩，连接已有三道门户。各棚位置、宽高、屋面碰撞不变。修掉山墙循环尾端浮点残差生成的零高度肋条，当前静态模型无退化三角形。
- 后场沿用原货架及三个卷材保护体积。木箱增加托脚、绑带、板缝与货签；三架分别表现箱货、桶装和真正两端贯通的管束；背景卷材有环向层次和绑带。未向工作面或物流路线增加固定货物。
- 继续沿用批准的蓝灰／绿色涂装与暖光。裸钢截面、涂装、木料、混凝土和橡胶在现有 `aMat` 中区分粗糙度／金属度，无新贴图、材质批次或全屏效果。
- 新增两处卷材侧向工作灯、两处拆检面条灯、接货／工具台夹灯和两盏车内顶灯。22 处静态灯具定义同时驱动灯壳与一次性顶点补光，实时灯仍恰好两盏、均不投影。按高度、方向与局部贡献选择灯具，并在同一对灯具换主次时保留 light slot，避免两个淡入同时重置。
- 货车仍为长 Z 侧装、1.2 m 地板、2.3 m 货物 pivot。可见地板与内壁分段，提供局部补光采样点；增加内壁凹入衬板及护条。一体碰撞包络保持原值，西侧装货口和坡道不加门槛。车内灯最低表面约 3.764 m，真实闭盖货物顶约 3.51 m；顶部中心／边角和侧向可见净空均通过大于 0.25 m 的断言。
