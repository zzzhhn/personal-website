# 五个想进去玩一会儿的地方

2026-10-25 · 第一轮历史讨论稿 v0.1。

**后续方向已更新：** Bobby 已选 Alpha 因子矿为第一个 pilot，并授权设计后开发。当前范围以 [Alpha 因子矿 PRD](PRD-alpha-factor-mine.md) 和 [开发计划](development-plan.md) 为准；Club 留作后续方向，潮汐弹珠湾、回声栈桥、风筝岬仅保留玩法参考，不再作为项目或经历映射。下文保留最初发散画面，不代表五处都进入开发。

先留下五个画面：**海边蹦迪、提着探测器挖矿、把浮球借风送进洞、和几秒前的自己合作、放一只越飞越离谱的风筝。** 去掉项目名字，这些动作也应该有意思。下面的时长是体验设计目标，趣味性还没有经过试玩验证。

## 1．DJC × 合拍：落日露天 Club

沿海岸听见低频，穿过一段帆布入口，眼前是朝海敞开的下沉舞池。头顶悬着一颗能把光撒到海面上的 Disco Ball；DJ 台、舞池、侧边坐阶和看海栏杆共同组成一个可以停留的地方。

- **先玩什么：** 走进舞池，角色开始随拍摆动，玩家随时切换舞步、转身、跳跃或定格摆 Pose。也能自由站着听，或跑到台上接一小段歌。
- **身体和声音的反馈：** 脚步落拍、衣服晃动、舞池灯带和镜球光斑一起呼吸。连续踩中几拍，可以引来旁边 NPC 的呼应舞步；他们是预设角色，不暗示在线玩家或真实人气。
- **小惊喜：** 拉一下舞池边的绳铃，镜球缓缓降下，整个舞池短暂进入贴着人群的碎光；下一次音乐起势，再把光送回高处。精彩之处是自己引发了这一刻，不必先攒满分数。
- **为什么再来：** 同一首歌换个舞步、换个站位、试一次接歌，现场就会不同。可以挑战一段短节奏，也可以完全不计分地蹦迪。
- **项目自然出现：** 想接歌的人拿起一张实体唱片，先听下一首的试听，再做一次大幅度、听得见的转场；DJC 提供操控的联系，合拍提供选曲与衔接的联系。完整产品入口留在台边，普通舞客不用学习混音软件。
- **还留着的选择：** 先做自由舞步，还是加一个约 30 秒的跟拍玩法；舞池是热闹 NPC 场还是更私人的海边 Set，都可以继续聊。

音乐先由玩家明确开始播放，离开后平滑减弱。曲目、音量和动效强度可调；减少闪烁时仍能靠角色动作和柔和光圈跟拍。歌曲、舞蹈动作、录制和导出所需的授权分别核对，不能因已有 Demo 就默认整套可用。

## 2．Alpha Agent：有回声的因子矿脉

山体裂开一条能走进去的矿道，矿脉沿墙壁爬上高低不同的岩台。入口挂着镐子和手持探测器；洞外是一池映着天空的水，池底刻着一条时间轴。

- **先玩什么：** 拿起探测器，跟着脉冲寻找矿脉，从不同高度和角度判断开采点。敲开表层、取出矿石，抱到回测池边，亲手投进去。
- **身体和声音的反馈：** 越接近目标，探测器的短促声和指针摆幅越清楚；镐子有预备、碰撞、碎屑和石块脱落的重量。探测器发现的是可开采因子，不负责预测收益。
- **小惊喜：** 一块看起来普通的石头，敲开后露出横贯整面岩壁的矿线，引出能从上层绕回入口的小路。发光、深度和稀有外观都不代表金融表现更好。
- **为什么再挖：** 记住一条矿道后，可以找另一支矿脉、试另一组参数，或者把上次失败的因子放到另一段真实历史里看。重复的动力来自发现和比较，不是“挖到必赚矿”。
- **项目自然出现：** 每块可回测矿石有固定身份，能对应到明确的因子表达式和窗口；回测池把真实净值路径沿时间轴呈现出来，回撤也照实留下。靠近矿石铭牌才展开表达式、数据来源与区间。
- **还留着的选择：** 探索更接近寻宝还是有一点工具技巧；先用固定因子矿石，还是允许把少量兼容碎片组合，都没有锁定。先保留镐子、探测器和立体矿脉这三个核心。

投石水花立即出现，真实结果允许稍后回来查看。无结果时不生成“看起来像回测”的曲线。历史重放、固定历史数据重算和联网计算是三种不同状态，详见 [真实回测如何接入](real-backtest.md)。

## 3．潮汐弹珠湾：借一点风，把球送过去

退潮的浅湾里露出几道弯曲石槽、可以转动的风向板和装着贝壳的目标碗。球不是藏在界面里的小点，而是一只需要人物推、踢、追着跑的大浮球。

- **先玩什么：** 站到球旁选一个方向，蓄一点力把它送出去；跑去拨转一块风向板，再看球擦着石槽绕弯、弹起或落进浅水。
- **感官反馈与惊喜：** 碰撞有空心鼓声，进碗会让贝壳依次响起来。有时没进目标碗，却撞到旁边的小机关，把另一条近路升了起来。
- **为什么再玩：** 少推一次、换一个入射角、试一条更好看的曲线。失败后球回到近处，几秒就能再来，不用重跑整片海湾。
- **当前定位：** 仅保留物理玩具参考，已撤回与交互式课程项目的映射。
- **保留空间：** 是纯物理玩具，还是短小的定杆挑战，等游玩方向确定后再选。

## 4．回声栈桥：和刚才的自己搭个伙

一段窄栈桥通向水上的小灯亭。桥板旁只有一盏可以提起的灯：放下灯后，一道半透明的“自己”会沿刚才走过的短路径再走一次。

- **先玩什么：** 自己踩住一块桥板，再回头，让回声替自己站在原处；趁另一块桥板升起，抱着灯走到对面。可以先随便走一段，看回声笨拙地模仿，也是一种乐趣。
- **感官反馈与惊喜：** 回声的脚步像隔着水面传来，两个人影错身时，灯光短暂叠成一个图案；终点可以坐下看整条栈桥逐段亮起。
- **为什么再来：** 用更短的路径完成配合，或者刻意编一段好笑的双人动作。失误后就地重录，不扣资源。
- **当前定位：** 仅保留与自身动作回声配合的玩法参考，已撤回与比邻项目的映射。回声只是短暂游戏记录，不读取私人对话。
- **保留空间：** 是否做正式解谜、记录多长、允许几个回声，都先不定；若动作回放成本太高，可以先留为远期候选。

## 5．风筝岬：把一只风筝越放越高

海岬上有一只折好的大风筝和卷线轮。先在草地助跑让它离地，再收放线，让它顺着海风划过灯塔上方。

- **先玩什么：** 跑、牵线、放线、调整方向，试着让风筝穿过两根旗杆之间，或者贴着海面拉起来。人始终留在地面，暂不引入滑翔和新的空中移动系统。
- **感官反馈与惊喜：** 风绳拉紧时人物后倾，纸面发出鼓动声；飞到某个高度，才看见背面藏着一条很长的尾巴，在岛上投下一道移动的影子。
- **为什么再来：** 一次更漂亮的转弯，或者在不同风向里留住它。也可以没有目标地放着，听海和绳轮声。
- **当前定位：** 仅保留自由玩耍参考，不承担项目或经历映射，不进入当前 pilot。
- **保留空间：** 有限的预设风段和自由风场哪个更合适，留给后续小样；不承诺完整空气动力学模拟。

## 当前收敛方向

**Alpha 因子矿已选为第一个 pilot。** Club 是后续方向，其余三个只作为玩法参考。EvalForge 等项目仍可直接从项目目录或场所旁入口访问，暂时没有足够好的独立玩法就不硬配一个。

一段候选体验可以是：营地出门，开车到 Club，在舞池里玩一会儿；远处山壁有脉冲光，想探索时再去拿探测器。也可以完全反过来。这里描述的是游玩节奏，不指定地块、坐标、道路改线或通关顺序；风筝和浅湾也不作为开矿、跳舞的解锁条件。

本轮先完成矿脉的空间、动作、探索选择和真实结果闭环，具体见最新 PRD；未来场所和全岛规模不在当前开发范围。
