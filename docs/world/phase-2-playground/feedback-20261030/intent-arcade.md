# Intent workshop 半开放检修廊

本轮只新增 `intent-workshop-arcade.ts`、同名专测和本文。没有修改 `WorldIntentWorkshop.tsx`、现有装置、`CoasterBatch` 或全局照明。延续当前已批准的切面工业风格，按本轮实际工位外围增加雨棚和服务背板，没有新增参考图或把测试当作视觉验收。

## 接口与集成

`createWorkshopArcade(): { body, glow, colliders, triangles, dispose }`。

- `body` 与 `glow` 都是非索引、带顶点色的静态 `BufferGeometry`，已经处于 `coasterWorld` 世界坐标。集成时不要再叠加 coaster 原点位移。
- 主体可复用现有 `WorldIntentSurface`；灯条复用现有顶点色 `MeshBasicMaterial`。两份几何各一个材质槽，新增两次颜色绘制，不新增纹理、材质实例、实时光源、动画或逐帧对象。
- `colliders` 为 `{ position, half, rotation? }[]`，旋转是 XYZ Euler，与现有 workshop 碰撞结构一致。每个主体盒体对应同尺寸、同姿态碰撞盒，没有覆盖天空和通路的总包络。薄灯罩属于发光饰件，不扩大实体碰撞。
- `triangles` 返回两份最终几何的实际三角形总数，专测上限 9000；本会话未执行几何构造，因此没有把估算当实测面数。源码规模预计约 4000～5000 面。
- `dispose()` 只释放本模块拥有的两份几何，可重复调用；现有材质和场景资源由集成方持有。

## 空间组织

工位来自 `WORKSHOP_TOOLS` 和 `WORKSHOP_INTAKE`，不引用旧 `INTENT_STATIONS`。各工位有独立短雨棚、两根钢柱、悬臂和斜撑；高位外围服务梁连续连接，中央没有整块屋盖。顶板下表面局部坐标 Y=5.57，悬臂下缘 Y=5.33，灯罩最低 Y=5.27，避开既有 intake 标牌和最高 Y=4.95 的支架。主体背板最高 Y=2.65，给 Y=3.15 的胶囊载具和 Y=3.65 的吊轨留出通道。

act 工位使用前侧两根柱，坐标 X=-11、-7，Z=75.15。若按普通工位放后柱，会切到 hub 至 act 的斜向运输路径；移柱后两柱夹出操作面，前场中间入口仍连通。低背板仍位于各工位 Z-1.85，不挡机械运动。柜体只在左外围 `[-26.2, 0, 69.4]` 成组设置。

主线首轮专测报告两处净空失败后，intake 左柱移到 `[-18, 0, 70.55]`，上部纵梁向后延长 0.6 m，使斜撑在进入 bell 上方范围前已高于保留体积。extract 左柱移到 `[-10, 0, 67.2]` 的工位侧边，避开 rewrite 斜向步行路线，同时位于该处胶囊支线前方。测试净空和路线没有缩减。本修复仅做源码与语法检查，复测由主线串行执行。

中央保留 X=-20.5～-12.8、Z=64.5～69.8、Y≥5 的天空开口；入口保留 X=-13.2～-11.8、Z=69.5～80 的地面通道。坐标均为加 `coasterWorld` 原点之前的设计坐标。站位与载具测试使用真实世界坐标，不移动既有站位以迁就建筑。

## 灯光与验证边界

每棚前部使用连续暖白工作灯，外围青色主线，debug／act／intake 三处有小面积洋红节点。`CoasterBatch` 的静态夜间属性继续保留，新增灯对本模块主体顶点做一次暖色补光；它不会照亮已有地面、设备或动态角色，现有实时光仍由主场景负责。

专测覆盖有限几何、9000 面预算、两色批次、资源释放、实体碰撞角点、全部 `workshopTarget` 站位、装置及 intake 标牌净空、实际胶囊运输路径、前入口及各工位步行路线、主门和中央天空开口。运输测试从 `createWorkshopCapsule()` 取得真实包围盒，加 0.1 m 余量并按不超过 0.15 m 采样；入口路线使用半宽 0.6 m、高 2.5 m 的身体／镜头检查体。路径和站位同时检查碰撞盒与可见三角面。

本次仅运行源码转译语法诊断及 `node --check`，没有执行几何专测、构建、浏览器或截图。主会话串行执行：
