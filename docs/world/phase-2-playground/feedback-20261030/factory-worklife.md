# 工厂备料与检修生活细节候选

2026-10-30。只新增 `factory-worklife.ts`、`factory-worklife.test.mjs` 和本文，未改动已有模块，未接入 `WorldFactory.tsx`，未提交或推送。沿用批准的奶油白、青绿工业环境和带护具的人物方向，没有重新设计厂区。

## 接口与集成

```ts
const life = buildFactoryWorklife(FACTORY_PALETTE, {
  lamps: built.lamps,          // 已有灯具，factory-local 坐标
  nightUniform: night,        // 已有共享昼夜 uniform
});
// life.root 挂在现有 FACTORY.origin group 内，不能再次加 origin 平移。
// life.solids 已是 factory-local，只追加一次到现有固定碰撞体。
life.update(clock.elapsedTime, active, paused || document.hidden);
// 卸载时先移除 root，再 life.dispose()。
```

返回 `root / solids / metrics / update(elapsed,active,paused) / dispose`。初始 root 隐藏，首次 active update 才显示。elapsed 为单调秒数；模块只积累 active 且未 paused 的时间，单步最大 `.1` 秒，隐藏或暂停后不追赶错过的动画。

不创建定时器、React 状态、动态刚体、批次身份、生产事件或新的灯光。这里的周转示范不改变玩家库存、试验结果或评分。

## 布置与用途

| 工位 | 工人脚位，factory-local | 保守占用区 X / Z | 作用 |
| --- | --- | --- | --- |
| 备料/分拣 | `[-14,.12,21.5]` | `[-15.55,-13.1] / [21.22,22.7]` | 两格浅盘之间搬移同一件 U 形周转料；侧架放整齐料块，下方收少量边角料 |
| 设备检修 | `[-39,.12,7]` | `[-40.55,-38.1] / [6.72,8.2]` | 扳手绕固定阀轴做短角度扳动，旁边存放备件，检修块留有凹入面板与实际轴头 |

工作面 Y＝`.92`，工人最高约 Y＝`1.69`。两人均有奶油白头盔、深色面罩、护耳、手套、工作服与固定站姿。物资都在桌、架、浅盘或余料盒内，没有沿地面散撒。

备料件只有一件，每 8 秒左右换到另一格，下轮反向；包含停留、抬起、横移、落下、松手与小幅回收动作，没有无限生成或到循环边界瞬移。材料架与余料盒是有限背景物，不冒充玩家正在制造的批次。

检修工具的骨骼轴心是 `[-38.82,1.125,7.44]`，与固定阀轴同心。工具约 ±`.22` 弧度往返，工人不行走、不改变设备运行状态；这是一段可读的检修动作，不声称模拟真实扭矩。

## 通道与相机边界

源码对照了原料磁吊 x＝-44.35～-30.65、z＝-24.35～-12.65，以及总装吊装 x＝17～39、z＝-25～27；两工位不在这些低位吊装包络内。备料位在第三条加工线以南，检修位在轮组线与外壳线之间的西侧空区，均不占三条沿 X 出料走廊或 x≥32、z≈20 的返工线。

现有互动站位、控制台、两条坡道及平台均未修改。新增专测还以保守工位盒检查全部互动半径、现有 work/dispatch 相机射线。检查尚未执行，实际行走与跟随镜头仍由主会话验收，不能从源码空间计算推断已试玩通过。

## 几何与资源预算

按现有 primitive 面数规则手工估算约 3.6k 三角，低于额外 6k 上限；尚未调用模型构造做实际计数，主会话测试会打印 `metrics`。

- 一个静态 Mesh，包含两张桌、两架有限物料、两个工人固定身体与护具、维修块和余料盒。
- 一个 SkinnedMesh，只有备料前臂、单件周转料、检修前臂与工具三个受驱动单元；四根骨骼含一个不动根骨。
- 2 次颜色绘制。仅静态 Mesh 投射阴影，动件不投射阴影；在现有单太阳阴影配置下再加 1 次阴影绘制，共 3 次。接收既有阴影与工作灯，不新增灯。
- 两份几何、一个共享工厂材质、一个 Skeleton，6 个静态粗碰撞盒。无 NPC 动态物理。动画更新骨骼，不改顶点缓冲、不逐帧分配材质或几何。
- `dispose()` 幂等，只释放本实例创建的两份几何、材质及 Skeleton/其骨骼纹理，包括被外部拆下的拥有部件；不遍历释放后来挂入的其他对象，也不拥有传入的 night uniform 或 lamps。
