## 连接现场与修复

用户的 Safari 现场确实停在横截面动量的失败提示。原代码把 HTTP、超时、数据校验和网络异常统一画成 Connection interrupted。原失败没有保留可读的错误分类，不能凭截图确定它是 Vercel 欠费、冷启动、网络中断或浏览器问题。

主线在同一 Safari 页面点击原有 Retry，约 1.51 秒得到结果，池上图线和指标出现，Inspect curves & metrics 按钮恢复。未刷新用户页面，矿石和进度保留。检查器只看到本地分析事件 `/api/events` 的 404 与已知弃用 warning，没有原回测失败的网络记录；不把这个 404 当作回测故障原因。随后关闭检查器，并将该页面暂停以减少资源占用。

同时以页面相同固定请求逐个调用真实接口：ROC20_RANK、LOW_STD_20、REVERSAL_5 均 HTTP 200、CORS `*`，耗时约 1.72/1.26/1.21 秒，每项 752 点且通过现有完整性校验。请求串行，无数据文件入库。这证明当前接口可用，不证明之前没有瞬时故障。

代码 `b52ab60`：

- 区分排队、请求中、8 秒慢响应提示、有限恢复和最终错误。
- 网络错误或 502/503/504 最多恢复一次，间隔 1.5 秒。启动恢复前及等待结束时都检查在线/可见状态。
- 25 秒超时、429 限流、其它 HTTP 错误和无效结果不自动重复计算，保留矿石供玩家主动重试。
- 单请求队列、同因子去重、三个访问内缓存、取消清理和旧响应隔离保留；无后台轮询和无限重试。
- 探测仪和池图使用同一组中英文状态。错误解释和恢复操作在当前池边出现，来源详情显示种类、HTTP 编号、请求序号、尝试次数及耗时；不显示原始服务器响应正文。

连接专用 11 项测试及交易所、回营地、池图兼容合计 26 项通过。类型检查 322 文件、0 errors、0 warnings（138 hints）。这是源码和模拟传输验证；新错误状态的实际界面验收将在整合浏览器轮次完成。

## 主线验证与当前性能状态

整合后的网络、矿区状态、布局、花草、物理、入口、路线、相机、角色、回营地、池图及交易所测试共 111 项：首次 110 通过、1 项因缺少资产环境变量跳过、0 失败。随后使用 `ALPHA_MINE_ASSET_DIR=public/world/alpha-mine` 单独复跑 `guide-mine.test.mjs`，11/11 通过、0 跳过，补齐真实工具插槽用例。没有把两轮重复项目相加。

实际浏览器已验证一次暂停停止更新：同一候选页面在 2026-10-26T05:38:59.996Z 与 05:39:54.812Z 的可见读数均为 frame 15483、wind 388.0658000000042，相隔 54.816 秒，无帧或风时钟增长，frameloop 为 demand。当时高画质 buffer 为 2684×1373、MSAA 4、shadow 2508，103 次绘制、248,504 三角形、230 geometry、61 texture、106 program。这是最终美术合入前的单点读数，既不是最终资产成本，也不是 CPU/GPU 能耗或内存泄漏基准。

在最终资产验收前，浏览器控制连续超时，用户主动关闭候选试玩并明确反馈卡顿。主线停止 4342 开发服务，没有重新打开页面。4341 仍保持 `3870aef`，未切换本轮候选。系统内存压力多次为 warning，但不能将用户感受到的卡顿只归因于系统。

性能源码审计已纠正一项错误猜测：矿区 mesh 被 `WorldOcclusion.excluded()` 排除，不参加四束常驻视觉射线，因此没有为此引入 BVH。已确认的可减少开销是全岛 473×561 RGBA8 踩踏纹理反复整图上传；按 60 次/秒计算的逻辑体积约 63.68 MB/秒属于静态算术，不是测得的 GPU 带宽。性能线只针对脏范围上传继续修改，不同时降低模型、密度、画质预算或改动阴影。

后续仍需分别量测的风险：High 固定约 369 万绘制像素、4× MSAA，以及三个 2508² 阳光阴影级联；目前没有随帧时间自适应的预算。4× MSAA 不能解读为所有片元 shader 必定执行四倍。草实例筛选、静态阴影对象重扫和矿石材质多层 noise 也是独立待测项，尚未修改。营火已有静态保持策略，不能说六面营火阴影始终每帧重画；单次约 922 MB 页内存也不能证明内存泄漏。暂停停帧与连续运行成本是两项独立验收。
