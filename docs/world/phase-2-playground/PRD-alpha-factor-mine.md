# Alpha 因子矿：从找矿到见证结果

2026-10-25 · Pilot PRD v0.1 · 设计基线 `8310f66`；已纳入主线采纳的矿场参考图与数据审计结论。

## 1．概述

把 Alpha Agent 的“挖因子”做成一座主题公园式独立设施：玩家走进立体矿脉，用探测器找矿，挥镐采出因子，带回回测池，看到有明确来源的真实历史结果。一轮游玩的价值在于搜寻、判断、动手与发现；真实结果不理想时，玩家仍有下一处矿、下一条路可以尝试。

Bobby 已选择它作为第一个 pilot，并授权设计完成后开发。本文件定义体验与验收，[开发计划](development-plan.md) 组织实施；主线审阅后继续推进，不新增一次开发授权门槛。底层物理、动画、建模和数据适配方法由执行线按效果选择。

## 3．背景与事实边界

新版世界已有营地、道路、角色、车辆和项目展位。旧 Alpha 研究桌主要是按键触发拨杆和演示曲线；这不足以让玩家经历一次真正的寻找与开采。新设施需要有独立轮廓、内部路线和可操作的工具，不能停留在水边小木屋里的一块屏幕。

长期方向是让实习经历成为可玩的设施，让项目成为有特色的场景或体验。本 pilot 将研究中的“提出候选、验证、保留失败并再尝试”融入动作和结果；不把整个研究工作流逐项变成三维表单。

## 4．目标与成功标准

**目标：** 交付一段约 4～7 分钟可自由结束的采矿体验。访客不用金融知识，也能发现自己想试的开采点；想了解作品的人能随时找到项目与经历来源。

以下为 pilot 完成前的观察目标，不是已有成绩，也不是对所有访客的保证。

| 结果目标 | 如何观察 | 达成口径 |
| --- | --- | --- |
| K1：首轮不用讲解也能开始 | 初次进入后，找到工具、扫描并打出第一块矿 | 目标 60 秒内完成首次有效开采；以最多 5 次首次游玩观察争取至少 4 次达成，样本不足报告实际人数，不用脚本或重复玩家冒充首访 |
| K2：一轮完整且有选择 | 从进场到投池，再自行找到另一条可玩路线 | 首次循环目标 4～7 分钟；局部 0／3／6 m 各层与回路可达，不依赖强制跳跃、答题或阅读长文 |
| K3：失败后继续而非等待 | 分别看见亏损／回撤、候选拒绝、无数据或服务异常 | 各状态均有原因和可执行下一步；矿石不丢失、移动不被锁住、无需刷新页面恢复 |
| K4：结果可信 | 抽取一个矿石身份，对照因子、数据与配置，核对结果 | 三种白名单候选均有本次真实历史运行与可复核重放；模拟和缺失不会被当作真回测完成交付 |
| K5：有第二次尝试的理由 | 首轮后不提示玩家去哪，观察下一步并询问原因 | 记录是否自发换路线、换候选或再挖，以及具体动机；Bobby 的乐趣与观感反馈单独保留，不用操作完成率替代 |

首访记录用于发现问题，不作留存率或统计显著性结论。性能沿用[长期性能任务](../phase-2-performance.md)：同条件比较新旧场景，不能靠删掉关键效果或降清晰度宣称完成。

首版面向当前桌面世界的键鼠体验；保留既有手柄和辅助访问入口的兼容性。没有实物验证时不宣称手柄完成，手机不在本轮新建完整三维控制方案。

## 6．给访客的价值

玩家先得到一段可自己掌控的小冒险：信号逐渐清楚、岩面被敲开、石头有重量、投池产生回应。他能回忆“我从哪条矿线挖出了什么”，而不仅是点过某个项目名称。

作品的联系来自真实方法：探测到线索不等于结果有效，漂亮矿石不等于更高收益，一次失败仍值得留下并比较。矿石的正式定义、结果和来源是可追溯的，深入细节由玩家自愿选择。

本 pilot 不做竞品优劣、采用规模或教育效果的无证据声明。它要优先做好一座独立设施，而不是扩张全岛或复刻完整研究终端。

## 7．体验方案与需求

### 7.1 空间：一座向上生长的开放矿场

从道路侧进入一个前庭，工具架靠入口，石砌回测池向前庭开放。入口与矿场底层和所在岛面齐平，岩壁向上围合出局部 0／3／6 m 的步行层；木回廊与缓坡连接不同高度的矿线。上层背光裂缝接入侧面回路，绕回来时，玩家能从另一角度认出之前看到的矿纹。

```text
道路与停车接点 → 前庭／工具架 ↔ 回测池 A、B 展示位
                        ↕              ↑ 能看见下一支矿线
                   0 m 开采面 ↔ 3 m 回廊 ↔ 6 m 裂缝
                        ↑___________________↓ 侧面回路
```

这是相邻关系，不是固定地图坐标。独立设施指完整的轮廓和内部体验，不要求新页面、传送加载或独立引擎。

- 主线采用的方向约为 32 m × 36 m，岩壁高约 4～9 m。0／3／6 m 均指相对设施底层的局部高度，局部 0 m 对齐所选岛面，不是海平面或世界坐标 0。场地落点由主线确定；细部按相机、通行和动作样板验证。
- 地面不下挖穿透岛屿，不用图中的凹坑观感要求真实地形切洞。采纳参考图的阶层岩壁、木栈道、贯穿岩面的彩色矿纹、工具架、灯笼和石池，不把图当成已实现画面。
- 入口先看到工具和一个可辨认的矿线，池边能看到另一条矿线。初次游玩不靠全屏任务清单找路。
- 两条路线都能步行完成，主通路以低于现有可走坡度的缓坡为目标；25° 是当前支撑代码的上限线索，不是建议坡度。跳跃只可作可选捷径。
- 按正常第三人称相机验证宽度、转角和顶空。山体遮挡时采用局部可读的空间处理，不能让镜头钻进岩石；不为一张截图扭曲模型比例。
- 回测池是前庭中的核心装置，有可接近的投石边、时间方向和近读来源位。不能把一片海面或原小屋屏幕改名当作完成。
- 不要求全岛开挖、体素破坏或真地下洞穴。手工岩面、局部破损与其他方案均可，只要开采结果与碰撞可信。参考图由主线持有，路径为 `alpha-pilot/references/quarry-art-direction.png`；本线已看图，不复制图片或覆盖美术线文件。

### 7.2 一轮怎么玩

| 环节 | 玩家实际做什么 | 场景回应与选择 |
| --- | --- | --- |
| 看见与拿工具 | 走到架前，取探测器和镐子 | 人物真实取物并收纳；默认只提示眼前一个动作，不弹设备配置页 |
| 寻矿 | 边走边扫，把探头转向不同岩面 | 信号脉冲、指针和岩纹相互印证；能判断大致方向及上下层，无法从信号强度推断收益 |
| 选一支矿线 | 近处底层，或沿回廊看高处分支 | 至少两条不同路线，三种白名单候选可选择；同一家族的矿纹可相似，但不伪装成实证金融相关性 |
| 挥镐 | 对准可触及岩缝，做一段短开采 | 预备、挥动、接触、碎屑、岩层变化、矿石脱落连续可见；初始目标约 2～3 次有效接触，按手感调整，不靠重复几十次拖时长 |
| 带回 | 拾起一块矿石，抱回池边 | 工具自然收起，矿石有手部接触与重量；一次携带一块，不开背包网格 |
| 投池 | 选择空展示位，实际投出矿石 | 松手、飞行、落水即时回应；收到合法矿石后才登记结果请求或匹配重放 |
| 见证与再出发 | 看结果，换支矿线或沿侧路返回 | 结果不替玩家判“通关”；失败也能取回／保留矿石身份，下一次选择始终可达 |

探测是连续观察，不是走近目标自动揭晓全部位置；开采是玩家触发的动作，不是按一次键替玩家播完整采矿电影。首个矿点线索清楚，后面的矿点允许绕到侧面、比较岩纹后再判断。已有展品的“一键演示”注释不限制本设施的玩法深度。

首轮至少有一次空间惊喜：敲开表层后，矿线在侧面继续延伸，从回廊才能看全；那里也能看回自己的第一处开采面。它提供新路线和视角，不附赠未经计算的收益加成。第二轮可以换矿支、改变走法，或尝试更准确的开采和投掷。

### 7.3 动作、输入与容错

- **即时响应：** 有效输入在 100 ms 内出现明确的姿态或提示回应；接触声在镐头实际接触时出现，不能提前敲响。完整动作可更长，不能因此吞掉输入或把人锁住数秒。
- **扫描：** 走路和转向保持可控。视觉指针／强弱刻度与声音提供同等线索，静音仍能找矿，不新增常驻第二套音频上下文。
- **挥镐：** 只有可到达、面向合适的实际目标可被击中；跨墙、跨层或距玩家很远的近邻不能成功。落空有清晰石面／空气反馈，不产矿。用实际模型接触点验证，不要求某一种碰撞算法。
- **取消与重复：** 接触前可取消，离开作业面、暂停或打开菜单不会自动追加敲击；一次有效开采只产一份矿石。按住或连按不会复制矿石、结果或任务。
- **搬运：** 一块在手时可放回就近承托面；切换工具先可靠放置，不突然消失。禁用手上拿石时的驾驶和其他冲突动作，放下后恢复原有行为。
- **投掷：** 从手中真实释放，目标边有自然投石站位和必要的落点辅助。投偏后能就近找回或通过取回点恢复，目标 3 秒内再次尝试；不让石头滚进碰撞死角，也不靠隐形吸附掩盖明显偏投。
- **状态恢复：** 暂停、页面隐藏或打开详情时停下本地动作；恢复不补播旧输入。离开设施不强制完成任务，重进有明确的矿点重置和本轮结果保留规则。

### 7.4 矿石、真实数据与回测池

每块矿石对应经过审计的身份：可读假设、精确表达式、版本、允许参数、数据适用条件。首版固定以下三种通用种子，来自 Alpha Agent `df25036` 的 `alpha_agent/factors/alpha158.py`，不取自私人 BRAIN 因子。矿石颜色、大小、深度和玩家技巧均不改变计算结果。

| 矿石／身份 | 精确表达式 | 玩到后可自愿了解的假设 |
| --- | --- | --- |
| 回声矿 `REVERSAL_5` | `subtract(0.0, subtract(divide(close, ts_delay(close, 5)), 1.0))` | 近期下跌可能短暂反弹；趋势延续与成本可能使它失效 |
| 顺流矿 `ROC20_RANK` | `rank(subtract(divide(close, ts_delay(close, 20)), 1.0))` | 近期相对强势可能延续；反转行情可能使它失效 |
| 稳岩矿 `LOW_STD_20` | `subtract(0.0, ts_std(returns, 20))` | 给近期波动更小者较高分；低波动不保证更高收益 |

实际规格还须包含窗口、声明算子、股票池等完整字段并通过原有校验。三个候选使用同一实际面板、区间、组合与成本配置，具体值由本次运行记录确定。展示成本是模型假设而非实测交易费用；如引擎采用两腿各满仓的多空组合，说明实际仓位口径，不称作天然市场中性。训练与测试样本日期分别标注，不能混成一段“验证收益”。

**首版已选：`4341` 本地真实历史回测重放。** 先用已有 Python kernel 对显式选定的本地历史面板跑出三份新结果，保存对应证据，再由场景读取重放。不沿用旧示例里的漂亮指标，不调用 LLM、私人 BRAIN 或账户；不把回放进度动画伪装成正在现场计算。

| 证据模式 | 必须在结果旁说清楚 | 对 pilot 的意义 |
| --- | --- | --- |
| 真实历史结果重放 | 这是已完成结果；展示原数据区间、截至日、原运行时间和对应配置 | 审计合格后可作为真实结果模式，但不称为“刚刚现场计算” |
| 固定历史数据重算／联网计算 | 本次运行身份与时间、实际数据截至日、数据与引擎版本；联网不自动意味着实时行情 | 预留适配能力，当前首版不承诺现场计算或任意参数 |
| 模拟／合成诊断 | 从进入该模式起就持续写明“模拟数据／交互测试，不是真实历史回测” | 只能用于开发与测试，不计入 K4，也不能静默填补真实结果失败 |
| 缺失／不可用 | 明确缺少数据、权限或服务能力，不画假曲线 | 仍可展示找矿与投石，但整项“真实结果 pilot”尚未完成 |

完整证据要求沿用 [真实回测说明](real-backtest.md)。本地数据与结果包连同结果 manifest 留在 gitignored 位置，原始面板不进入公开前端资源。忽略 Git 只能避免版本提交，不能保证构建不会打包；执行线还须验证公开构建和部署路径排除这些本地文件。公开展示权由主线继续确认，本地开发不依赖该回复，不默认切到合成市场结果。

来源铭牌从实际结果 manifest 读取数据集、提供者、真实日期、过滤后资产数、数据／引擎版本、运行时间、成本、仓位和样本切分。审计指出 v3 文件含 Alpaca 行情及 WRDS 元数据，不能因此把整文件复制到网站；只读审计尚未生成可交付结果，也未证明公开展示权。

池内曲线按真实时间与数值展开，回撤和负收益照实保留；可以用流光呈现进程，不用机械波浪随机生成收益。A、B 两个展示位最多同时比较两份结果，采用相同时间和坐标口径。日期、来源模式、数据截至日靠近曲线可读，完整方法再展开。

投石水花先发生，结果到齐后再展开证据。实体矿石与比较结果分开：池边三格回收台保存三种矿石，A／B 两个展示位可替换结果，取回矿石不抹掉已有结果。等待时矿石可暂存托盘，双手释放，玩家继续采矿；展示位或任务容量满时说明原因，允许换展示或暂存，不无声丢弃矿石，不无限追加计算。清空展示不等于伪装取消仍在服务端运行的任务。

首版本地重放只显示实际读包与呈现状态，不显示“正在回测”或虚构排队。下表中的计算／容量状态用于真实计算适配的扩展与故障验证；本地读不到结果时明确进入缺失状态。

| 看见什么结果 | 设施如何回应 | 玩家下一步 |
| --- | --- | --- |
| 有效但亏损／出现回撤 | 保留完整曲线与解释，不打碎矿石或播放“你失败了” | 比较另一个候选，或回矿道看同家族分支 |
| 因子被拒绝／数据不适用 | 说明具体原因，与亏损区分 | 保留身份，选择受支持的候选；不把拒绝算成零收益 |
| 排队／计算中 | 标明真实状态；没有可用总进度就不编百分比 | 离开继续玩，完成后以常亮灯和短提示通知 |
| 超时／服务不可用 | 不编曲线，不无期限锁住结果位 | 查原任务状态、稍后重试；若有历史模式，明确由玩家切换 |
| 没有真实证据 | 来源位保持“暂无真实结果” | 可继续开采、直接看项目介绍；交付报告明确未完成真实闭环 |

新候选或参数变化必须得到对应新结果，不能套用外观相近矿石的历史曲线。随机只可用于碎屑等演出或不改变研究身份的位置变化。首版不做任意表达式拼装、LLM 实时生成或参数寻优排行榜。

### 7.5 自然联系经历，不增加一份工作任务

入口以一句话交代：“把研究中的挖因子，变成能亲手探索的一座矿。”工具与矿脉先说明动作，池边才出现假设与证据。玩家第一次看到无效或亏损结果时，可自愿读一句研究经验：“找到候选只是起点，能否留下，要让数据说话。”这属于设施叙事，不冒充未提供出处的 Bobby 原话。

前庭始终提供两个清楚分开的入口：“Alpha Agent 项目”和“WorldQuant 研究经历”。前者解释软件与可审计研究，后者读取原有经历内容。来源牌明确写本次结果实际来自哪里；若来自独立 OHLCV 数据，就不挂成 BRAIN 结果。任何时候均可绕过游玩直接访问，不能要求收益达标才能看作品。

### 7.7 假设、成本与未决定项

矿线判断、多层绕行和少量有效击打是否足够有趣，必须靠小样验证。32 m × 36 m 是主线提供的场地起点，0／3／6 m 是相对层高；2～3 次击打和 4～7 分钟时长可按实际观察调整。

已经收敛：地上开放矿场、主线参考图、三种白名单、本地真实历史重放。尚未决定：精确落点、细部结构、重放适配方式、实际计算配置、资产性能预算，以及运行中材质与接触效果。公开展示权由主线跟进；常规本地实现不等待一次重复的开发审批。

本文件不要求特定引擎扩展、物理求解器、状态管理库或建模算法。新设施需要独立生命周期和可核对的证据身份；实现方式保持开放。

## 8．分阶段交付与可观察验收

### 8.1 首版边界

**首版包含：** 一座完整可识别的地上矿场；前庭、0／3／6 m 连通步行层与回路；探测器、镐子、单块搬运和投石；三种白名单因子；双位结果比较；`4341` 本地真实历史重放；失败可继续、双语、直接作品入口及资源清理。

**留到之后：** 任意矿石合成、实时 LLM 造因子、动态大地图、无限可破坏地形、升级经济、多人协作、收益排行榜和全新移动系统。Club 继续保留方向，但不抢本 pilot 的资产和运行时范围；其他三个点子只作玩法参考。

### 8.2 交付节奏

数据审计和参考图方向已有输入，先落实场地和一次本地真实计算，同时制作最终质量的开采面与工具动作样板。样板用于检验能否好玩、好看，再扩到多层设施与池边闭环，最后串行完成整合试玩与必要性能回归。各阶段以效果和证据推进，不按固定日期赶占位版；具体责任、资产批次和接口见开发计划。

探索样板可以使用临时几何定位，但它只算开发中间态。完整 pilot 必须以游戏中最终资产、动作与证据验收，不能把占位矿山、图片概念图、构建通过或固定镜头渲染当完成。
