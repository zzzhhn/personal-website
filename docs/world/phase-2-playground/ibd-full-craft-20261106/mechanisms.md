## 局部验证

新增机制测试、原 hoist-detail 和 craft-geometry 共 9/9 通过，包括：

- 全 256 个 solid 的 JSON SHA256 保持 `ad00d1525a6e8602925b1b43253f441332a69503a7a6f013291b00ca73a9a56e`。
- 全 walkSurface vertices SHA256 保持 `a7a86e1c42de0df4951a7a839a08368a648436fd77b81c04a34cffb40fb54ee2`，indices 保持 `6d27b54f865dd07c848f77a54e2accce001e770a22ea968ffc51fd473d33f284`，即 2,450 vertices / 3,813 triangles。其中原辊道仍为 832 vertices / 720 triangles。
- 高廊仅原五个顶面的 20 个顶点使用 `-4`，坐标与原位置严格对应；脚板接地、立腿承托、轴端实际连接及原下穿空间无横撑均有射线检查。
- 机械各网格属性有限、无坍缩三角形、无材质分组；除涂漆卷帘外，全部动态族均有实际 `-2` 裸金属顶点。
- 原手电方向与工具可携带范围、原卷扬机开放窗口及屋顶净空、原夹鞋接触全部通过。

原 roller-contact 的四项行为检查全部通过：16 次普通角色接近、原横穿道／手柄站位、杆间空隙和 1,928 次满尺寸货物样本及相邻样本扫掠。其第一项在旧 static 48,500 上限处失败，失败发生在后续 contact triangles 对照之前；新增测试已独立锁定整个 contact mesh 字节未变。

另跑原 yard-geometry：七项玩法／物理检查通过，包括全运输路线、入口、相机 roof sweep、高廊连通、真实角色上坡转弯和全部站位。唯一失败为旧 representative 76,000 预算断言，当次完整 fixture 测得 93,783 triangles。该数是当时工作树的原 representative fixture，不是整批最终加载场景总量；并发整合后须重新量测。
