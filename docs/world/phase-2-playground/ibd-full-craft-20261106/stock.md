2026-11-06。基线 `e2abcb8`，分支 `codex/coaster-car-astra-pilot`。沿用已批准的三棚工业场景，未改布局、碰撞、货物数量、规格、操作锚点或箱盖轴。此次仅修改运行代码及轻量测试，没有启动 Blender、浏览器、构建或图片服务，没有新增／替换资产。

## 实际绘制路径

- 三座后部货架：`ibdCraftOptions(null).rackMode = family` → `addIbdStockRack` → 主静态合批 → 现有 IBD 材质。此次折弯立柱、地脚和锌层响应进入该路径。保留各层承载面、前缘琥珀条和原来的折边／承梁。
- 拆检螺栓、叉托、游标卡尺：`buildIbdPackParts` → 实际独立活动网格 → 原有 moving 材质。六角头保留握持半径和 `Y=.065` 接触面，改为独立倒角六角头及十二边回转轴；线程带保留原数量，改成接在轴上的环状梯形截面，去掉埋入轴体的整盘封盖。叉托及游标增加真实固定件，承载顶面、夹口接触面和拇指接触面不变。
- 检查台、两种工作台、十座控制台：`static-craft-v1.glb` → `createIbdStaticCraft` 按六类实体材质合批 → `cloneIbdCraftMaterial` → 共享 PMREM 及原静态灯具顶点夜间补光。保留源木纹、法线、粗糙度／金属度图和原生结构，不修改成功的原生几何。合批保留 `uv` 及存在时的次级 UV。
- 所有动态、库存、备用和回收箱体／箱盖：`crate-v1.glb` → 原有 Shell／Lid 节点及机制框架 → `createIbdCrateVisual` 复制实例材质 → 共享 PMREM 和随实际朝向变化的微弱夜间补光。几何、UV0、AO UV1、AO／木纹／法线／粗糙度纹理均继续借用 loader 缓存，箱盖本地变换及铰轴不变。未用修改备用程序壳体来冒充主 GLB 已精修。
