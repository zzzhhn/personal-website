# 国投装车卡车构造升级，2026-11-06

本轮只修改实际运行的 `ibd-truck-geometry.ts`，增加 `ibd-truck-craft.test.mjs`。基线为本工作树 `e2abcb8` 的原卡车生成器。批准方向为 `visual-calibration-20261027/ibd.json` 的 v1 工业场地，已查看其昼夜参考，实施检查通过。没有运行 Blender、浏览器、导出、构建或部署；最终游戏画面对照由主会话完成，本文件不表示视觉验收。

## 构造图

| 部位 | 构造与支撑 | 普通装车视角应看到的改变 |
| --- | --- | --- |
| 驾驶室 | 保留斜风挡、门窗凹口和轮拱；增加压制门带、连接屋顶的雨槽、保险杠牵引口 | 大门板有可读折面，亮金属与车漆、玻璃、橡胶分离 |
| 六个车轮 | 真实轮胎内孔、胎肩和三条胎面；环形轮缘、六条压制轮辐、凹入制动鼓及有厚度的轮毂 | 轮辐间隙可真正看进去，轮圈不再是平贴钢片 |
| 载货底板 | 钢制承板支撑八条长木耐磨板，板面精确位于 y=1.2；板缝下方 25 mm 即钢板 | 开放车厢出现可读长木板、细缝与金属包边，不增加坡道门槛 |
| 车厢端部 | 两扇钢板封门、中央闭合缝、包边、连接门体的锁杆与铰接点，替换旧的任意竖条与点状紧固装饰 | 端部具有真实闭合结构与冲压加强筋，保留既有封闭端面 |
| 东侧板与屋顶 | 东侧折压筋的斜返边落回连续壁板；屋顶边帽及顶面筋连接原屋顶 | 斜看出现板材折面与屋面厚度，西侧装车洞口完全开放 |
| 底盘 | 薄腹板和上下翼缘形成纵梁；三组横梁经立垫连接纵梁和钢制承板；钢板弹簧与原轴梁相接 | 车底具有连续传力关系，替换悬空平块和整条方梁 |

木板及内侧木质防撞条使用已有 `aMat.w=-3`，裸金属轮圈与部分边帽使用 `-2`，制造坐标写入原 `aSuv`。木板坐标沿车长，未增加纹理、材质组、实时灯或 draw。钢卷专用的 `-1` 未用于卡车。其余车漆、橡胶和玻璃保留各自 roughness/metalness；不改公共 palette 或 shader。

实际绘制路径：`buildIbdTruck` → `buildIbdStatic` 的同一 Builder → `WorldIbdYard` 的静态几何 → `createIbdMaterial(true, uniform)`。现有 shader 读取 `aMat`/`aSuv`，调用已存在的 wood/milled finish；没有未使用的 GLB。环境、烘焙灯光及其资源所有权由主会话保留。

## 固定契约及验证

最终三个测试文件共 13 项通过：

```sh
node --loader ./tools/world/alpha-mine-tests/loader.mjs --test --test-concurrency=1 \
  src/components/world/attractions/ibd-truck-craft.test.mjs \
  src/components/world/attractions/ibd-truck-art.test.mjs \
  src/components/world/attractions/ibd-truck-layout.test.mjs
```

新增检查确认全部八个 collider 对象和两条坡道旋转与旧值完全相同；全部属性有限，无坍缩三角形；六个车轮的真通孔比轮辐面凹入至少 45 mm；木板顶面与载货 datum 相同，板缝下方有钢承板；两个装车洞口在 y=1.3、2.2、3.3 的穿行射线仍完全开放。

原测试另外确认实际 Rapier 货物 load/unload 全路径扫掠、最终货盘承托、屋顶净空、普通角色登上并离开两条坡道、向西经过驾驶室离场；后轮最高点仍低于实际载货表面和物理地板。轮心 y=.6、半径 .58、半宽 .23、轮距及三轴 z=9.5/14.5/19.5 均未改变。驾驶室三个脚踏层、斜风挡与侧窗、格栅和灯窝的原探针全部通过。没有增加发光假工作灯。
