# v42 · 清算翼、后库工艺与空闲更新

本轮继续五项长期目标中的场景建模、照明和物资场体验。v41 卡规修复保留；没有重新制作已获方向认可的漫游音乐，也没有把整体 Goal 标成完成。

## 交付内容

- 清算机背后增加有厚度的胡桃木柜、票据格、分层纸卷册、台面前框与铜脚栏。柜体采用真实板材，保留操作位、后侧通道、楼梯和回廊，不增加新的任务步骤。
- 两条柜灯使用原有材质夜间通道和有界顶点补光。工作面保持绿色设备与木材颜色，不提升全局曝光，不增加实时灯或阴影通道。
- 国投后库货架改为可辨的前后立柱、柱脚和横梁连接；箱体增加接缝、压条、边条和带扣。样件、卡规、起吊零件、箱盖和碰撞保持同源不变。
- 非活动箱不再因其它箱的夹爪/槽位变化更新隐藏机构。交易所静止道具在状态未变时不重复写姿态；完成、取消和暂停恢复仍同步最终姿态。
