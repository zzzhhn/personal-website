# 主岛矿区与线上计算，2026-10-26

Bobby 的最新方向替代初期的小岛 Alpha 矿屋方案。因子矿区归属 WorldQuant BRAIN 实习经历，Alpha Agent 独立为交易所项目场景。两者之间保留数据计算关系，但页面明确说明矿区使用 Alpha Agent 计算，并非 WorldQuant BRAIN 官方回测。

## 当前实现

- 主岛西北轮廓扩展，控制多边形面积由约 20,541 m² 增至 27,919 m²，约增加 36%。原营地、城区、主路和五个其它项目小屋保留。矿区入口在 `[-84, 1.14, -55]`，新增土径连接主岛道路。
- 矿场有原三层核心矿线，以及西侧爬升、带实体顶壁的洞道、北侧深沟桥和上层返回环路。新岩面使用斜向裂面、弱色层和接地碎屑；前庭地面边界不再是矩形。矿场静态资产 86,663 三角形，6 个材质批次，约 2.50 MB。资产源文件和独立几何验证见 `alpha-pilot/quarry-v2.md`。
- 119 个草簇锚点接入全岛同一套实例草。风、人物推开、踩踏衰减共用原有时钟；扰动按脚底高度匹配，避免下层的人压倒上层草。可见实例上限仍为流畅 1,800、高清 2,450。
- 专用探测仪显示相对人物朝向的方位、距离、高差和信号。三类矿石具有不同轮廓：短期反转的双弯晶簇、动量的定向长晶体、低波动的层叠密石。地面、手持和投掷使用同一资产变体与握点。
- A/B 池位在实际完成投矿后请求线上回测。结果曲线、测试段指标和数据来源一起浮在池上。双池采用统一净值标尺，彩线为因子，灰线为 SPY。图面朝向镜头，空间图线维持可读线宽；深度遮挡仍启用。
- Alpha Agent 的交易所位于原项目园区入口以北 `[60, 1.14, -55]`。敲开市钟后，用 10,000 虚拟点数体验买入、手动推进历史交易日、卖出和重开。数据来自同一 API 的 SPY 基准净值，首日归一到 100；这是历史指数份额沙盘，不是个股实时报价或真实下单。板面只随状态/语言改变重画，不轮询。项目详情入口在主行情板前。
- 靴子前端缩短 6%、鞋底宽度缩小 10%，保留脚底高度、靴筒和原骨架；运动测量使用同一修订后的模型。增加五种轮换闲置动作，动作/移动开始即重置。没有声称本轮替换了全部动捕或解决了全部转向/落地问题。
- 人物用原胶囊体做运动扫掠与上下车通路检查，保留原物理重力、坡地支撑和推物响应。实测发现贴地胶囊会把正常地面接触误判为上车阻挡，已只给通路查询增加 12 mm 离地余量；不跳过混合地面/墙体网格，完整宽度、头顶和墙面检查保留。
- 三辆车加入真实内凹进气开口；轿跑增加灯腔、透镜、前唇、引擎盖缝和制动盘细节，合入既有车身/轮组批次。驾驶 HUD 复用角色状态发布，移除自己的 100 ms 轮询。氮气尾焰仅在物理状态真正 boosting 时出现。

## 线上契约

请求现有 `https://alpha-api.bobbyzhong.com/api/v1/factor/backtest`，固定三种白名单因子，不调用 LLM、不传凭证、不修改后端、不产生订单。参数为多空、前后 30%、训练 80%、10 bps 成本、purge/embargo 各 1 天、SPY 基准、静态模式、请求历史成分修正。

客户端验证曲线日期严格递增且对齐、数值有效、因子和返回参数匹配；货币值各自按首日归一为净值。收益、IC、回撤来自 API 的测试段指标，完整历史曲线另行标注。接口当前返回的历史成分修正状态和 membership date 被保留；收到时间仅为客户端验收时间，不冒称服务器计算时间。请求参数与接口实际回传确认的参数区分保存。

每次访问最多保留三个因子结果，一次只发送一个请求，同因子去重，25 秒超时，仅手动重试；卸载中止未完成请求，不会自动重试或轮询。结果不写入仓库，不添加本地行情副本或历史录像。原本地回放工具仍保留为历史/离线验证用途，矿区当前 UI 不再依赖它。
