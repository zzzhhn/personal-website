# Club 三类现有家具与设备精修

本包替换两张平躺椅、DJ 台身和两只监听音箱，共三个真实剩余家族。保留已接受的吧台、圆日床、灯笼和伞，所有布局、物理三角形、座位、接近坡道及DJ控制器保持原值。用户原有站位、转盘、旋钮、推子、耳机和发光按键继续由原几何负责。

平躺椅采用完整低木框、17根承托板、四角接件、闭合微拱软垫、连续包边与锁式缝线。DJ台身保留原板条节奏，补全顺材独立顶板、钢架、横撑、脚垫、背衬和台底线缆鞍。音箱采用真实厚箱壁、双层振膜与柔性盆边、固定销、封闭高音罩、离面格栅及其支架。构造和材质由普通视距的边厚、接缝、轮廓及真实间隙解释，未通过放大粗糙噪声增加细节。

304个原生命名网格均闭合，零非有限坐标、零退化三角形。GLB按家族及材质合批，三个实际命名根为 `DJC_Furniture_lounger`、`DJC_Furniture_console`、`DJC_Furniture_speaker`，共10个网格、6种物理材质、6张内嵌贴图。单份资源33,280三角形，五个场景实例合计52,964三角形；此为几何数，不是网页性能通过声明。

最终 `furniture.glb` 和 public `furniture-v1.glb` 均为2,891,784 bytes，SHA-256为 `35ca81133737bcee227b7c5686327d428c71d43d19d94b38b6125ca2c533aca3`。三类真实before、最终fresh及clay共9张检查图均已实际打开；修正后fresh与clay再次逐张检查。新增家具4项及相邻遮阳伞6项测试共10项全过，没有跳过资产测试。重型工作已结束，Blender退出且本任务FILE锁释放。

木色与OpenGL法线来自已接受的本地Poly Haven `wood_table_001` CC0照片，原图只读，派生1K后内嵌。板件UV逐面展开，长纹沿真实长轴，不将水平顶面压为一条UV线。织物颜色、粗糙度及法线按0.6m平铺、2mm线距确定性生成，音箱涂层粗糙度为512px原创图。未新增外部依赖、HDR、实时光、AO、透明或透射材质；来源与原始散列见 `texture-sources.json`。

真实before由冻结版本 `0118dfc` 在原 `add` 路径截获，不是手工重建，也不是浏览器截图。三个单件分别为120、510、300三角形。before、after、fresh与clay保持各家族相同机位、灯光和曝光。源、几何、输出、相机与灯架记录见 `manifest.json`、`asset-contract.json` 和可复现工具。渲染为Cycles CPU3线程、960×768、16采样，无景深。音箱首轮检查发现顶部裁图和高音罩材质误用青色包边，已扩大检查机位并改为设备金属后重新导出和渲染。

运行时递归解析家族根及嵌套材质，跨实例共享loader几何及图像，只复制自有材质和采样器，并复用现有 `WorldDjcFurnitureEnvironment` 缓存。90m内首次加载，180m外剔除；加载和错误均回退至同一份原几何，候选与旧图不会叠加。对照入口为 `?qa=1&djcFurniture=legacy`。所有原始碰撞、座位、坡道及已接受资产数组均由精确比较测试覆盖。

原有遮挡仍保留：第一张 `[74,47]` 平躺椅约后1.85m被 `[74,48]` 圆日床覆盖，两张平躺椅中心也均有原遮阳伞杆穿过。为避免视觉脱离原碰撞，本批未擅自移位、抬高或隐藏。网页比较应采用第二张 `[74,63]`，并将这种既有布局问题与新材质区分。若后续重新安排位置，需要一并修改视觉与碰撞、检查日床坡道。

离线审图与技术导出完成后，浏览器日夜、真实成本和用户视觉接受仍由主线复核。本包未启动浏览器、修改全场灯光、构建规则或全局运行逻辑，未提交或推送Git。
