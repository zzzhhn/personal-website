# Alpha Agent：复古交易所高厅实现

2026-10-27。以 `concept-1990s-20261027.png` 为本世界的风格参考。此次交付是代码和几何实现，尚未在浏览器验收。

## 空间与模型

入口原点仍为 `[60,1.14,-55]`，与园区连接的原 approach 及其 3.1 米宽度不变。厅体扩为约 26×30 米，高约 12 米。它包含厚石墙墩、带柱鼓和竖向饰线的奶油石柱、叠层深檐、三角山花、真实侧窗／前窗、透光天窗和厚木格梁，内部和夹层均可进入。

两组前场胡桃木马蹄交易席和一组后场交易席具备实体柜体、厚台面、铜饰边与后侧开口。28 套厚 CRT、键盘、电话、线缆和纸张构成设备层；四个实际操作屏共用原状态图集，其余屏幕保持待机底色，不生成装饰报价。后墙有深铜钟壳和大钟，前场保留可摇动的铜钟。

地面有真实木板接缝、边界嵌条和罗盘式几何镶嵌。后夹层有支撑柱、约 2.2 米宽的连续坡道及铜栏杆，坡道出口留有真实栏杆缺口。正门与右侧出口是独立地面通道，均通过完整站立胶囊检查。

天窗和高侧窗单独合批，玻璃参与相机碰撞但不投射不透明窗板阴影。世界已有太阳可通过窗格照入；两盏有界暖色点灯补厅内光线，不增加带阴影的灯。

## 共享锚点

`alpha-exchange-layout.ts` 是共同坐标来源：

- `EXCHANGE_STATIONS` 保持 `buy / sell / next / reset` 四个原动作，新增 `yaw` 让操作屏朝向操作者。买卖席位于 local `x=±6.6,z=-5.4`，站位 `x=±6.6,z=-3.75`；推进／重置席位于 `x=∓3,z=-9`，站位 `x=∓1.45,z=-9`。
- `EXCHANGE_HALL.project` 为 `[0,1.4,-24.2]`，主历史板位于 `[0,2.65,-27.25]`。大钟和开市铃的位置也由 `EXCHANGE_HALL` 导出。
- `ALPHA_EXCHANGE_FOOTPRINT` 表示实际规整建筑平面，不表示矩形陆地。建筑下方是与全岛相同的地形高度场，外围有自然变化的岸肩和向既有桥水道回退的连续凹湾。

地图继续从真实地形三角提取水线，不再用矩形交易所范围强行写入海岸距离场。地图上的矩形只标识建筑；草散布排除建筑、落台及既有 approach。

## 实机入口共面重叠修正

主线确认入口栈桥出现明显 Z fighting。原 `approach` 旋转盒一直延伸到 local `z=0`，`entry-porch` 占 `z=.2..3.4`，厅内地板延伸至 `z=1.2`，三个顶面均为 `y=0`，形成真实正面积重叠。侧出口落台也有 2.5 米深的区域与大厅地板共面重叠。

已将地面接驳独立为 `exchangePlatformSlabs()` 的真实多边形板面：

- 大厅地板止于 `z=1.2`，门廊从该边界延伸至 `z=3.4`。
- 旋转栈桥按门廊 `z=3.4` 边线裁切，末端成为准确吻合的斜切接缝。
- 园区端按现有 `BOARDWALK_POINTS`／`BOARDWALK_WIDTH` 的实际外边线裁切。原 approach 起点本就在园区板面内约 0.35 米，这段继续由既有园区支持，栈桥不再覆盖它。
- 侧出口落台从大厅 `x=13` 外缘开始，去掉覆盖厅内的部分。
- 共享接缝不再重复生成隐藏的竖直墙面。顶面、底面、外侧封边和支持碰撞均来自同一组裁切多边形。

入口原点、路径锚点、地面高度、交易锚点及数据逻辑均未改变；没有提高板面或使用 `polygonOffset`。夹层坡道与楼板原来只在边线上相接，无需同类修补。

验证为 6 项几何／物理测试：包含四块接驳板与原园区条带的两两交集面积为零，以及生产动态胶囊在入口／侧出口两个路径、双方向、左右 0.8 米偏移的八条轨迹。使用生产支持、地面跟随、速度响应和清障函数，所有接缝连续且稳定，没有大于 1.5 厘米的高程误差或持续失地。目标类型检查通过。
