## 从当前版本到新体验

现有实现是约 26×30 m 的复古大厅，四个交易台负责买、卖、推进一天、重置；其余大多数 CRT 是静态装饰。当前历史数据是校验后的 SPY NAV，使用虚拟积分，没有真实下单、费用或滑点。新版不把这套受限数据包装成实时交易所。

本次提出约 36×42 m 的大厅、连通回廊和侧翼，尺寸仅为待审空间目标。中央只留一个有主次的交易池，历史档案室与清算室成为可进入的目的地。多出来的空间承担观察、操作、探索与绕行，不增加成排相同的电脑桌。

## 一个先做完整的游玩回合

1. 在档案室取一张历史时段票，票面说明数据来源和时段，不提前泄露未来走势。
2. 在主席插票启动，拉动仓位滑柄作一次选择，再敲钟推进下一段历史。报价板、纸带和手中单据同步变化，动作结果留在场景中。
3. 经过少量关键选择后，在清算室拿到实体回执，再上回廊回看自己的路线。第二次可用另一种选择重演同一段历史，与自己的上一轮对照。

“和自己的上一轮较量”比给出正确答案更适合这个场景。每轮只需少量有结果的选择；保留自由漫游，不设置强迫倒计时。独立侧翼可以藏新的时段票或可读的策略资料，但首轮不先堆很多系统。

Alpha Agent 的联系是候选思路、历史检验及人的判断。图中的送单装置是游戏化表现，不声称项目真的拥有券商交易链路。若以后加入策略对照，先接已有可核验结果；不编造收益、行情新闻或公司功能。WorldQuant 的因子矿场保持独立归属。

## 造型和照明

- 保留已有岛屿世界的切面造型、白盔人物、奶油石材、胡桃木和低光泽铜件。细节来自窗框、梁、接缝、台面与可操作结构，不依靠写实贴图和满屏粒子。
- 大钟、开市钟、中央台是三个相互关联的焦点。两条出入口、连续回廊及侧路能从结构上辨认；参考图不是碰撞或净空已通过的证明。
- 夜间灯具照到台面、角色、踏步和扶手，窗外仍保留冷色环境。蓝调小图只是气氛参考；实施前另补同构图日夜图，并记录实际引擎固定相机。
- 不用场景里的大量人群、音箱或屏幕掩盖玩法不足。先以一名玩家的一套完整动作成立，再决定是否需要有限 NPC。

## 首个样板及验收边界

用户通过方向后，先做入口至一张工作台的空间样板，及取票、插票、调仓、敲钟、取回执的完整短回合。手掌接触、撤销／离开恢复、暂停和回营地分别验证。再补代表性石木铜构件及同机位昼夜实拍，才扩大到回廊和两翼。

沿用现有场景距离门控、合批与有限音源。重复窗框和栏杆实例化；面光优先顶点／烘焙表达，少量有界实时补光只覆盖玩家操作区。不新增实时镜面、常驻行情轮询或网页后台音源。扩大布局后的性能需重新量测。
