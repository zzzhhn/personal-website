# 营地三家族精修候选

范围为当前 `WorldCamp.tsx` 的 C05 石砌火坑、C06 原木长凳、C07 书桌与凳。保留营地切面与暖木／灰石语言，精修石块接缝、刨平原木、横向垫木、木桌板、榫接、抽屉和凳架。当前请求明确授权这三类，不扩大营地摆放、角色坐姿或照明。来源以当前原始 GLB 与 `/tmp/bobby-world-batch2-c5f79ee1-20261101` 冻结运行版本为准。离线 before 是当前真实 GLB 回读，不能称为网页截图。

全部使用米。原生 Blender Z-up，GLB 仅转换一次到 Y-up，根节点为 `C05`、`C06`、`C07`，无额外平移／旋转／缩放。C06 坐面保持局部 Y＝0.600000024 m、Z＝±2.4 m；八处原座位仍使用旧 C06 推得的接触面和 ±1 m 切向位置。四个原长凳放置矩阵不变。C05 原半径 1.6 m、原火焰、时钟、暖光和运动保留。C07 桌顶保持0.852044821 m，书堆和桌灯位置不变。

视觉与碰撞分开。`InstancedAsset` 仍从原 `/assets/world/camp/C05.glb` 等文件计算并注册 `campShapes`；新 GLB 只替换可见网格。`WorldCampPhysics`、`WorldCampContent`、座位与坐姿动画均不修改。加载中、失败或 `?qa=1&campCraft=legacy` 显示原网格，物理始终挂载。

一个共享 GLB 保留三个家族之间的材质与图像身份，每个家族按材质合批，长凳四实例共用几何。摄像机距离营地95 m以内开始加载，180 m以外隐藏，随后保持loader缓存。无新增灯光、PMREM、透明／透射渲染、动画或服务。渲染器全局环境由主协调统一处理。

原生源保留命名构件、ASSET／BASELINE／PRESENTATION集合；运行时从副本派生，不覆盖可编辑源。木照片复用本地已许可的 Poly Haven `wood_table_001` CC0，缩至1K；C06／C07的树皮和端纹为确定性原创512px贴图。C05 r2改用本地CC0 Rock Face 03和Bark Willow扫描，色图sRGB，OpenGL法线和ARM粗糙度Non-Color；炭木颜色是扫描形态的明确派生，不称为炭木扫描。出处和原始散列见 `texture-sources.json`。原预算为小于30k三角、6材质和8图；C05表面修正后实际7材质、15图，多1个材质批次，无新增实时光，成本仍需网页实测。
