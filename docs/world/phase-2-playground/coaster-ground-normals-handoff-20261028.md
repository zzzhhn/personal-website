# 北岩肩缓坡法线候选

基于 `f521510` 追加，分支 `codex/coaster-drop-landscape`。按主线最新指令取消北岩肩底面一律分面的限制；只读查看 `world-v22-rock-material-day.png`，沿用已批准 v4 方向。本轮没有生成实际候选截图，视觉验收由主线完成。

## 改动与边界

只对北岩肩底面中朝上、坡角不超过 45° 的三角面，按面积汇总其共享顶点的邻面法线，再归一化写入原渲染角点。陡面不参与缓坡平均，也不接收平滑法线。四处独立岩床及碎岩完全排除，封底和边缘闭合面保留原法线。

处理发生在原 `computeVertexNormals()` 之后、现有夜间响应计算之前。没有改变灯具、光照参数或照明代码；夜间响应自然使用新的坡面法线。没有改变地形位置、颜色、接触数据、面数、纹理、植物资产或其他六块地形，也没有改动 4341。

## 验证

资源预检为 pressure 2、可用磁盘约 6.24 GiB。两个短窗口均原子取得共享锁、串行执行并在结束释放；没有浏览器、图像服务、下载或完整构建。

- 10 项定向测试通过：drop-landscape 6 项、structure-transfer 4 项。
- 2,679 个复用缓坡角点的单位法线及现有夜间响应完全一致；2,703 个角点的法线相对面法线变化超过 0.01。缓坡法线仍处于 45° 坡向范围内。
- 181 张朝上陡面仍采用面法线；560 张独立岩床／碎岩面保持分面。封底也未被平滑。
- 原有 2,400 个全程样本的车体、头部和三种预设视线净空检查通过；50 点可见面与 Rapier 接触最大差约 0.000223 m。
- 从 Git 临时构造 `f521510` 基线：所有可见 position、color 和全部碰撞 vertices、indices 一致；其他六块地形的 normal、nightRadiance 一致；岩床、陡面和封底的 normal、nightRadiance 一致。仅北岩肩缓坡角点法线改变，共 2,968 个角点有数值变化，其中包含小于 0.01 的变化。临时源码已删除。
- 真实合批断言通过：远档含三车 137,416 面、近档含三车 215,704 面，均不变；远档 140,000 上限剩 2,584 面。地形 24,546 面、接触数组 444,348 B、远／近描述符 746／1,080，均不变。
- `git diff --check` 通过。由于位置和接触数据全部一致，本轮没有重复运行植被全套或完整地形距离扫描。
