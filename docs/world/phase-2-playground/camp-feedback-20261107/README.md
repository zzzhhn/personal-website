# 营地反馈迭代，2026-11-07

基线 `d1c24a30e22a1a4a7bb61c06d8500e6e47ed1717`。沿用已认可的营地美术，补布料运动、物件操作、局部材质照明平衡及遗漏的音乐交接。三个 GPT 6.1 Sol / high 协作，主会话负责角色控制器接口、材质、实际试玩和整合。

## 改动

- **旗布：** 原 C10 每面 19 列布面顶点已足够。固定旗根，叠加传播波、阵风和旗尾轻颤；GPU 表面与阴影同形，法线按变形梯度修正。语言互动仍可抬旗，但沿布身弯曲，不再带着旗根整片旋转。共享风时钟随世界暂停。
- **可操作物件：** 工具取用／归位、哑铃取用／举起／放下、行李箱地面牵引／放手、书本翻页。保留原个人信息入口。操作通过既有 E／Y 与邻近选项选择，不新添覆盖场景的控制面板。
- **接触与退出：** 角色层做右手接触和低位屈膝，物件在掌心接近后才离位。行李箱保持动态刚体与碰撞。退出、走远、切换场景、回营地和暂停都释放操作，原物件复位机制保留。
- **发灰校准：** 晴天营地距离远小于雾起点 350m。精修材质同时获得现有半球补光和 PMREM 漫反射，本轮只减弱日间后者，保留 PMREM 高光、金属反射、原纹理和色彩空间；夜间恢复原环境光强度。`campSurface=legacy` 可同构建对照。没有全局增饱和、改曝光或用后期滤镜。
- **BGM：** 接入此前停留在音乐 session 交接目录的《栈道晨光 v2》，详见 [来源、许可与替换证据](music-recovery.md)。保留完整自然收尾后重复，不声称无缝循环，也不将旧方向批准当作最终听感认可。

### 性能边界

`performance-after.json` 与 `performance-legacy-surface.json` 的相机、2013 × 1030 画布、DPR 1.1772、FOV 50 和曝光 1 一致；各采集 360 帧。新版 P50 16.9 ms、P95 32.5 ms，旧材质分支 P50 20.9 ms、P95 48.7 ms。两者均为 335 draw calls、1,057,278 triangles。

这是局部材质分支对比，不是全部新互动对旧版的性能结论。两次采样加载过的区域不同，几何／纹理驻留量也不同，机器内存处于警告状态，因此不将帧时间差解释为性能提升，也不声称全岛无回退。重构建与 3D 试玩串行进行，没有新增浏览器实例。

最终行李箱修复后的独立 360 帧复测见 `performance-final.json`：P50 21.8 ms、P95 37.7 ms、最大 209.4 ms，339 draw calls、1,060,384 triangles。此前移动过的行李箱仍处于新位置。该轮依然存在长帧，不能记作稳定 60 FPS；未观察到新增控制台错误。最终资源预检为内存警告、约 13.6 GiB 历史 swap、11.65 GiB 可用磁盘。
