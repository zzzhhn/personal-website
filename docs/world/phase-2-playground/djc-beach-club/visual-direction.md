# DJC beach club visual direction

2026-10-27: Bobby rejected `concept-20261027.png` as visually incompatible with the existing game. It is a rejected draft, not a modeling target. The approved general development scope remains a medium-to-large beach club extending the main island, with two or three dance styles and visual quality taking priority over extra mechanics.

The revised target is FINNS-inspired Balinese beach-club architecture, translated into the existing game's visible faceted forms, restrained materials, white spherical helmet characters, muted island palette and simplified vegetation. Do not use photoreal resort materials or the rejected linen tent / stone amphitheatre direction.

`concept-v2-20261027.png` was generated with the native imagegen tool, using Bobby's actual game screenshot as the primary style reference and an official FINNS photograph only for spatial reference. It is a proposed visual target, not an in-game capture or user aesthetic acceptance.

Key forms: broad curved thatch roof on exposed bamboo arches; open pavilion containing DJ booth, disco ball and dance floor; sea-facing pool terrace with turquoise daybeds; palms and an open beach horizon. Two broad exits and a legible return route stay part of the design. Pool presence should not silently expand this milestone into a swimming simulation.
