# DJC beach club：本轮实现与证据

## 方向

Bobby 否决第一张偏写实度假酒店的示意图后，本轮改为 FINNS 竹拱建筑的空间参考，加上现有世界的切面造型、克制材质与白头盔角色。`concept-v2-20261027.png` 是原生生成的修订参考图，尚不等于用户审美验收；第一张图是弃稿。保持两个舞步，不增加复杂比赛、经营或游泳系统。

## 实现

- 主岛东南岸增加自然陆地，地面、碰撞、海水边界与地图共用同一形状；保留原有桥下水道和海湾。
- 竹拱茅草大厅、双 Deck 台、镜球、木舞池、浅水泳池、青色圆形 daybed、小吧台与随风移动的棕榈。约 32,776 个视觉三角形，9 个静态 draw、2 个动态 draw，2 盏不投影的局部灯；这些是资产预算，不是全世界渲染成本。
- 屋顶上下壳、封边和主竹构有同源碰撞。Club 不使用视线挖洞淡出，相机依靠实际碰撞退让。泳池使用可见池底与南北坡道。
- E 加入舞池，1／2 切换 Groove／Twist，WASD 离开，E／Esc 停下。舞步改编自 CMU 60_01 和 141_12；细节见角色文档，未声称原始捕捉就是 Disco。
- DJ 台：两轨播放／暂停、Cue、横推子、滤波和音量。曲目使用本地 DJC 已有素材，不加载完整 DJC 引擎；BPM 来自原素材命名，不声称已做自动对拍或精确 downbeat 检测。旧小屋的台子改为前往 Club 的地图引导。
- 音频仅在玩家操作后加载，单 AudioContext、最多两个 BufferSource，无调度 timer／worker／analyser；远离、暂停、后台或静音停止 source，卸载释放 buffer 与 context。两名环境舞客不挂玩家控制器，48m 外隐藏并停止骨架更新，18m 外降低更新频率。

## 验证

2026-10-27，Chrome 同一既有标签，流畅画质，单个候选服务：

- 从正式入口 `[30,1,39]` 实际步行上坡到 DJ 平台，E 接管，启动第二 Deck，横推子设为 0.5、滤波设为 0.6。DJ 状态下 W 不移动，Esc 正常退出。
- 舞池 E 启动，1／2 切换和 WASD 离开通过；可见动作读数为 ClubDisco，身体 grounded，渲染根位置约 `[41,1.6005,55]`。
- 从舞池走到北露台 `[56.46,2.18,46.16]`，走入浅水中心附近 `[56.53,1.82,53.87]`，再沿坡道走出 `[56.53,2.18,45.64]`。这是初始自然池底的现场读数；随后加了 1.015m 的可见矿物色衬底，坡道测试按同源几何重新通过。
- 午后、黄昏和深夜现场画面检查；海侧字牌方向、薄屋顶和相机穿顶问题经现场发现后修正。仍需 Bobby 对修订审美作最终评价。
- 音频可见 QA：播放时 1 个 context、1 或 2 个 source、2 个 buffer、46,092,528 bytes、0 timers；暂停后 context suspended、sources 0。
- 单次舞池渲染快照：91 calls、217,326 triangles、273 geometries、66 textures，当前 frame delta 16.8ms。这不是持续 FPS 基准或所有机器的性能保证。
- 24 项几何／地形／音频生命周期／交互注册／回营地检查通过；G24 两个舞步的实际靴底接触、循环、骨长和退出混合测试通过；受影响世界模块 TypeScript 检查通过。

机器磁盘约 11 GiB，内存曾处于警告状态。重用已有 Chrome 标签，重型任务串行；一次加载中的浏览器输入超时后恢复，未新增浏览器实例。开发服务在打包前停止。完整构建通过，4342 使用打包版本；`quality=balanced&paused=1` 现也在打包预览中生效，便于低负载进入。

## 范围边界

本轮是可体验的第一版 Club。泳池为浅水，可步行进出；daybed 是场景家具，尚无新躺卧动画。DJ 的手臂操台动作、更多舞步、自动对拍和完整 DJC 工作站不在本轮。未把 FINNS 品牌或其摄影作为网站运行素材。

音频来源：`Artifacts/djc/public/demo/disco_118_v2.mp3` 与 `Artifacts/djc/scripts/out_v2/house_124.mp3`，以原字节复制；来源 DJC 项目记录为生成素材，未引入外部商业歌曲。
