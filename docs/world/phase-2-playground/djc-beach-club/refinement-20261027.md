# DJC 场地与实体细化

2026-10-27。基线 `d5224e3`。当前候选参考为 `concept-v3-finns-20261027.png`，保持现有风格化世界的暖竹木、低面植被和克制材质。下文保留从 V2 到 V3 的实现与验证过程；旧的写实酒店概念为弃稿，V2 不是当前设计依据。原生概念图仍须与实际游戏画面分别评价。

## 已实现

- 海岬保留与主岛的同一高度场，轮廓改为不等幅的湾、岬与肩部变化。地图继续从实际地形三角提取水线，没有另画规则 Club 陆地块。
- 舞池、舞台和控制台坐标不动。池中心改为 `[60,1.35,55]`，尺度约为原来的两倍，边界由 96 点不规则轮廓定义。水面无碰撞。
- 统一地形局部形成浅盆，其上为可见且可走的矿物池底。池底高程为 `0.55..1.0` 米，水深为 `0.35..0.8` 米；由浅边、较深中央和西侧缓浅台面形成层次。地形在可见衬底下留 3.5 厘米余量，避免草地穿出。
- 池畔铺地沿水面轮廓展开，外缘斜接自然地面；两条不规则扇形木步道从舞池北、南侧绕到池边。两个约 3.5 米宽的缓坡入口穿过池缘，不用隐形墙封池。
- 四座圆形 daybed 共八个座面锚点，补真实床垫支持面、靠背、床边桌、框架灯笼和水下实体基座。另有水下坐沿、池边灯笼、竹吧台前板和可碰撞的凳、遮阳伞。
- 主要竹结构与屋顶闭壳继续使用同源碰撞。六棵棕榈的整段树干均有实际碰撞，所有根部避开铺地并采样真实地形高程，避免海滩上的树浮起。软叶片与八组地面植物则随全局风摆动，并读取已有 `ActorTracker.actorState` 中最多四个接近的身体，按根部权重向外弯折；没有第二套追踪器、计时器或 RAF。
- 棕榈叶片投射世界已有太阳阴影，阴影深度材质采用与可见面相同的风和接触位移。没有新增动态灯。

## 水体接入

共享布局为 `src/components/world/djc-club-layout.ts`：

```ts
CLUB_POOL.waterY: number
CLUB_POOL.contains(x: number, z: number): boolean
CLUB_POOL.floorHeight(x: number, z: number): number
CLUB_POOL.distance(x: number, z: number): number
CLUB_POOL.boundary(angle: number, outset?: number): [number, number]
CLUB_POOL.outline: [number, number][]
```

`buildDjcClubGeometry().pool` 是世界坐标、向上绕序、96 个三角形的水面扇形。其 `userData` 含 `shape: 'djc-pool'`、`waterY` 和 `outline`。它只有视觉水面，支持面位于池底。

`WorldDjcClubVisual` 已消费主线的 `createClubPoolWaterMaterial()`，每帧只写其 `uniforms.uNight`。透明度、Fresnel、反光与共享涟漪由主线水体实现负责。

## 接触遗漏修正与池底反馈

后续审计发现八个座面锚点尚未注册，且原锚点高于坐垫 3.5 厘米、朝向与靠背不符。本次将坐垫中心／厚度与座面高度共用为 `DJC_DAYBED_PAD`／`DJC_DAYBED_TOP`，实际接触高度为 1.755 米。

`WorldDjcClub` 现逐个注册八个稳定 `kind: 'seat'` 交互，使用既有 `store.seat`、SitDown／SitIdle／StandUp 和 E／移动／跳跃起身流程。坐点在垫子前缘，朝向为 `π/2`，腿朝世界负 Z 方向垂出；没有新增躺卧动作。每床补一个 1.2 米宽、约 3.1 米长的中央接近坡道，坐点分居两侧，边桌移至侧后方避免挡路。

可坐条件要求玩家从前方、在接近垫面高度处进入。候选检测和实际按键都重新检查同一条完整胶囊通路；水中低处、床后方、远处或被新障碍挡住时不能隔空坐下。卸载时注销交互，并只清除属于 Club 的坐下状态。原 `clubAudio.tick()` 和主线 `createClubPoolWaterMaterial()` 接入保持不变。

镜球使用共用 `DJC_MIRROR_RADIUS = 0.66`，新增一个固定 `BallCollider`，带 `solid`、`assetId: 'djc-mirror-ball'` 与相机识别标记。球形外包络不随表面旋转而改变，无每帧物理重建。

主线实机确认的池底放射状棋盘问题也已修正：矿物池底统一为低对比浅灰青，不再按径向分片交替明显颜色。池底高度、出口和水面接口未改，水层折光／深色对比继续由主线水工厂负责。

本次 15 项几何／交互检查和目标 TypeScript 检查通过，包含八座注册与注销、坐垫接触高度、前坡连续支持、实时障碍拒绝、每座起身搜索范围内存在实际支持与净空，以及生产相机 sweep 被镜球挡住。交互测试只隔离了无关渲染资产，使用真实注册代码、状态与 Rapier；没有代替浏览器挂载或动作视觉验收。

更新后模型 40,646 三角形，`surface` 3,490、`solid` 13,488 三角形，另有一个镜球解析球碰撞。绘制批次和点灯数量不增加。

## 实机阻断后的动态回归修正

主线在第二床 `[64,61.7]` 附近记录到玩家走至 `[64.41,2.54,60.15]` 后失去 grounded 并滑落。前一批测试只验证静态支撑线和净空，确实未覆盖动态上坡后制动。

使用真实 Club trimesh、生产 `playerSupport`、`followPlayerGround`、`sweptPlayerVelocity` 和 `playerVelocityChange`，按实际胶囊尺寸、72 千克质量、零摩擦、12.5 米／秒²重力、CCD 和阻尼复现：抵达 `[64.492,2.533,60.158]`，停四秒后滑至 `[65.073,1.369,59.490]`。确认了局部坡道缺少平坦站立区、侧缘净宽不足；另一个独立问题是旧坐下 shape sweep 将胶囊静止时约 1 毫米的地面接触皮肤误判为障碍。

本次只修局部几何与交互：

- 通路加宽到 1.6 米，总长约 4.35 米；下端与坡顶分别平滑过渡，顶部补约 1 米长的真实水平落脚台，与坐垫同高。整个通路是连续顶面与外侧封边，没有每段内部竖直碰撞面。
- 第一床越过池缘处以最高真实支撑起坡，避免把池缘与池底的高度平均后留下跌落接缝。
- 坐点同步为床中心 `x±0.95,z-0.85`，保留 1.755 米高度、向负 Z 的朝向及两侧腿部位置。可坐的横向门限按真实平台宽度计算。
- 必须有真实 `playerSupport.grounded`。坐下通路复用生产 `playerRouteClear` 的 12 毫米查询抬升及障碍检查，既不把地面皮肤当墙，也不穿过后插入的墙体。没有修改全局角色物理。

新增动态回归覆盖四张床、左右各 0.41 米偏移的八条路线，从池底或池畔真实地面起步，按正常走路输入、加速度、清障查询和地面跟随连续上坡。每条路线都实际制动、静止三秒，保持 grounded，并通过真实注册表的距离／视线筛选，实际调用座位交互进入 `store.seat`。八次静止期间最大额外位移为 0.000467 米。

第二床右侧轨迹修复后抵达 `[64.442,2.575,60.183]`，制动停在 `[64.443,2.574,60.438]`，随后三秒漂移约 0.0000014 米。16 项定向测试及目标 TypeScript 检查通过。更新后的主体为 40,982 三角形，`surface` 3,602、`solid` 13,712，绘制批次与灯数量不变。

以上是生产函数驱动的动态物理回归，未开启浏览器；主线仍负责确认真实输入／相机下的提示和动作观感。

## FINNS V3 局部结构细节补充

本轮只修改几何及几何测试，参照 V3 与 `qa-20261027/club-pool-afternoon.png` 中已确认的差距，未改布局、Visual、水材质、灯、交互注册或已验证的通路参数。

池畔两圈铺地改为世界坐标固定 1.8 × 1.25 米的错缝石板，缝宽约 2.4 厘米，石板仅用三个接近的暖灰色。各石板和缝隙直接裁切原三角面，并插值得到原平面高度；它们互不叠加，没有抬高、polygonOffset 或遮盖原面的贴片。移除了按径向扇区交替的强色差。池底统一矿物色和池缘缓坡保持不变。铺地面积回归确认细分前后完整覆盖，所有新增支撑面仍是对应可见三角形。

屋顶保留原壳体与相机碰撞，茅草层边由三条细带补成八条较宽的曲面层边，海侧与背侧的弧形檐口增加连续圆竹收边。新增收边略超原屋壳，因此使用同源 solid 三角形。竹节由原先全局竖直的短圆柱改成沿每段竹杆切线的环节；三杆拱架补十二组双圈纤维绑接，绑接留在原束杆包络内，没有地面新障碍。

四张日床上缘改为真实厚木框，替换原石座同一包络的上层；靠背分成三块圆角软垫，圆形主垫补细滚边，框边补少量内嵌端木。主垫半径、座面高度、八个坐点、中央坡道及平台边界均未改动。没有增加植物、材质种类或绘制批次。

## 热带软植被层次候选

## 木接驳与池畔石板闪纹修正
