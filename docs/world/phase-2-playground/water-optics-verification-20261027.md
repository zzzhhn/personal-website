# Club 泳池光学样板验证

2026-10-27。本轮交付是 Club 泳池样板，海洋与矿区回测池仍沿用此前水面。视觉是否达到用户预期，留待实际体验；本记录区分实现、测试、浏览器观察和性能采样。

## 实现与范围

- 新增 `WorldClubWater.tsx`、`WorldClubWaterCapture.ts`、`WorldClubWaterShader.ts`，接入 `WorldDjcClubVisual.tsx` 的既有泳池几何。没有改泳池碰撞、入口或水深。
- 对 Club 与人物做局部颜色／深度采集，用水下深度决定吸收、透射与折射；采用 Fresnel 混合局部建筑倒影和天空。人物浸水部分也进入透射采集。
- 使用本仓库已安装 Three.js 的 `Reflector` 做反射相机裁剪，未增加依赖或下载新资产。研究来源见 [水面调研](water-research-20261027.md)。
- 以同一组波纹法线将光线投向实际池底，形成动态焦散亮纹。池底浅缝用于提供深度和折射参照；亮纹通过池底石材受光，不覆盖岛上其他地面。
- 保留已有角色入水／移动接触波纹。未实现完整流体求解、任意物体受焦散、独立雨滴激波或完整水下观察模式。夜间焦散用近似局部入射方向，并非逐灯光追。
- `WorldPlaytestReadout.tsx` 仅增加 DEV 对照与采样按钮，正式试玩页不显示这些控件。

## 性能约束

- 平衡画质：折射颜色与深度最多 768 像素宽，反射 384 × 384，焦散 256 × 256。高清上限分别为 1024 像素宽、512 × 512 和 256 × 256。
- 平衡画质的折射／焦散最多 20 Hz，反射最多 10 Hz；高清分别为 30 Hz 与 20 Hz。摄像机在暂停期间发生变化时允许一次修正。
- 仅水面可见且相机距泳池 80 米内时采集。排除全岛、海面、草地，禁止递归采集与额外阴影更新；复用目标纹理并在卸载时释放。
- 暂停前后采样计数均为：captures 1208、reflections 605、caustics 1208。截图及 JSON 见 [证据目录](qa-water-optics-20261027/)。

## 验证结果

1. 水面采集状态、异常恢复、分辨率预算、暂停与交互、Club 几何、座位、地形共 **35／35 项通过**。目标 TypeScript 检查通过。`git diff --check` 通过。
2. Astro production build 成功。有既有大块打包提示，没有构建错误。
3. 在复用的 Chrome 页面验证了白天池底／人物折射、夜间建筑／灯光倒影、雨天正常显示。控制台未读取到错误。
4. 真实按键入水后，角色位置约 `[56.68, 1.65, 52.33]`；连续走出后到达岸上草地 `[45.03, 1.82, 64.05]`，`grounded: true`。这项出水证据没有使用传送代替。
5. 正式构建从 Club 入口实际走到池边并进入浅水，最终画面保存在 `pool-production-4341.png`。沿吧台与舞台侧边的低台边缘仍需跳过一次，未把这条路线描述成全部无障碍；本次未改变该处碰撞。
6. 极低镜头可以进入水面下方，当前会使用简化回退效果，不等于完整水下渲染已完成。

同一开发版镜头、流畅画质、2013 × 1030 绘图缓冲、180 帧样本：
