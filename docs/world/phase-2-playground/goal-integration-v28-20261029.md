# v28：国投场内混凝土地面

旧地面按网格交替使用两种颜色，产生了明显的大棋盘格，与仓库、工作台和车辆的尺度不协调。本轮保留已经批准的工业园布局和配色方向，把铺地改为较统一的浇筑混凝土，增加错缝分仓、细伸缩缝、轻微色差、骨料与表面法线细节。没有更换高分辨率贴图，也没有增加贴图下载。

处理只作用于铺地朝上的完整三角形，设备、墙面、地台侧面和活动零件不受影响。细颗粒和接缝按像素覆盖范围衰减，降低远处闪烁风险。复用合并材质的现有标记通道，不新增绘制批次、灯光、定时器或逐帧 JavaScript 工作；片元着色计算有所增加，不据此声称 GPU 成本为零。
