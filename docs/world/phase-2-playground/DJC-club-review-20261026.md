# DJC 海边 Club：方案确认稿

2026-10-26 · v0.2 · 待 Bobby 确认。仅设计文档，不授权或启动场景开发。

## 当前状态与依据

此前只有[露天 Club 概念](README.md#1djc--合拍落日露天-club)，没有独立 Club PRD、确定选址、最终美术参考、音乐包或舞蹈资产。当前园区 DJ 台仍使用 `WorldParkAudio.ts` 的两组程序合成循环，不能算完整 DJC Club。

本稿保留 Bobby 指定的露天 Club、舞池、Disco Ball 和角色蹦迪。结合[后续场所方案](play-atlas-proposals-20261026.md)，本场所以 DJC 为主体，合拍保留独立项目身份与后续体验空间。本稿新增的布局、动作与现场互动均为提案，尚未实现、未验证趣味性。

真实项目联系以 [DJC 项目内容](../../../src/content/projects/djc.mdx) 的双 Deck、唱盘、混音、同步与音效能力为依据。进入开发前还须检查 DJC 当前工程，不能将项目描述当作已完成复用。

## 一句话体验

**一座能下场跳舞、能上台接歌、也能坐在海边听完整段音乐的 Club。玩家可以亲手改变正在发生的派对。**

建议以自由游玩为主。入场不考核节拍、不要求先学 DJ、不强制参加活动；想认真操控的人可以上台。第一轮希望玩家愿意停留约 3～5 分钟，离开时记得自己跳过、接过歌、让现场发生过一次变化。

## 空间与美术

推荐方向是旧海岸仓库旁改造出来的露天 Club。保留世界已有的暖色石材、木材、植被和海岸环境，用有磨损的金属、线缆、设备和布篷增加真实感。Club 的识别点来自空间、音乐和镜球，不依赖满屏霓虹。

| 区域 | 玩家能做什么 | 建模与空间重点 |
| --- | --- | --- |
| 入口小径与停车侧 | 从海岸路步行或下车进入，第一次主动打开音乐 | 植被与坡地自然过渡，招牌、入口帆布、停车和行人路线分开。 |
| 朝海开放的中央舞池 | 进入、跳舞、换舞步、邀请旁边舞客回应 | 曲线边界，浅高差和宽坡道；舞池与周围坐阶连续，不切出突兀方形地块。 |
| 靠陆侧略高的 DJ 台 | 从侧坡上台，拿唱片、上盘、混音 | 双 Deck、转盘、推子、旋钮、耳机、监听音箱与真实支架；设备是近看重点。 |
| 镜球与灯架 | 玩家触发一次镜球降下、碎光聚拢的现场变化 | 镜片分块、吊索与支撑有结构，灯具方向有依据；默认不高频频闪。 |
| 侧边吧台与坐阶 | 坐下听、看别人跳，也可绕到台侧 | 吧台、软垫、杯具、工具、唱片箱，细节服务于“有人使用过”。首版不做点单经营。 |
| 看海露台 | 离开舞池后仍能听到变远的音乐，放松或拍照 | 声音与光线随空间变化，留出宽出口、栏杆和清楚的返回路线。 |

概念上的低位舞池通过周围坐阶与平台组织，不预先决定挖穿岛屿。精确地块、尺寸和坐标需在最新地图上比较，确认不挤占已有道路与场所后再定。

白天是可以停留的海边空间，黄昏开始有暖灯，夜晚由灯架、镜球与舞池形成层次。玩家选择的全局时间照常生效，进 Club 不强制切夜。DJ 台和一部分休息区有遮雨棚，雨雪状态下仍有可用路线和可读设备。

## 三件真正可玩的事

### 1．下场蹦迪

靠近舞池出现简短的「加入舞池」交互，主动加入后进入跳舞状态。舞步可切换，角色能转身、移动换位，随时走开；不靠进区就自动接管角色。

首版目标是 3～4 组有区别、质量合格的舞蹈，以及进入、切换、停下的连续动作。舞步数量可由动作质量决定，不能靠一套摆手动画加速／减速凑数。重点检查脚落在地面、重心换腿、转身不打滑、不同节拍下动作不抽动。

舞池有一小组预设 NPC，站位、动作和相位适当错开。玩家做一个招呼或标志舞步，邻近舞客可以回应，形成短暂的舞圈。它们是场景角色，不宣称真人在线，也不展示虚构人气。首版人数在性能样板后确定。

### 2．上台接一首歌

从唱片箱挑一张实体唱片 → 拿到空闲 Deck → 听候选片段 → 启动下一首 → 推动 crossfader，听见两首歌真正交接 → 离开 DJ 台，回舞池听自己接出的音乐。

新手可选择辅助对拍，但转场由玩家完成；关掉辅助后可自行尝试。首版保留少量有辨识度的动作：播放／Cue、crossfader、滤波，以及一次可听见的 backspin 或短 loop。具体音效从实际 DJC 可复用部分选择，不承诺把整个工作台搬入场景。

近距离操控时镜头靠近设备，唱盘与推子本身反馈状态，必要提示放在设备附近。离开台面立即恢复行走输入；跳舞、驾驶和 DJ 按键不可互相穿透。高级操作仍可从台侧打开完整 DJC 产品。

### 3．把现场点亮一次

舞池边的绳铃可以触发一段短场景变化：镜球降到安全高度，光斑从边缘聚向舞池；在音乐下一个合适乐句，镜球重新升起、场内光线展开，舞客共同做一次抬手回应。

这是玩家能主动导演的一个小瞬间。声音、舞步与灯光依实际播放的节拍／乐句对齐；不强行给没有 Drop 的曲目编造 Drop，也不以任意倒计时冒充音乐分析。音乐停止时装置仍可缓慢复位，避免状态卡死。

建议先做这一项有记忆点的环境互动，优先把质感和连续性做好。自由游玩首版不加入积分、强制通关、货币、解锁树或排行榜。

## 首版范围与验收

首版交付一个完整 Club，包括可连续进出的场地、舞池、DJ 台、镜球装置、可坐的休息区、一小组 NPC，以及少量能形成完整转场的音乐。音乐从 3 首不同情绪、可实际混合的曲目起步，最终数量由质量与资源验证决定。

| 观察点 | 达标才进入下一批 |
| --- | --- |
| 动作 | 背面与侧面观察跳舞、切换、停下，无明显滑步、浮空和周期性抽动；坐下沿用本轮已修复行为。 |
| 音乐 | crossfader、滤波及所选特色操作真实改变音频；可以完成一次听得清的双曲转场。 |
| 场景 | 近看设备有结构，中景舞池有层次，远景与海岸连起来；白天和夜晚都成立。 |
| 可玩性 | 不读长说明能加入舞池、上台接歌并离开；短体验后能说出自己改变了什么。 |
| 安全退出 | DJ 台、坐阶与栏杆转角无卡死；舞蹈和设备状态可随时退出；保留回营地。 |
| 资源 | 同机同设置对比进场前、场内、离场、暂停及重复进入；不接受音频节点、Worker 或内存随进出持续累积。 |

本轮不纳入多人联机、整套专业 DJ 面板、浏览器内实时 Stem 分离、整曲后台分析、录屏导出和强制节奏闯关。以后有需要可单独评估。

## 音频、时间天气与性能约束

- 音乐由明确用户手势开启，有可见静音和音量控制。离场渐弱，远处停止不必要的播放和调度；暂停、后台、卸载沿用现有资源清理规则。
- 舞步、灯光和设备动画共享实际音频时间基准。曲目节拍信息优先预处理，不在游玩主线程持续分析，也不给每位 NPC 单独开音频或计时器。
- 首版精选曲目与舞蹈逐项核对来源及展示权限。允许使用自有或获准素材，但现有程序 loop 只可用于内部验证，不能作为最终音乐质感的完成证据。
- 近处保留细节，远处降低 NPC 更新、舞步与灯光开销。镜球光斑优先采用有界、可控的表现，不让每块镜片产生一盏动态阴影灯。
- 雨雪、时间变化和海面继续服从全局系统。对遮雨、反光与夜间可读性做实际观察，不额外启动一套天气模拟。

## 确认后的协作顺序

1. **设计与美术**：基于本稿做统一风格的整体概念图、DJ 台近景与夜间舞池图，并给出地块比较。原生生图用于对照目标，概念图不能当作实际效果验收。
2. **先完成一段样板**：一小段最终质量舞池、镜球、角色舞蹈和真实音乐，验证“愿不愿意多待一会儿”。不先铺满场地再补质量。
3. **分线制作**：人物线负责舞蹈与操控衔接；音频线负责精简双 Deck 与生命周期；美术线按结构、核心设备、环境细节分批制作；性能线检查每批资源成本。
4. **主线集成**：连通地图、车辆下车、时间天气、输入、退出与回营地，实测后才更新试玩页。各线使用共同基线与明确文件所有权。

可给各 session 的自然语言提示：

- 人物：「让这个角色真的能在 Club 里跳起来，重点是落脚、换重心、舞步切换和随时走开，不要靠摆手循环凑热闹。」
- 音频：「把 DJC 最有手感的少量操作带进真实 DJ 台，让玩家接出一段听得见的转场，同时保证离场和暂停后电脑能安静下来。」
- 美术：「做一座有海风、有设备使用痕迹、日夜都值得停留的露天 Club。先把舞池、DJ 台和镜球做到让人想靠近，再扩充细节。」

## 本次需要确认的选择

建议主方案为：**海边露天 Club，自由蹦迪与上台接歌并重，小规模 NPC 气氛，音乐偏适合日落至夜间的 House／Disco／Groove。** 音乐类型是本稿建议，并非已知的 Bobby 个人偏好。

请优先反馈这三件事：整体气质是否对、自由跳舞与亲手接歌的比重是否对、希望用什么音乐让这个 Club 有自己的性格。正式开发等待 Bobby 确认，本稿未冻结曲目、选址与机制参数。

## 10 principles re-check

| 原则 | 对应设计 |
| --- | --- |
| 意图对齐 | 场地可自由游玩，主动加入舞池或上台操作。 |
| 降低认知负担 | 每个区域只有一类主要玩法，DJ 首版保留少量核心控件。 |
| 状态可见 | 设备、声音和舞步共同显示当前播放及动作状态。 |
| 容错 | 随时退回自由行走，接歌失误不扣命、不锁进度。 |
| 可操作暗示 | 手能接近的唱盘与推子确实影响声音，装饰与控件区分。 |
| 界面退后 | 复用附近交互提示，详细项目入口留在台侧。 |
| 无需手册 | 入场后通过现场提示完成跳舞、接歌与离开。 |
| 尊重时间 | 无强制教程和等待解锁，动作开始即有可见反馈。 |
| 无暗模式 | 不自动开声，不将 NPC 展示成真实在线用户。 |
| 清晰主操作 | 跳舞、设备操控、自由行走按情境显示当前主要动作。 |

## Cross-cutting conventions audit

| 项目 | 约定 |
| --- | --- |
| i18n | 玩家提示与帮助沿用 `world-i18n.ts` 中英双语，曲名保留原名。 |
| 字体 | 沿用 world 字体及键位样式；品牌设备铭牌仅作有意的场景差异。 |
| 布局 | 复用 `WorldCards` 附近提示、地图设置和回营地入口；设备局部 UI 另做小样。 |
| 侧栏导航 | 场景从岛上进入，项目目录仍可直接找到 DJC，无通关门槛。 |
| 本地化数据 | 曲目 BPM、节拍、曲名来自实际音乐元数据，不虚构匹配评分。 |
