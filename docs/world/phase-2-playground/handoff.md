## 给其他工作线的信息

- 人物线：Club 可能需要舞步和 Pose，矿脉可能需要持物、探测、挥镐与投石。这些是待协调的动作需求，本轮不要求改变当前动作链。
- 驾驶线：场所希望能自然停车、下车、再自由离开；没有新增漂移门槛、任务用车或道路修改。
- 美术线：下沉舞池与 Disco Ball、分层岩台与矿线、池底时间轴是可讨论的空间意象；没有指定模型、尺寸、材质或地块，不覆盖当前美术决策。
- 回声栈桥依赖短动作回放，风筝依赖绳线与风反馈，都可能带来独立成本；它们不是近期必做项。Club 和矿道同样需要经过小样才能判断是否好玩。
- 当前 `WorldParkAudio.ts` 是两组程序合成循环并在启动后全岛播放。Club 所提曲目、选曲、分区衰减和节拍互动尚未接入，不能把现有音频演示当成完整 DJC／合拍集成。
- 项目事实继续从现有双语内容源读取。项目与经历入口保持可直接访问，不要求通关；尚无合适独立玩法的 EvalForge 等项目无需勉强新建场所。

## 取舍与下一步

五个角度分别是表达、搜寻、物理试验、时序配合和自由玩耍。Club 与矿脉的优先级来自 Bobby 的明确灵感和相互补充的节奏，不代表其机制已定稿。

Bobby 可继续补充 Club 的现场气氛、矿中更想做的动作，以及三个新画面里最有吸引力的一个。收到补充后再收敛到一个小样；本轮不启动开发。

真实回测仍需主 session 确定可公开数据与因子、结果模式和服务边界。历史包可以让投池先有真实证据，但不能支持不匹配的新组合。网站 Alpha Agent 与经历中的 BRAIN 链路不能未经核验混用。
