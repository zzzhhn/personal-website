# IBD 钢卷作业区精修 · 2026-11-06

## 范围与来源

基线为 `0a2fe297ef9c8886a8ff0a0286f691a9d247da85`。沿用已批准的三棚工业场地，不改变盘点流程、任务坐标、货物运动轨迹或碰撞壳体。

本轮精修两个可交互钢卷、三件背景钢卷、两座桥式起重机横梁，以及钢卷随动承托。厂房和移动设备复用 renderer 已有的环境反射图；不增加实时反射场景。

## 构造与材质

- 主体：真正开口的钢卷内孔、桶身冠形与回折卷边，窄幅张紧绑带与扣件。
- 构造：承托采用桶身切线楔面，保留 2 mm 名义余量；压脚、六角螺栓、底架横撑和车轮轴。横梁补全腹板加劲肋与支承螺栓，两座梁使用同一家族。
- 表面：钢卷端面紧密卷层、轧制方向与粗糙度差异、木托纵向纹理。密集纹理按屏幕导数过滤，避免用共面圆环叠层。
- 加工坐标使用已有 `aSuv`，私有负 `aMat.w` 区分端面、桶身和木托，不占用地面或标牌的正值编码。

## 实际渲染链路

`addWoundCoil → buildIbdCoil → WorldIbdMechanisms` 与 `buildIbdStores → buildIbdStatic → WorldIbdYard` 生成实际游戏网格；`createIbdMaterial → applyCoilBayMaterial` 保留原先的地面、夜间照明和厂房角色，新增 mill shader 负责钢材反应。原生可编辑源就是这些参数化 TypeScript 构造器，本轮没有把离线 Blender 渲染冒充游戏效果。

`useDjcFurnitureEnvironment` 借用 renderer 共享的 256×128 环境源及 PMREM；组件不拥有其纹理，卸载仅释放借用引用。昼夜强度随原有共享时钟变化。

## 复核发现与修正

独立只读审阅发现初稿楔面仍相交约 1 cm，及 atan2 桶身 UV 分支切口。已改为数学切线与连续平面投影；真实几何 raycast 和每三角形坐标连续性测试验证这两点。
