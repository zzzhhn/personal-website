# 水面运动与方向尾流，2026-10-27

用户反馈水面主要是一圈圈荡漾。本轮重点改 Club 泳池和各水体共用的接触扰动，保留海面已有的 Gerstner 浪涌，不恢复场景倒影。

- 泳池使用四个方向／尺度不同的波包，按有限水深色散关系计算速度，波群包络和波峰以不同速度传播。高度与法线使用同一解析场。方法参考 [GPU Gems 的方向波叠加与法线推导](https://developer.nvidia.com/gpugems/gpugems/part-i-natural-effects/chapter-1-effective-water-simulation-physical-models)。
- 9.3／6.1 米长波推动实际水面网格，2.2／0.75 米短波只用于法线，避免稀疏网格采样短波时闪烁。泳池网格从 96 增至 2016 个三角形，Club 验证总量为 67881，仍低于原有 68000 上限，表面 draw 数不变。
- 人物／车辆移动记录水平方向，生成后方两束逐渐扩散、衰减的尾流；转弯后的扰动随新方向变化。落水／投物仍有短暂向外传播的冲击，减弱原来的高亮圆环。站立不重复发射。
- 保留固定 8 个接触槽位、原有暂停时钟、两张离屏目标及捕获预算。没有新 Worker、定时器或渲染通道；未假定增加的波形计算免费。
