## 脚部根因与实现

实际 GLTFLoader 加载的 Run／Sprint 脚部参考坐标相对靴子绑定轴有固定侧向偏差，Walk 已有不同的参考校准。`WorldGuideBoots.ts` 在加载时使用真实细化后的靴子顶点，分离前后摆动与侧向参考偏差，重建接地支点和双骨 IK。腿长不变，不添加脚或小腿局部平移。校准后的 actions、相位、鞋底探测和接触数据共用同一组 clips。

只在加载时计算一次；人物 session 测得约 18 ms，不新增每帧校准。保留 3 mm 屈膝余量后，Run 固定骨盆下降 18.6 mm，Sprint 下降 13.8 mm。对未知骨架或超出 35 mm 校准预算的素材保留原动作。

真实资产每周期 528 个相位的回归结果：

| Run 左／右支撑期侧向偏差 | 24.31°／22.43° | 1.44°／1.42° |

## 时间、天气与性能边界

`NightClock` 是统一时钟，复用现有 useFrame；界面只在整数分钟变化时发布状态。灯光、天空、海面与各区域灯具读取同一个连续采样结果。手动切换使用约两秒的有界过渡，暂停菜单完成预览后回到 demand 休眠。

`WorldWeather.tsx` 以 GPU 移动固定粒子，不给每片雪或每滴雨建立物理体。流畅档雨／雪上限 600／360，高清档 1200／720。稳定天气只显示一种粒子绘制，切换时短暂交叠。复用已有风时钟，无新增定时器、音频上下文或阴影渲染。

33 × 33 遮挡高度格按每帧最多 32 次固定物体射线分批更新，移动约 8 m 或碰撞集合变化时才重算，排除角色、车辆及 sensor。资源卸载时释放几何、材质和高度纹理。地表采样与合成均复用现有 shader。

实现依据：[Rapier scene queries](https://rapier.rs/docs/user_guides/javascript/scene_queries/)、[QueryFilterFlags](https://rapier.rs/javascript3d/enums/QueryFilterFlags.html)、[Three.js BufferGeometry](https://threejs.org/docs/pages/BufferGeometry.html)。

当前是首轮雨雪：无雷暴、雨雪音效、积水模拟或积雪厚度；薄雪主要覆盖岛屿地表，并非所有建筑的完整积雪。太阳与阴影方向仍使用既有固定布局，六时段控制颜色、亮度及夜间状态，未实现天文学太阳轨迹。屋顶遮挡通过真实 Rapier 回归，未逐一人工走遍所有室内和洞穴。

## 10 principles re-check

| 原则 | 本轮决定及组件 |
| --- | --- |
| 意图对齐 | `WorldApp` 在原设置里直接选择时间和天气，不另开配置页。 |
| 降低认知负担 | `WorldApp` 将用户指定的六时段分为 3×2，天气独立为三项。 |
| 状态可见 | `WorldApp` 显示 HH:mm、当前选中态与时间流逝开关。 |
| 容错 | `store.selectWorldTime` 可随时重选，关闭流逝不会清除世界进度。 |
| 可操作暗示 | `world.css` 沿用可见焦点、边框和 aria-pressed 按钮状态。 |
| 界面退后 | `WorldApp` 不在游玩画面新增永久天气面板。 |
| 无需手册 | `world-i18n` 直接解释一秒对应一分钟以及暂停规则。 |
| 尊重时间 | `WorldNight` 点击即更新选中时刻，光照只做短时平滑预览。 |
| 无暗模式 | `WorldApp` 清楚显示默认开启的流逝开关，可直接关闭。 |
| 清晰主操作 | `WorldApp` 保留「继续探索」为设置中最显眼的主按钮。 |
