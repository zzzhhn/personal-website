# v4 过山车整岛集成

2026-10-28。基于 `1abe315` 空间样板，按用户已批准的 v4 日景方向实施。此轮交付可乘坐版本，不代表参考图美术已全部还原，也不结束当前七项 Goal。

## 实际改变

- 真实角色、三节列车、站台和既有上下车链改用同一 v4 轨道与坐标架。现长 1,904.15 m，最高约 85.34 m，内扣首降、两个立环、眼镜蛇回转、高空倒挂、双螺旋与贴水桶滚组成八次倒置。完整运动学回路 113.493 s，界面向上取整为 114 s。
- 增加开放钢架塔、检修平台和经过车体／默认镜头筛查的支撑，北侧及东侧增加三片连续岩脊。保留入口、解锁、车站和安全出口坐标。海岸向北、向东扩大，并保留贴水段的凹形水湾。
- 整岛试玩发现原天空球半径无法包住扩大后的路线与总览相机，导致黑边。天空改用仅旋转的视图矩阵，始终以镜头为中心，不增加面数或实时光；晴天雾距适应扩大后的海岬，雨雪仍缩短能见度。
- 沿用局部静态夜间面光，增加主塔暖色设备面和冷色钢架补光，无新增运行时灯或阴影通道。

## 协作及复核

- `v4_landscape` subagent 负责三片岩脊及相应测试。主协调复跑封闭网格、实际碰撞、轨道与镜头净空、步行环线及植被检查。
- `v4_clearance` subagent 提供实际合并网格诊断。它发现了支架遮镜头、观景台灯具与乘员冲突；主协调修正支架筛查、灯柱位置和末段桶滚路线，并重新运行。
- 「Phase 2 · 性能与资源效率」session 实现空间索引，并独立对照实际 547 次支架查询，结果完全一致。单次查询累计 2.67 ms，对照旧逐点公式 475.24 ms；不包含索引构建、采样与镜头筛查，不是整体生成或 FPS 测量。
- 资源压力为 warning，磁盘约 5～6 GiB。数值检查、构建和浏览器重活串行；复用唯一既有试玩标签，没有新建浏览器实例或下载模型。

高塔、两个不同位置的完整立环和交错回路已能辨认；夜景可见车站、路面、塔身与岩脊实体，近景乘坐中角色与前路可见。这通过本轮可体验版本的基本可读性检查，**用户对实际画面尚未验收**。

与已批准参考相比，岩岸仍偏低且水道少，远景树群偏稀，支撑有重复直柱感，部分连接细节未达到参考级丰富度。继续围绕这些具体差距细化，不能靠更多雾、升曝光、提高分辨率或换更有利角度掩盖。音乐、国投体验、全局一致性等其它 Goal 内容仍未完成。
