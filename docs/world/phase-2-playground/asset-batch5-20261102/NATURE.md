# G17 与西营地路径样板

本次是对批四的深化返修，不把批四的三团球冠或小幅顶点改动视作已接受的质量。只制作一个 G17 和一处草土边界，先交主协调看实际网页，未批准前不扩大树种或地表区域。采用既有切面海湾、原叶色和米制角色比例，不改场地、角色或行走路线。

R1 已由主执行亲阅原生／fresh 中距后否决：主干更连贯，但叶量像水平托盘、粗枝裸露过多，树冠体积和高度不足。七张实际 R1 图与当时 manifest 已归档至 `rejected-r1/`，只能作被否决的过程记录。R2 随后改为每根次枝内 7～12 根三维弧形细枝、实际 1560 片有不同俯仰和轴向滚转的叶片，让上中冠层恢复体积、枝组之间保留空隙。该轮 L1 木批次单独派生为 42％ 面数目标，native 的可编辑近景部件未做这次简化。

后续实际状态：主协调已亲阅 R2 的八张树网页日夜／中近距对照，结构方向通过，仍不扩树种或集成。该轮七张原生图、八张网页图和 JSON、manifest、脚本与 GLB 已另存 `reviewed-tree-r2/`，没有移动当前 review 引用。现脚本为在这副已审骨架上做的 R3：1560 叶数量保持，单叶长约缩 20％、宽约缩 25％，以交错相位和根部错位分散整束扇叶感；枝组及窗的位置不重建。近干增加浅枝领、按枝长定向的低幅纵纹，三张原创 256×512 color／normal／roughness 图由脚本生成，不是照片或扫描；normal／roughness 为 Non-Color，color 为 sRGB，保存后重新读入再打包，确保 native 与导出使用相同图片解释。U 沿每根枝周向，V 为枝长除以 1.4 m。L1 木降至 33％ 目标，叶从每扇七片降到五片，保持两份木／叶批次。新材质图和顶点拆分的成本需实测，不能沿用 R2 的文件字节或性能结论。

地表 R1 则经主执行在正常网页视距比对后否决：只微调原宽渐变，没有形成可读的草岛和土隙。八张地表 PNG、八份对应 JSON、当时 WorldTerrain 源码及 SHA 已归档 `rejected-ground-r1/`，未动树图。地表 R3 改为实际 coverage 重映射：从共享 `WORN_PATHS[2]` 推导原西行路径距离，中心 1.1 m 保持裸土；在约 0.6～2.6 m 的肩带里生成 0.45～0.95 m 的不规则草岛和相连土隙，0.025 m 加像素导数作边缘滤波。局部纯 grass 或 soil 也能改变为草岛／土隙，不再受旧乘权方式的零值锁死；颜色、法线与粗糙度都跟随同一份新覆盖。R3 树和地表仍须同机位网页复核。

R3 后续网页审阅：树的缩叶／树皮材料可继续送主协调，树脚本、GLB 与适配现冻结。地表再次内部否决，原因是逐格 ellipse union 形成近规则椭圆绿斑，像波点地毯。`rejected-ground-r3/` 留存本轮四张实际 candidate 图／四份 JSON、R3 源码和 hash；配对的四张 legacy／四份 JSON 从 `rejected-ground-r1/` 复制复用，来源及 hash 写入 `reused-legacy-baselines.json`，不声称在 R3 重新拍摄。树图没有移动。

现地表为 R4 稳定样板：完整删除逐格椭圆与九邻居循环。以原路径距离作为连续边界的主方向，叠加域扭曲后的 1.8 m 主场、0.55 m 次场和原 grass coverage 偏置，再阈值成覆盖。外侧草层连通地向路肩伸出不规则半岛，土层咬入其间，仅同一相关场的少量闭合分支可成为离散小岛，不再先将整条 band 变土然后铺点。中心 1.1 m 仍裸土，外侧 2.5 m 起固定为草地；原椭圆与 3 m 路径作用域不扩大。R4 尚待实际网页开图，数学连通性检查不替代自然观感验收。

原始与批四资产均只读。脚本默认从兄弟 checkout `personal-world-djc-release` 读取 `tools/world/nature-craft/blend/G17.blend` 和旧 public 文件，可用 `--baseline-root` 显式替换。生成器会拒绝输出路径经过 symlink，所有新产物只写当前 checkout 的真实 `public/assets/world/facility-craft/nature/`、`tools/world/facility-craft/nature/` 和本目录。

由主执行持有 FILE 锁后运行：

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python-exit-code 1 -P tools/world/facility-craft/nature/build_nature.py -- --render --close
```

输出为 `tools/world/facility-craft/nature/blend/G17.blend`、`public/assets/world/facility-craft/nature/G17.glb` 和本目录 `nature-manifest.json`。`--render` 生成旧／native／fresh 的同机位中距图，另有旧／native 同机位 clay。`--close` 增加 native／fresh 近距构造图。渲染使用同一米制正交机位、灯位、功率、Standard／None、曝光 0，Cycles CPU 24 samples、900×800、3 线程。原生与导出后再渲染，不用后来修改过的文件冒充之前画面。所有编辑部件保留在 native；GLB 仅包含四份派生批次与同一原点的 G17 根。

manifest 记录实际叶数／部件数、三角数、材质数、字节、源／产物 SHA-256、原碰撞 SHA、根信息、风范围和 fresh 坐标误差。检查拒绝非有限位置／风值、退化面、缺失 POINT 风属性、COLOR_0 丢失、LOD 名称改变、三角不一致或超过 0.00005 m 的包络偏差。此轮可见主干有意重建，不能再声称它与旧可见主干逐点相同；旧碰撞文件 hash 和放置契约独立核对。

开关优先级：`natureCraft=legacy` 保留旧的显式全局回退，优先于本次自然样板；只用 `facilityCraft=legacy` 且不加 `natureCraft=legacy` 时，G17 和地表返回批四，C09、石头、水和其他树保持本来各自开关行为。本轮仅候选 G17 的 URL 指向 `facility-craft/nature/G17.glb`，不改其它 Camp 设施。

地表只影响西营地路径的椭圆区域：中心 world xz `[-61.5, 34]`，完整效果半径 7，至半径 10 淡出，x 方向乘 1.25，并在原路径距离 2.4～3 m 内再次淡出。椭圆和路径肩带之外使用相同基色、覆盖、UV 和路径遮罩，不制造新行走路线。R4 有效带内为两次域扭曲噪声加两次相关场噪声、四段路径距离、像素滤边与覆盖／颜色校正；四次 value noise 共 16 次简单 hash，已删除 R3 的 27 次邻居 hash 与九组距离计算。区域外跳过场／域扭曲分支，但仍多区域距离／分支；椭圆内但肩带外仍算路径距离。18 次纹理读取不变，不等于 shader 无成本，必须测网页性能。

R2 生成时的实际计数：255 个可编辑近景部件，L0 为木 10072＋叶 24960＝35032 三角，L1 为木 4230＋叶 6720＝10950 三角；GLB 506420 bytes、2 材质、0 纹理，每个可见 LOD 为 2 draw。批四源为 6432 三角、234644 bytes，近景几何为 5.45 倍、下载约 2.16 倍，不能用“合批仍两次”冒充无性能成本。四个 fresh 节点三角与导出前一致，包络最大误差为 0.00000215 m，原碰撞 SHA 未变。R2 结构方向的后续网页评审记录见上文，其完整计数留在 `reviewed-tree-r2/nature-manifest.json`。

R3 的实际新 manifest 已由主执行生成：1560 叶／255 部件不变，L0 仍为 35032 三角；L1 为木 3322＋叶 4800＝8122 三角，比 R2 低约 25.8％。GLB 为 587904 bytes、2 材质、3 张共用 256×512 纹理；比 R2 增约 16.1％，比批四源约 2.51 倍。四节点 fresh 三角一致，最大包络误差 0.00000191 m，三种树皮贴图的导出存在性断言均通过，原碰撞 hash 保持。这里只记录生成与导出结果，R3 树皮响应、较小叶片、地表量块及性能还需网页同机位复核。

轻量检查 `node --test tools/world/facility-craft/nature/runtime.test.mjs` 四项通过：`facilityCraft=legacy` 的完整 shader／cache key 与固定基线 `2f22560` 批四逐字相同，旧 `natureCraft=legacy` 优先，候选保留顶点 ABI、18 次读取、非负且有限的 helper 权重，作用域之外完全不重映射，原路径核心保持裸土，肩带纯 grass／soil 可形成新的草土覆盖。CPU 参考场中，超过 96％ 的草像元与外侧草岸连通，路肩边界位移范围超过 0.35 m，不是测试场中的点阵铺装；这些仅验证算法边界，不证明网页自然观感。`py_compile` 和定向 diff 检查也通过。本协作者未自行运行 Blender、构建、浏览器或服务。主执行还须记录 R4 地表的实际画面、踏压／恢复和相同缓冲下的性能；没有得到这些证据前，只称待评审样板。
