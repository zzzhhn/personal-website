# 车辆细节与驾驶状态，2026-10-26

本轮保留 G25／G26／G27 原始 GLB、BLEND、轮廓、碰撞与驾驶参数。运行时只细化近档：深格栅与灯的构造仍属于各自车型，不把三辆车改成同一种前脸。

- 三车格栅从已烘焙车身中切出真实开口，加入后壁、内侧壁、嵌入式金属边框与立体横栅。三角裁切保留原顶点色、粗糙度、金属度与灯角色。
- 轿跑侧进气和细长前灯也使用实际开口。前灯包含深色灯腔、两颗投射单元与四颗细小日行灯；机盖补细缝，前唇补与原底板相连的端部及支撑。五辐轮内增加有 12 个实际穿孔的刹车盘。
- 越野保留圆灯与护杠，补灯内构造和格栅紧固件。货车保留圆灯、厚杠与竖向体量，补灯内构造及保险杠紧固件。
- 所有静态新增件并入原车身／四轮实例的既有烘焙几何。材质仍使用 `world-vehicle-v1`、原色板和原角色，不增加纹理或灯源。远档完全沿用原文件与 60／58 m 切换阈值。
- 轿跑实际 `boosting` 为真时，两根原排气管各显示外焰与内焰，共一个四实例网格。复用 `WorldVehicleVisual` 原有 `useFrame`，不新增定时器、帧循环或粒子系统；暂停和停止加速时隐藏。激活时增加一次主画面提交，不投影。

驾驶 HUD 显示实际侧滑角。接地轮至少两只、纵向速度超过 3 m/s、侧滑至少 8° 时显示「漂移中」，并一直给出 W 加速后 A／D＋X 的输入顺序及松开 X 后反打的恢复提示。该阈值只解释测量，不改物理。

氮气显示物理储量换算出的可用秒数、冷却秒数与耗尽后的 Shift 锁定状态。未把「储量不足」直接宣称为「正在补充」。提示为 W＋Shift，松开补充；手柄对应 RT、X 与 A。现有 HUD `setInterval` 已删除，改由 actor 的约 90 ms `position` 发布触发读取，停车时仍更新；motion owner 确认保留该发布逻辑。`vehicle-telemetry.ts` 仅扩展已有 `boostLock`、`rechargeDelay` 字段。

## 验证

`vehicle-detail.test.mjs` 与原 `vehicle-driving.test.mjs` 共 13／13 通过。新测试覆盖真实穿孔射线、原几何保留、材质组范围、非索引烘焙、三车材质属性、灯／玻璃角色、刹车盘穿孔、排气位置和物理状态解释。原驾驶测试继续覆盖有限氮气、按住不自动循环、加速、刹车、手刹侧滑与路面支持。

针对改动模块的独立 strict TypeScript 检查通过。未运行整站构建，也未自行启动浏览器或 Blender。运行时 `vehicleLodSnapshot()` 新增 `detailTriangles`、`rotorTriangles`、`boostExhaustVisible` 供主线读取。新增构件自身为 G25 462、G26 1128、G27 450 三角，G26 每轮刹车盘 210 三角；车身切孔产生的实际三角净增量应以加载后的 snapshot 为准，不能用构件计数替代完整近档预算。

## 设计检查

| 原则 | 具体处理 |
| --- | --- |
| 意图、操作暗示、免手册 | 驾驶时显示 W→A／D＋X、W＋Shift 与恢复方式 |
| 认知负担、主要操作 | 保留大号速度，下面仅侧滑与氮气两个仪表 |
| 状态可见、时间 | 显示实测角度、剩余秒数和物理冷却，复用 90 ms 发布 |
| 容错 | 明示松开 X 恢复抓地、松开 Shift 解锁及补充 |
| 自然、无诱导 | 不给虚构漂移分数，不把输入等同成功动作 |
| 跨组件约定 | 沿用 Geist、原色板、`world-speed` 角落布局，所有文本具备中英文 |

移动视口、实际对比度和截图观感仍为主线的渲染验收项，本记录不预填视觉评分。
