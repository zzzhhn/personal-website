# 意图过山车：轨道、轨枕与支撑精修

范围为资产清单20、21、22三族，基线5b8ef64，保持已批准v4场景和车厢/宝箱的材料方向。用户明确要求继续精修轨道；原轨道路线、坐标架、运动速度、镜头、实际物理与通路没有设计变更。

四种真实PBR表面分别是运行钢、蓝灰涂装钢、加工连接钢和矿物基础。连续型材与真实构造由TypeScript生产生成器精确沿现有全圈坐标架生成，再提供一段原生Blender可编辑样段；不把样段GLB误称为全圈网页直接加载源。

主会话负责真实consumer、原视觉移除、四材质及已有夜间光照适配。Sol制作新生成器及原生导出；另一独立Sol核对物理、worker传输和生命周期。所有生产/审查者都读取了最新material-craft流程。当前美术候选、测试和性能状态按后续实际证据更新，不自动继承入口区或单车通过结论。

## 结构与成本边界

原轨道、节点、支撑和基础先按原顺序完整生成物理，随后仅将这段旧可见parts移为不写颜色/深度的原投影载体。新模型取代其颜色通道，不叠画两套外壳。投影沿用原FrontSide约定；细螺栓不新增投影。

新geometry保留indexed位置、法线、米制UV；近远档各四材质合批。粗糙度复用本轮门锁的两张256px自制数据图，非扫描材质。夜间复用现有静态照明的incident字段和已有PMREM，无新增实时灯、定时器或UI轮询。

投影载体在主颜色pass的`onBeforeRender`临时将drawRange设为0，`onAfterRender`恢复；`onBeforeShadow`与卸载也恢复，避免重复提交旧轨道约14.7万三角。属性、bounds、caster纳入与shadow chunk输入不改，不复用或改写全局阴影管线。回归同时覆盖indexed/nonindexed及有限/无限range。

代表段原生文件已实际用Blender 5.1.2导出，共130个具名部件、5,492三角面，保留UV与法线；GLB位置范围匹配源JSON。它是生成器的可编辑样段，网页直接消费TypeScript全圈生成器。离线原生未渲染，下面截图以真实网页为准。

最终生产合同、worker传输、缓存释放和投影range恢复共11/11通过，候选正式构建通过。轨道和碰撞匹配5b8ef64；视觉表面有毫米级内收与简化，参见CONSTRUCTION的精度边界。

详细几何与原生脚本见CONSTRUCTION.md，生产边界见CONTRACT-AUDIT.md。整批入口候选上轮长尾性能未通过仍然成立，本轮不得用局部轨道结果替代该结论。

## 实际网页验收

真实Chrome最终候选`coaster-rail-full-v3`已检查短段与整圈正午/深夜，以及柱头盖面修复近景。连续双轨、轨枕、支撑、柱脚均可见，控制台无error；与基线固定相机、曝光、画布、DPR和天气。模型使用实际PBR consumer，不再经过抹去UV的旧CoasterBatch。无全局提亮、后期美化或截面放大。参考截图见`before/after-bay-*`、`before/after-overview-*`与`after-detail-day.png`。

去掉投影载体主颜色pass后，实际减少146,884个重复三角；接头修正与重复盖面删除后，最终相对v1净减148,268面。最终相对原版仍增加65,287面和10 calls，不能称零成本。首窗geometry 148、texture 70，相比原版138/66。

这些是浏览器帧间隔短窗口，不是GPU耗时或长稳压测。最终v3正午首窗最大171.1ms、11帧超过50ms，深夜最大45.9ms；本轮性能不能宣布通过。系统内存压力在warning与normal之间变化，不能把P95波动全归因于轨道。

巡览远景后再回同一正午机位，复测P50/P95为16.6/26.8ms、最大54.9ms；但geometry驻留从148变344、texture从70变86、program从76变168，已不是严格同驻留状态对照，不用较好的一窗替代首窗，也不据此判定泄漏。后续性能工作应检查远景切换后的资源驻留与冷加载阴影收敛。原始窗口见`baseline-performance.json`、`candidate-v1-performance.json`、`candidate-v2-performance.json`及最终`candidate-performance.json`。4341不变，4353提供本轮候选与静态对照。
