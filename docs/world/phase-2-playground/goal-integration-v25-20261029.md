# Alpha Agent 交易所 v25

实施依据是用户对 [v2 参考图](alpha-exchange/rebuild-v2-20261029/reference.json) 的「通过，按这个方向做」。该确认覆盖建筑、风格与空间方向；本次实际运行画面仍待用户体验评价。衍生的日景、夜景参考图用于照明校准，没有独立冒充用户验收。

## 本轮实现

- 36×42 m、约 14 m 高的交易厅，保留入口世界原点与旧栈道连接，扩大为非矩形海岸地块。奶油色石柱、胡桃木中央圆岛、低光泽铜栏杆、开放格栅屋顶和连通的 U 形高廊；左侧历史档案室，右侧清算室，后方开市钟与行情板。
- 一轮交互为取时段票、插票、选择 0～50 份仓位、封单、敲钟推进历史，三段后领取清算回执。点击铜轨档位，或 Q 选择拨杆再 E 操作。敲钟前只显示本轮已经到达的历史；完整回执保存选择与权益轨迹，重玩保留上一轮对照。
- 实际读取既有 Alpha Agent API 的 SPY 历史基准净值，以虚拟点数计算体验结果。这里没有真实证券交易，也未模拟费用或滑点，不把结果称为 Alpha 策略的实盘收益。
- 取票、插票、拨杆、封单、拉铃、取回执接入真实角色接近与手部接触采样。接触未成立、暂停、恢复、离地或阶段改变时不提交迟到动作。使用现有角色上的编排曲线和上肢 IK，不声称新增真人动捕。
- 回营地或离开交易厅会清除携带物；尚未插入的票归还档案台，已提交的历史选择保留。音频仅复用现有提示音，本轮未替换正式漫游音乐。

## 验证与修复

行为、动作、角色骨架、控制器测试 30/30；最终空间、实际 Rapier 胶囊行走和镜头测试 25/25；严格 TypeScript 检查、参考完整性检查、构建、diff 检查通过。构建仍有既有的大于 500 kB chunk 提示。

浏览器通过普通键盘输入走完一轮：初始仅使用 DEV 档案台定位，之后全部步行到台、操作、绕中央岛前往钟、返回调仓、去清算室领取回执，没有中途传送。载入 752 个历史交易日，2023-05-02 至 2026-04-30，三次目标仓位均为 10 份；最终权益 10749.245448349722，虚拟盈亏 749.2454483497222，10 次有效接触。回营地保留结果，回档案台可领取新票重玩。证据：[完成状态](qa-20261029/exchange-v25-round-complete.json)、[完成画面](qa-20261029/exchange-v25-round-complete.png)、[重玩状态](qa-20261029/exchange-v25-replay.json)。

实际试玩发现并修复两处数值通路测试最初未覆盖的问题：

1. 交易池后沿到开市钟有裸露地面和竖直台阶，改成真实可见的连续石材缓坡，并验证往返。
2. 正式打包版从正门出发会被第一道台阶卡住。门厅和交易池前沿增加中央缓坡，两侧保留台阶，碰撞与可见面共源。平面三角形内部接缝另产生假凸起，对 surface 网格使用 Rapier `FIX_INTERNAL_EDGES`，不降低净空或着地阈值。完整入口路线中心、±0.8 m 两边均做双向真实胶囊测试；正式打包版也实际步行完成大门到交易池再原路退出，未跳跃。证据：[走入](qa-20261029/exchange-v25-entry-walk-in.png)、[走出](qa-20261029/exchange-v25-entry-walk-out.png)。

## 画面与性能

最终生产构建的 [日景](qa-20261029/exchange-v25-hall-day.png) 与 [深夜](qa-20261029/exchange-v25-hall-night.png) 使用同一冻结机位：position `[71,9,-60.5]`，target `[59,4,-79]`，FOV 50，1710×875，balanced、晴天，时间分别固定正午与深夜。未后期调亮。初次夜景的钟和后墙太暗，因此重排原有两盏无阴影点光源，并加入对应的可见吊灯；中央岛、档案柜、后坡和清算台的材质面可辨。布局和奶油石材、胡桃木、铜件延续批准方向；最终审美接受仍由用户判断。[外观与海岸连接](qa-20261029/exchange-v25-exterior-day.png) 为本轮同布局的入口修复前截图，不能当作最终缓坡特写。

最终主体 23748 三角面，天窗 144 三角面，碰撞 surface 120、solid 17424 三角面。建筑、天窗、显示图集共三个静态渲染批次，少量交互道具独立更新；显示共用一个 1024² 事件驱动图集。没有新增常驻轮询、反射相机或更多实时灯光。

[帧时间采样](qa-20261029/exchange-v25-frame-sample.json) 为在清算台持回执的 DEV balanced 日景，57.77 秒、3464 帧：p50 16.7 ms，p95 18.4 ms，最大 32.7 ms，超过 33 ms 比例为零；可见场景 85 draw calls、420725 三角面。此窗口在最后吊灯和缓坡微调之前，不是最终全地图、夜景或低配机器的性能保证。最终生产通路与日夜截图未出现控制台错误。本机内存压力有警告、磁盘约 10 GiB 可用，验证串行执行，只复用一个浏览器标签。
