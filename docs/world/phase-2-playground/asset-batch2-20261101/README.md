4341 已更新为 `build-candidate.json` 对应的冻结目录，HTML、runtime bundle与两个新GLB的HTTP散列均匹配，见 `delivery.json`。未push或公开部署。共享整合树只接收本轮精确补丁和新资产，保留其它场景及`club-basin` claim，12项整合定向检查通过，见 `integration-receipt.json`。

实际网页的箱A完成开盖，以及Pocket1取样、M8接触读数、归槽与工具收起。其余槽位、搬运及发货没有扩张为本次实测声明。相关源码58项通过后，箱体最终仅改AO／UV1并重跑真实叉槽、托垫与81角度扫掠；3项既有恢复流程测试失败另列于 `runtime-tests.md`，没有混报为全套全绿。

性能为同包默认候选与双legacy的两个局部视角，每窗90帧预热+300帧，实际1710×931。伞p95从17.6到17.1ms，箱p95从17.6到18.6ms，各窗约60FPS、无大于33.4ms帧。箱视图draw calls由90增至131，说明几何与材质细节有实际成本；没有测GPU计时、长期内存／发热或整岛保证。完整范围见 `runtime-after/README.md`。
