## 音频运行证据与边界

为读取开发专用按钮，完成生产乘坐后停掉 4343 preview，在同一端口切为 Astro dev，并复用唯一任务标签。此阶段不作为生产性能数据。

- 初始暂停时 AudioContext 为 absent，缓存 0。可信点击后候选 B 的 `previewPlaying=true`、context 为 running、缓存 2,304,000 bytes，`timer=false`、ticks=0。
- 在同一约 3.1 秒的操作调用内，读取播放状态后按 Esc，立即读取到 `previewPlaying=false`、context 为 suspended、timer=false、voices=0。实际 UI 读数存于 `runtime/world-v19-audio-pause.txt`。
- 恢复探索并再次读取后没有自动补播。缓冲保留一份供本次页面使用，退出清理由已有测试覆盖。
- 另一次重载后，启动试听并保持世界运行，随后读取到试听自然结束、context 为 suspended、timer=false、voices=0，保留单份缓存；见 `runtime/world-v19-audio-ended.txt`。
- 真实 Safari、操作系统打断、Club crossfade 交接、后台 30 秒与耳机／扬声器听感尚未验证。没有因为读取到 running 就声称听过或认可成品。
