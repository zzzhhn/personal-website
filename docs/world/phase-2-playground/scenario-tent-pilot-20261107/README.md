## 视觉结论

原版没有 UV、颜色、法线或粗糙度图，屋面厚条和大片纯色容易被读作硬质板房。新版用较薄的接缝、圆润包边、轻微布面起伏、收褶和五张共享 512px 图改变材质表现。

普通距离和近景有可见提升，夜间仍能辨认轮廓和门洞，未改曝光、全局灯光或场景布局。但主要提升集中于材质和边缘构造，大轮廓仍保守；细织纹还显得比较规则。过滤修正没有让单张截图产生巨大差异，不将其描述为彻底消除了所有纹理干扰。该结果可作为一次有明确边界的 pilot，不能直接认定为新的高品质样板或替代人工审美检查。

原版与新版均采自实际 WebGL，浏览器截图未调色或修饰。普通机位 `[-33.4, 8.1, 22.6]` 指向 `[-42, 6, 12.5]`；另含固定门口近景、侧面视角。FOV 50、曝光 1、Balanced、晴天，白天 12:00、深夜 00:00。绘制缓冲区均为 2013×1030，DPR 1.1772275318111343；页面截图 1710×875。静态截图模式冻结物理与风动，动态验证另行进行。

三角形约增加 1.5%，绘制调用不变，新增五张图。新增 GLB 为 508592 bytes、10568 triangles、五个材质批次。旧 GLB 的原始三角形数量不能直接作运行成本基线，因为旧消费者会对布面做运行时细分。

当前机器内存压力为 warning，磁盘约 14 GiB，后台负载未隔离。中位帧间隔基本持平，夜景尾延迟较旧样本上升；首轮新版夜景 P95 曾为 40.6 ms。数据不足以把这些尾延迟变化归因于单一帐篷，也不证明完全没有回归。所有原始样本都保留，未只挑最好的一次。此为固定机位的局部渲染检查，不是 GPU 耗时、冷启动、全岛帧率、低端机或长时泄漏认证。

## 对技能的实际补强

核心入口仍是 `blender-material-craft`，其它旧 Blender skills 已路由到此入口。新增固定版本的六类工具、MIT 归属、wrapper 与兼容 smoke，没有安装不相关 DCC 或云端服务。

本轮实际使用 UV 密度测量、材质接线审计和 GLB 内容统计。原生拓扑检查是作者自己的 bmesh 检查，不冒充 Scenario 功能。应用中发现的屏幕采样问题已补回 `references/scenario-tools.md`。工具的价值是辅助构造、诊断与交付，不能用全绿报告代替游戏内视觉结果。
