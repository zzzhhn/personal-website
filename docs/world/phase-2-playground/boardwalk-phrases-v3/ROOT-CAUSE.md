# 2026-11-07：Boardwalk 长版被用户否决后的重作

用户指出小节不连贯、主旋律像随机按键。502.1878 秒旧长版未获听感认可；此前的播放、响度、文件完整性验收不代表作曲质量。

## 调查与复现

输入为 `tools/world/boardwalk-longform/{score.py,render.py,aux.c,v2-seed.json}` 与原 `public/assets/world/park/audio/boardwalk-longform.mp3`。音乐会话核对这些文件与原交付哈希一致。

- 主旋律按 `role=i%4` 生成，没有把上一句的落点传入下一句。新增 160 小节里 193 次马林巴起音中，108 次位于四小节单元的第一小节、64 次在第二小节、第三小节为零、第四小节 21 次。第 10 小节最后的 G4 结束后，距离第 13 小节 E5 起音相隔 8.4 拍。这是固定模板造成的长空档，不能靠混响补成连贯旋律。
- `nearest(chord,target)` 分别改变首尾音，未保持旋律方向。第 65 小节的 G4–C5–D5 变成 G4–C5–C5，第 129 小节的 E4–G4–A4 变成 E4–G4–G4。十个长段更换和声和配器，但仍复用相同的局部结构，没有独立写成完整主题与发展。
- `max(1.6, gate)` 把短音延长。新增旋律含尾声的 196 个马林巴音符有 81 对书写时值重叠；按起音计，新段有 71 次起音时另一音高仍被按住，最多三音。半拍相隔的 E5、D5、C5 因此同时持续。旧短版也有此现象，叠音不是所有音乐的错误，也不能独自解释长版失败；新版明确采用单线条主旋律，需要分离音值和乐器余响。
- 低音用转位低音 `root+7` 生成所谓五度，C/E 因而在四处加入 B1，实际带入谱面未标注的 Cmaj7/E 色彩。它不是本次不连贯的充分解释，属于独立的和声实现偏差。
- 渲染管线按绝对帧发送音符，音高/通道对应正确，滤波器及短延迟状态跨 8192 帧块保留；没有找到逐小节重置 DSP 或 MIDI 时序的代码。对旧音频 32–46 秒抽样，700 个 20ms 块中仅 2 个接近静音。第 13 小节前有短呼吸，其余抽查的小节线也存在能量起伏，不能把它们直接当作丢 PCM。此次检查未证明所有全曲听感正常。

## 比较与假设

短版可保留的关系是第 2 小节 E5–D5–C5–G4 问句由第 3 小节 A4 接住，随后落向 G4–E4；第 5 小节重提，后续答句变化并走向 G7–C 的收束。保留的是这段关系和轻柔音色方向，不是把旧文件无变化重复二十遍。

主要假设 H1：缺乏完整乐句建模导致断续和模板堆砌。先保留 82 BPM 和轻柔音色方向，写出 16 小节完整主旋律，展示逐音谱和短样。新谱同时重新安排了和声，因此这是重作短样，不是只更换主旋律的单变量音频实验。H2：强制延长音值加重叠响。它用独立的音值/起音回归验证，不能以缩短 gate 代替 H1 的作曲重作。

参考的组织原则是动机重提、发展和终止，见普吉特海湾大学 [The Sentence](https://musictheory.pugetsound.edu/mt21c/SentenceStructure.html)。不搬用其中曲例音符。新增测试只能验证已声明的单线条、句内连接、确定性及事件完整性，不能给音乐打“好听分”。

新曲听感需要实际试听。主协调不得把符号规则通过、音频 QC 或协作者“完成”写成用户审美验收通过。
