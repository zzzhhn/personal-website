# C · 开阔水面

C 大调，4/4，四分音符 = 82 BPM。每音按 `起拍/音高/时值` 记谱，时值单位为拍。小节线后的延音仍属于原音，空拍为休止。

第 1–8 小节把旋律放慢成一口长线。A4 先唱满三拍半，最后半拍的 G4 引向低处的 E4。第 2 小节末的 G4 从 C/E 延进 Am7，和声先换，旋律后到 A4。第 4 小节的 C5 经弱拍 B4 回到 A4，原样重唱第 1 小节。随后 F4–A4 和 G4–D5 把线条逐渐抬到第 8 小节的 F5。这里仍在 G7 上作半终止，末尾 B4 向第 9 小节的 C5 接续。

第 9–16 小节先在 C6 上接住 C5，随后原样重唱前三小节的 A4–G4–E4–G4–A4。第 13 小节起缩短前面的长音，C5–E5 接第 14 小节的 F5，到达高点后经 D5、B4 回落。第 15 小节的 G4 回到尾拍 B4，第 16 小节在 C6 上用整拍小节的 C5 作全终止。
