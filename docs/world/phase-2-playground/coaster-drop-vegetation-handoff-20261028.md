# 首降局部改用现有风动植被

增量基于 `3b204a0`，分支 `codex/coaster-drop-landscape`。主线尚未集成前一提交，因此应连同前一提交一起审阅。本记录替代上一份景观 handoff 中「六棵静态小树、十五丛静态灌木」的实现与成本记录；四处岩床、草土覆盖和回收平面面数的方向保留。

## 改动

- 删除 `createDropPlant`、其五边形树冠／灌木及所有局部静态植被三角面。北侧样板的地形网格现在只有地面和岩床，不包含替代树叶。
- 在原实例容量内，调配两棵 ST1、两棵 ST2、六丛 G19 到首降岩肩与坡脚。全局仍为 22 ST1＋26 ST2＋36 G19，共 48 棵树、36 丛灌木；保留入口花槽，其余位置按原轮转布局填满剩余容量。
- 未修改 `WorldCoasterVegetation.tsx`。新位置通过原 `coasterVegetationLayout()` 进入现有实例、`attachNatureWind`、树冠 LOD 和物理树干路径；树干继续在两个渲染 LOD 中使用同一 L0 几何与实例矩阵。
- 把北侧地面与岩床的生成数据提取为共享局部缓存。`coasterDropHeight()` 直接查询相同三角面，不以旧地面高度、中心点近似或额外生成完整场景代替实际落根。
- 根部四周仍按原坡度门限筛选并嵌入 0.06 m；完整动叶包络使用原 `clearCoasterPlant()`，同时避让轨道、视线、两档支架、基础和步道。没有放宽筛选范围。

设施静态面数减少 636，远档 140,000 的原上限剩 2,920 面。静态可见属性减少 91,584 B，接触数组减少 12,240 B。

现有植物实例采用独立且未变的预算：最坏可见面数 151,088、最多五次绘制；共享几何属性 2,251,704 B、树干接触数组 1,677,504 B、实例矩阵 8,448 B，全部保持。没有新增资产、下载、材质批次或碰撞对象；仍为 48 个真实树干 trimesh。设施描述符仍为近档 1,080／远档 746。

本机本设施几何工厂单次计时约近档 792 ms、远档 379 ms，不含浏览器、GPU 和物理挂载。与之前不同资源窗口的计时不可直接作性能改善比较。

## 验证

20 项定向测试及两档真实合批面数断言通过，串行运行，无新依赖。

- 读取并解码已有 ST1／ST2／G19 Draco 资产，验证两档可见顶点、原始风权重和完整风摆包络。复用真实资产，未用代理形状冒充此项。
- 新增落根检查：四树六灌木的采样高度与实际 Rapier 岩床接触最大差约 0.0000044 m。树干两个渲染 LOD 与物理顶点使用同一矩阵，误差小于 0.00003 m；刚性树干风权重为零。
- 3,600 个错位全程样本，轨道／角色到动叶包络的最小距离约 4.164 m；三种预设视线、两档支架和公共路径通过。
- 花园步道使用实际树干、地形与设施碰撞，817 步胶囊移动全部贴地，路径完成。
- 原实例选择、LOD 滞回、容量、实例上传和包围球回归通过。
- 局部岩床 3 项、thrill-landscape 3 项、worker transfer 4 项通过；完整地形／接触继续一致。
- 从 Git 读取 `3b204a0` 作几何对照，七块地面／岩床的 position、normal、color、nightRadiance 属性逐字节相同；仅移除新增的静态植被 636 面。两个 TS 新改模块及布局模块无语法诊断，`git diff --check` 通过。
