# v35：玩家实际操纵国投吊架

沿用已通过的 IBD v1 场景方向，没有变更园区布局。把一次按键后自动搬运，改为玩家握杆、吊起、横移、落稳、松杆的完整操作链。用户本轮另确认了 40 秒漫游音乐的轻柔、日常探索方向，已记录于 [音乐反馈](music-direction-approval-20261029.md)，本次没有替换运行音乐。

## 操作与接触

- 靠近桥式吊架按 E。角色走到控制台，转身，双手握住两根实体控制杆。
- 按住 ↑ 吊起、← 左移、↓ 落稳，也可以按住画面对应按钮。松开即停，每段到位后停下，必须重新按下一段；顺序不正确时不移动货物。
- 货物继续使用既有三段路径与 Rapier 净空保护。货物落稳、角色松手恢复之后才提交任务进度；计时器不能跳过接触或直接完成。
- 手部目标随控制杆转动，由真实 G24 骨架矩阵采样验证。没有增加或声称使用新动捕，没有拉长骨骼。原台面太高，已按角色实际可达范围降低，并纠正台体与握杆位置不一致、站位与台体相交的问题。
- 暂停、页面失焦、隐藏或释放按键会解除持续输入。恢复后不自动继续。离开设施、回营地、失去地面支撑和换批次会取消旧操作，旧 token 不能提交新批次。
- 不新增定时器、轮询、纹理、灯光或刚体。复用角色物理时钟与现有渲染循环；新增两根控制杆共两个 draw calls、144 个三角面，从原静态几何移出相应杆件。静态 47821 面，代表性资产集合 68385 面，仍在既有 48000／70000 上限以内。
