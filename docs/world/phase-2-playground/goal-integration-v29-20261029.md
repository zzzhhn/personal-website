# v29：扩建区域的太阳阴影与国投货车接地感

本轮从货车缺乏接地感开始检查，发现了两层问题。轮胎几何实际接触地面，但环境补光没有车底遮挡；更关键的是，固定截图一直使用旧主岛的阴影窗口，国投和北侧过山车位于窗口之外。普通游玩的阴影相机虽然跟随角色平移，沿光线方向的深度范围仍固定在旧岛上，远北区域也可能被裁掉。

## 实现

- 近景截图改用游玩时的三级局部阴影窗口，以真实拍摄目标为中心。国投和过山车总览改用各自场地范围，过山车保留 110 m 的保守垂直包络。未更改截图机位、视场角、曝光或世界灯光强度。
- 普通游玩时，三个阴影窗口沿光线方向的深度中心也随各自观察区域移动，避免新园区的物体落到旧岛深度范围以外。保留原窗口尺寸、贴图预算和 2 mm 深度偏移；拍摄范围的投影缓存只计算一次。
- 为固定装卸货车的车底和六个轮胎加入解析式柔和环境遮蔽，与可见轮胎共用轴距和轮距数据。只衰减地面的间接光和已有夜间补光，不涂黑地面颜色、不替代太阳投影，也不作用于活动货物。没有新增灯、贴图、绘制批次或轮询。

## 验证与边界

- 16 项国投几何、材质、工作灯和美术结构测试通过；11 项真实阴影相机覆盖、阴影构建集成和调度测试通过。新增覆盖测试直接投影实际阴影相机，检查营地、国投、北侧地面和高处乘坐位置，以及两座园区总览包络的八个角。不是只检查字符串或配置字段。
- WorldIbdYard 和 WorldEnvironment 的严格 TypeScript 检查通过。国投顶点位置、碰撞体、地面与步行网格哈希均与 v28 相同，见 `qa-20261029/ibd-v29-geometry.json`。
- 日夜截图继续使用 v28 的货车机位 `[-80, 6.3, -147]`、目标 `[-72, 2.7, -162]`、50° 视场角、1710 × 875、balanced、晴天和固定 12:00／00:00。新图为 `ibd-v29-after-day.png`、`ibd-v29-after-night.png`；基线为同目录 `ibd-v28-after-*.png`。
- 新日景可见棚顶、立柱、设备和货车的实际太阳投影。v28 截图存在阴影覆盖缺陷，因此此前日景只证明地面材质变化，不能视为完整棚内光影验收。夜景保留暖色作业区域，轮胎接触暗部连续，没有改全局曝光来补偿。
- `coaster-v29-shadow-overview.png` 检查扩建轨道与地面的总览覆盖。这张图没有旧版同机位对照，不宣称整个过山车美术已完成；远景岩岸、植被和整体资产仍需精修。
- 复用现有 Chrome 标签，在正常游玩模式通过可见 QA 落点到首降岩肩，再实际走动。约 29.62 秒采样 1,766 帧，p50 16.7 ms、p95 18.1 ms，最大 200.1 ms，超过 33 ms 占 0.17%。国投接货区与内部通道约 42.91 秒采样 2,575 帧，p50 16.7 ms、p95 18 ms、最大 25.4 ms，无超过 33 ms 的帧。两次窗口设置未变，浏览器未读取到错误；数据见 `qa-20261029/world-v29-runtime.json`。尖峰仍记录，不以单次采样保证所有机器或完整乘坐无卡顿，也不推导相较旧版的性能提升。
- 三张固定截图均已读回检查。测试后恢复自然时间，暂停渲染后串行构建。受磁盘余量和内存压力约束，本轮没有增加并行浏览器或本地协作者。
