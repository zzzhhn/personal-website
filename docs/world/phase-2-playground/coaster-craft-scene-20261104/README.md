# 意图过山车整场精修

2026-11-04。用户要求「一个场景一个场景地推进，能先把意图过山车那个场景的建模 assets 给全方位地优化一下吗」。本轮优先完成这一场景的连贯可见质量，其它场景候选保留，不继续分散重型制作窗口。

## 当前依据和质量目标

沿用已批准的 [v4 日夜参考及授权范围](../visual-calibration-20261027/coaster-v4.json)，主已实际打开两张参考图。实施检查通过，不要求用户重复批准既有方向。保留切面海岸、蓝灰钢构、灰白建筑、青色技术光和暖色公共空间。轨道路径、乘坐速度与镜头、人物尺度、解锁机制及固定物理接触沿当前可玩版本。

已有局部构造通过不代表质感完成。主对最新入料台四张普通视距原图的判断是：薄板、门缝和底座改善可读，但全场仍以均匀地面、平色柜面、直条钢构与巨大说明牌为主，材料身份和画面层次不足。接下来以入口工坊至站台为一片连贯候选，先把占据画面的大表面、体块和连接做实，再扩展同一场景。不能用一次只多几条缝或几颗螺栓的截图替代整片提升。

旧队列的 15 族是索引，不限制全场覆盖。列车、实体门锁、标牌与场地设施不能因旧索引遗漏而不检查。重复实例不额外计族数，局部样板也不按整族完成扣除待办。

设施线只写 `coaster-rail-section.ts`、`coaster-detailing.ts` 的 `createSupportMemberDetail` 及独立 `coaster-structure-craft*` 模块，不写轨道/支架拓扑和碰撞。场景主线拥有统一材质角色、总装入口及其它场景造型，双方先明确回调/属性再合并。主协调持有 release、4341 切换和最终接受决定。

## 材质和交付约束

当前 `CoasterBatch` 删除 UV 并重写顶点色，`WorldIntentSurface` 对 craft 角色覆盖粗糙度/金属度；植被合批也不消费源贴图。新原生材质必须有真实渲染路径，不能用未消费的 GLB 或贴图作为提升证据。可合理调整本场景批次与属性以保存需要的材质，不把旧实现当作禁止使用优质纹理的永久约束。

新增属性需要覆盖无标记部件、近远两档、worker pack/unpack、缓存与销毁。各类表面的夜间补光语义要保持正确，不能简单调高全局曝光。静态材料、发光体、活动工具与列车保持各自的更新和所有权边界。

先在真实 WebGL 中建立入口、站台、工坊、总览的冻结日夜机位，记录时间、天气、相机、画幅、DPR、曝光及 source。主审普通距离下的提升、再看难点近景。随后检查走近/操作、进出车及一段实际乘坐净空，最后一次组合构建与对应资源验证再切 4341。成本核对区分三角面、绘制、纹理驻留、CPU worker 冷进入和帧间隔；无 GPU timer 不声称测了 GPU 帧耗。
