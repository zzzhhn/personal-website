# 意图过山车全线轨道与支架

基线 `024e5a6`。全线钢轨沿用原运行截面和端环，运行钢与深色主脊各用已接入的材质角色。原开放段铜色直杆改为同位置的贴轨横枕，近档由枕身和左右钢鞍座组成，远档用与轨底接触的单件横枕。既有支架布置、柱高和横撑长度沿用原值。近档以实体柱头、接板和灌浆底座说明承托，远档合并柱头及基础叠层。高变化曲率段保留窄枕身与窄鞍座，避免相邻运行姿态与枕端相交。

每档沿用现有钢、发光两个合批。角色缓冲仍为 Uint8，近档整批 620,028 字节，远档 369,204 字节。表中统计仅为 `createCoasterStructure` 的钢批与发光批三角面，未测 GPU 帧耗。[完整计数与角色记录](full-batch.ndjson)

候选与 024e5a6 的轨道接触数组、所有碰撞描述、地形走面与发光顶点逐项一致。使用候选新增的可见网格，两档各检查 3,600 个车体、头部与三种镜头的位置。缩窄急弯段轨枕后全部通过。既有轨道、支架与传输套件 11 项通过。[两档净空读数](full-clearance.ndjson)

统一入口接线只涉及四处，精确片段在 [CPU 总装复现脚本](../../../../../tools/world/coaster-structure-craft/check-full-batch.mjs)。把 `scope:'full'` 和 `detailed` 透传给原两个入口，跳过旧铜杆、旧底板，支架杆调用 `createSupportMemberDetail(segment, craft)`，并以原语义回调标记既有基础。正式开关由场景线接入。短跨模式保留为诊断。

[原生导出脚本](../../../../../tools/world/coaster-structure-craft/export-sample.mjs) 可重建场地坐标中的完整结构几何。用 `--full` 生成近档、再加 `--far` 生成远档。导出源包含近档 7 组 143,260 面和远档 6 组 65,148 面，只有本组结构，无轨旁地形或照明。文件存于本机 `/tmp/bobby-coaster-full-source`，体积约 105 MiB。[导出源哈希](FULL-NATIVE-SOURCE-SHA256.txt) 中记录了两档。档案参数为基础 PBR 近似，真实 WebGL 反射和昼夜可读性待统一构建核对。
