# 过山车低位短跨结构样板

基线 `7280675`。选第一立环之后的低位短跨，中心参数 0.265，范围约 16 米。近远档各有八道轨枕和一座现有支架进入样板。沿已批准的 v4 参考保留蓝灰钢结构、浅色运行钢轨和现有夜间灯带。

| 普通视距应读到 | 候选 |
| --- | --- |
| 运行钢轨如何落到轨枕上 | 在原轨枕与钢轨底面之间加入贴合鞍座，钢轨和主脊共用原截面环 |
| 横撑、立柱、轨道主脊如何相接 | 增加两片跨梁连接板，把原柱头套筒分成收肩柱套与承压领圈 |
| 柱脚如何落到基础 | 在现有基础顶面加相接的灌浆垫和钢底板 |

现有物理轨道数组保持逐字节一致，两档候选各以实际可见三角面检查 3,600 个全程参数的车体、头部及三种镜头射线。每档增加 304 个可见三角面，预算只含轨道和支承节点子组件。轨道位置、相机、速度与支架布置使用原源码。分段视觉件共用原端环与法线。见 [净空和成本读数](preflight.ndjson)。

总装可将同一 `CoasterStructureCraft` 对象透传给 `addCoasterRailSections` 与 `addCoasterSampleNodes`。对象的 `mark(geometry, surface)` 回调收到已转换并烘焙的真实 CoasterBatch 零件。独立导出验证 WeakMap 标记能写入批次角色属性。正式角色编号、场景着色器和总装开关由主线接入，日夜实景尚待拍摄。归档源的七组基础 PBR 材质为近似，不能代替实际运行着色器。[可编辑导出源](native/coaster-short-bay.source.json)
