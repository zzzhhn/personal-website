## 视觉证据

五个固定机位各含正午、午夜，共十组匹配对照。基准为 4341 原运行源码 `9c2328278570b0d9b40dc3b6ec7a5eccef719022`，候选为 `45ce8e4`。两者独立源码构建，未用新旧文件拼装基准。

相机位置与方向、FOV、1710 × 931 画布、DPR 1、Balanced、晴天、曝光 1、720 / 0 分钟均逐字段匹配。每张保存时资源加载完成，失败数为 0，阴影任务结束、日夜混合为 1。云、树叶和人物姿态未固定，不属于像素级回归。所有 `candidate-*-day/night` 图均来自最终源码；性能和实际乘坐记录单独保留源版本。

运行时原图由主逐一检查。`production-4341.jpg` 是更新后的正式本地页面，已确认不带本轮验收读回属性、没有浏览器错误，最后已暂停渲染。当前证据是主审交付，不代表用户已经作出新一轮审美认可。

## 验证与性能边界

- 几何、轨道接触、全圈相机净空、近远档传输、夜间材质、列车和登车相关测试 47 / 47 通过。之后仅给三块已有地坪追加材质角色，再跑建筑检查 4 / 4 通过。
- 最终源码调用真实 Worker 消息处理器，经过 transferable 所有权转移后，近远档的几何属性、碰撞和地形与同步生成逐项一致。该检查不冒充浏览器冷启动耗时。
- 含三节列车的过山车结构，远档 139,906 / 140,000 三角面，近档 239,794 / 240,000，原阈值未放宽。余量很小，后续增件必须先重新分配预算。周边世界不在这两个数内。
- 工坊固定机位绘制 130 → 127，三角面 617,723 → 650,234；全景日景绘制 257 → 256，三角面 1,010,145 → 1,031,321。新增材质角色仍合批，没有逐件拆成绘制调用。
- 同一工坊机位各采 180 个浏览器帧间隔：基准 p50 17.5 ms / p95 43.9 ms / 最大 72.2 ms，候选 p50 16.6 ms / p95 34.5 ms / 最大 178.3 ms。存在偶发尖峰。这是墙钟采样而非 GPU timer；系统负载、已访问机位和缓存不同，不能据此宣称整机性能提升或精确比较显存。未做 GPU 耗时结论。
- 正式构建包含全部八个页面并执行原 prebuild 检查。4341 切换后 142 项 HTTP 与文件字节检查通过，102 项此前消费的资源逐字节保持，G21 模型保持。回滚根目录与旧资源均保留。

运行资产实际由 TypeScript 几何生成器与 WebGL 材质消费。此前原生归档保留在作者目录，但不是这一版运行资产的替代证据，不宣称旧 `.blend` / GLB 已包含最后的列车返修。
