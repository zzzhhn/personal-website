# v40：后库实物验样与选箱

本轮接着 v39（`351ab22`）推进国投场景。后库从静态货架变成可操作的备货区，沿用已批准的国投 v1 工业场风格与三棚布局。没有改主岛边界，没有公共部署或合并 main。

## 玩法与实物

- 原 B 箱发现差异并签认后，实体退到隔离位，B 台留空。原箱及原始证据保留。
- 后库左右各一箱，外标同为 M8／4 件，实物分别为 M8、M6，位置随访问轮次与案例变化。玩家可以开盖、任选槽位、取样、调整真实卡规、测量并放回，再决定选哪箱；也允许未验样直接选择。
- 被选中的同一箱沿后库通道送回 B 台。身份、数量、规格不被自动改写；后库抽样不能替代 B 台完整复检。选错后需要完成复检及差异签认，才可退回原位重新选择。
- 选箱、退箱先归还样件、收好夹量机构并合盖，再运输。仍使用既有货物运动与角色避让机制。取消及旧回调不能复制货物或完成过期操作。
- 后库候选不加入本批发货数量，原有四个货物槽位和发货核对规则保持不变。A 箱及钢卷退换保持既有流程。
- 带路标记指向中立的后库入口，两侧验样台都可操作，不提前指明正确答案。箭头仍从上一项已完成的操作点出发。
