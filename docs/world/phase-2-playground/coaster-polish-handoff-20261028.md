# 过山车 v4 细化首轮交接

2026-10-28。基线 `43f9507`，分支 `codex/goal-coaster-polish`，工作目录 `personal-world-phase2-coaster-polish`。本轮完成实现与定向验证，本地提交由本线创建；push、合并、4341 和实际视觉验收归主线。未编辑旧 coaster 目录或 integration。

## 实现

- **支架连接：** 62 个近景支架组中的 186 根主构件，采用原钢管表面的端部接头、端盖与连续主体分色。端部短段 0.34 m，保留原八边形截面、长度、端点与碰撞；没有向外加粗或追加碰撞。
- **站房层次：** 增加两根纵向承梁和四根斜撑，连接现有柱头；六件均使用与可见盒体完全相同的位置、尺寸和旋转生成碰撞。四个梁底暖色灯槽共用静态面光位置。
- **岩脊岩台：** 三片 v4 新岩脊从圆缓坡面中削出倾斜层理的宽岩台和短坡坎，采样最大下切约 1.85 m；不抬升原表面。原轨道／镜头／基础净空裁切保留，低于 2 m 的基础地面不改。矿物灰成为主体，苔色限于较平缓的上层面；原地形轮廓、贴水湾、公共步道不改。
- **夜间体积：** 增加站梁局部暖色面光和三处低强度岩岸冷色反射补光，写入已有顶点夜间辐照度。无新增实时灯、阴影通道、贴图、材质批次或每帧任务。

真实轨道、约 1,904 m 长度、85 m 高塔、八次倒置、列车与骑乘时间未修改。共享人物、自由视角及上下车实现未修改，仅做接口回归。

## 实测预算与旧碰撞失败

使用真实几何工厂的局部计数路径，跳过合批和非必要面光，并立即释放临时几何；没有创建整岛或渲染器。两档均包含三节真实车体的面数：

| 项目 | 当前 | 原上限／增量 |
| --- | ---: | --- |
| 近景静态 | 213,340 triangles | 本轮 ＋6,072 |
| 近景含三车 | 214,096 triangles | ＜240,000 |
| 远景静态 | 106,940 triangles | 本轮 ＋120 |
| 远景含三车 | 107,696 triangles | ＜140,000 |
| 近景结构碰撞 | 1,080 | 基线 1,074，本轮 ＋6 |
| 远景结构碰撞 | 746 | 基线 740，本轮 ＋6 |

角色线报告的 `<650` 失败来自 v3 时期遗留断言，与 v4 已扩大的设备不匹配。审计近景组成：389 根支架杆件＋124 个支架基础＝513；独立主塔 148；其余设施 419，其中含本轮六个站房构件。基线其余设施为 413。

近景全量描述中没有完全重复项，也未发现任一碰撞包络严格包含于另一实体盒内、可直接移除的项。把这些离散杆件塞进一个凸包会填掉通路；保留精确开口的静态三角网格聚合是可选后续优化，但需要再验证接触、相机查询、工作线程传输及加载时间，本轮不据此删掉真实碰撞。

因此改为两项有界约束：支架杆件与基础不超过 **528**，其它设施不超过 **568**，合计上界 1,096。当前为 513＋567；其它设施上界来自基线 561＋本站房六件＋一件余量。没有放宽镜头 11.9 m 或护栏物理要求。这是与现有 v4 拓扑相符的描述数量上限，不是性能验收或允许未来无界增长。
