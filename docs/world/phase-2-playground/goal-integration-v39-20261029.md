# v39 · Alpha 回廊与室内细节

本轮沿用已获用户确认的 Alpha v2 奶油色石材、胡桃木与克制黄铜方向。参考与批准范围见 `alpha-exchange/rebuild-v2-20261029/reference.json`。本轮没有重新定义建筑布局，也没有把实现验收当作用户对最终美术的认可。

## 改动

- 回廊后墙增加两座有柜门、隔板、书脊和纸页块的书柜，两只具有真实壳体的花器及枝叶。
- 后墙补充胡桃木壁板、石柱收边、回廊饰板和局部暖光。暖光沿用现有顶点发光通道，没有新增实时灯光或阴影。
- 复盘旋钮旁新增倾斜阅读屏，放大实体台面并补足木作与黄铜边框。小屏复用已有显示图集和合并批次，显示已完成区间的同一组曲线、仓位与指标。
- 保留原有旋钮接触点、两侧通路及楼梯落点。柜体、盆体和台面存在真实碰撞，装饰不以整块隐藏盒封路。

## 实际浏览器验证

证据目录：`qa-20261029/exchange-v39/`。

- `hall-before-day/night.png` 与 `hall-day/night.png` 使用同一大厅镜头，比较旧版与本轮的正午、午夜。
- `gallery-day/night.png` 使用同一回廊镜头。书柜、花器、木台边框及屏幕数据可见。夜间保留窗外暗度，阅读台与钟墙维持暖光。
- 在线数据为 SPY 的 752 个历史交易日，范围 2023-05-02 至 2026-04-30。实际取票后，通过步行携至交易台插入，再真实拨档、封存、击钟、操作回廊旋钮。
- 本轮验证到首个已完成区间：2023-05-02 至 2024-04-30，持有 10 份虚拟单位，区间损益 +221.838185，曲线含 251 个历史点。共完成 6 次实体接触。没有用未来区间填充复盘图，也没有执行真实交易。
- 为缩短重复路线，已插票之后使用开发验收按钮到达钟与回廊；该部分不能声称是全程无传送步行。取票到交易台的携票路线为实际步行。
- 早先回廊往返已观察到 x=43.04 至 70.67 的多个落脚点保持着地；本轮新增测试还每隔 0.25 米检查后排两条通道、两侧连接及旋钮前方的实体胶囊净空和地面支撑。
- 开发版最终 33.883 秒回廊窗口采样 2,033 帧：p50 16.7 ms，p95 17.2 ms，最大 26.7 ms，超过 33 ms 为零。窗口包含静止与短距离往返，没有修改画质或切换场景。详细上下文见 `runtime.json`。
- 较早一次仅保留下来的 180 帧瞬时样本曾有 p95 44.8 ms、最大 75.1 ms；整段窗口当时被另一次诊断覆盖，因此不作为完整性能结论。最终窗口不能证明所有视角、整个岛屿或其他机器都稳定 60 fps。
- 浏览器旧验收标签曾持续失联。在用户解锁刷新后，重新使用同一 Chrome 实例的一个任务标签恢复控制，并关闭旧任务标签；没有同时运行两份 3D 页面。恢复后的开发验收未记录控制台错误。
- 正式构建也已在 4343 实际加载至交易所入口，人物移动及暂停菜单有响应，无控制台错误。HTTP 返回内容与构建文件哈希相同，入口引用的 5 个样式与脚本资源均返回 200。该正式版检查不冒称包含开发版专用的回廊测量按钮。
