普通机位由真实layout与当前适配器派生，先选无长椅遮挡的海堤16号跨，以及含.0778358rad坡度的`rail-beam-5`。相机眼高比理论地形高约1.6m，数值在`rails/baseline/views.json`；实际浏览器构图仍需核验，不把计划机位冒充实拍。

跨度只从现有`railLayout`的实际相邻placement派生，没有第二份53/27配置。旧2m只保留为原碰撞与旧基线的合同；新视觉不做累计长度补丁。新增`bindStreetFacilityCollision`集中原WeakMap／hulls语义，先规范化来源并禁止自绑定。新视觉Builder与完整原代理分离，两LOD的getter均可返回原代理；实际StreetStatic读取L0原代理的positions／indices哈希保持不变，未把只冻结hulls当成全源不变。

真实静态路径：原factory → 本组独立可见构造／物理槽／UV → 原StreetStatic → StreetBatch。动态木梁只在原StreetKnock视觉工厂分支包装，不修改质量／COM／受推锁定／30s复位；其余动态源码逐字一致。实例placement、beam描述、LOD阈值、distance fade均不变。共享Surface／StreetMaterial和纹理所有权不改，不增加运行时逐帧适配。

源检查23项通过，覆盖全部既有族输出／代理、已绑定来源再绑定、两LOD全原代理、首／中／末跨与终端、baseline／legacy、法线绕序、UV面积／圆柱接缝、真实坡梁横销轴线、实际BatchedMesh合并后的slot与UV，以及既有bench／bin／shelter合同。木柱锥顶使用非圆柱端面响应，避免UV在轴点跨周拉伸。技术检查不能证明美术提升。

可见几何改变：海堤两LOD跨度；近景金属帽／套接／底板，木柱销位、近景端纹与长木面。木梁长度／根位置和远景木构形体／三角数保持原样；木构两LOD更新物理slot／UV，角点拆分会改变buffer索引和顶点数量。端纹是有限程序色环，不冒称新增照片扫描。当前保护完整原代理，未声称可见几何等于碰撞几何。
