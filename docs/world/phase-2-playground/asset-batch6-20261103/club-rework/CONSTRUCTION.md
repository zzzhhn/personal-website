# Club 主亭与实体池岸返修

基线 bdd9d2e1378230a96a2ac5241cbd722cdba6a43e。参考是当前项目的 FINNS 式暖竹、低面茅草和浅色石岸，已查看 V3 与 V4 图。V3 便于读搭接与节点，V4 保留圆润屋缘和宽阔浅滩的风格信息。现场空间继续采用当前可玩几何，参考图的家具数与空间比例只用于理解材质和承托关系。

| 设施 | 普通距离需要读清的结构 | 固定合同 |
| --- | --- | --- |
| D-pavilion | 茅草沿坡面从高到低搭接，边缘能看见厚度，竹拱经真实承托连接檩条和屋底 | 原 24 × 26.4 米闭合屋壳、舞池、舞台、控制台、镜球、通路、玩法及相机碰撞 |
| D-basin | 贴水的收边石、其下实体池壁和自然色的周边铺装，坡口仍能辨认 | 原自由轮廓、盆底高程、连续坡口与床的进出路径、水面输入与坐标 |

取证使用真实 `WorldDjcClubVisual` 的 `djc-fabric`、`djc-wood` 和 `djc-stone` 网格。原合批保留线性色和法线，新增米制表面坐标及精确角色。独立适配模块只处理角色 1–7 的构造范围，使用局部材质克隆和原光照，原水面继续使用既有接口，焦散注册在实际绘制的 stone 克隆。浏览器读取实际 mesh 的角色、编译标记、色值直方图、粗糙度和三角面数。Blender 与 GLB 为可编辑及交换档。

`tools/world/djc-pavilion-basin/baseline.json` 是默认正式路径开启分离家具时的实际 builder 指纹，已用 git 从 bdd9d2e 取回的源码逐项复算。
