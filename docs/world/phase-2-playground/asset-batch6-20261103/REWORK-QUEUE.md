## 返修标准

- 已有用户反馈的第五批14族，以及当前已启动的材质返修，直接修弱项。其它条目先查现有真实网页证据；证据不足与实物质量不足分别记载，不把每件旧资产一概认定为失败，也不以旧技术通过免除复核。
- 每件给出具体缺口、源/运行消费路径和预期普通视距下可见的变化。沿用新版 `blender-material-craft` 与 `orchestration-harness`；不要重复发明另一套技术规范。
- 旧画面缺有效同机位证据时，补冻结基线。正确性、美观改善、交互、性能分别记录；原始状态2仅在主协调实际审图及必要运行验证后更新，不提前标“已优化”。
- 保留已确认的场景风格、布局、尺度、座位、碰撞、机制、动画和数据接口。过山车轨道路径/速度/镜头本轮不顺手重做；Alpha仍是现有装配精修，不授权自行发明新岛布局。
- 各线只在隔离分支改自有场景源、对应资产与适配器。禁止从历史会话分支覆盖当前release。跨场景材质缓存、全局光照、统一植被接口由主协调分配。Club植物实现归自然线，主亭/池岸归设施线；共享 `WorldDjcClubGeometry.ts` 的总装入口由主协调合并，不允许双方同时重写它。
- 重型工作沿 `/tmp/bobby-world-phase2-heavy.lock` 串行；每次开始前重新预检资源，不能把历史 warning 当作当前状态。轻量源码/方案/脚本可以并行，浏览器验收使用一个自有页，4341 由主协调最终更新。
- 首样/整组完成或发现跨边界问题时主动回报主协调：文件/提交、真实看过的图、验证结果、仍未解决的缺口。此授权不需要每件重新向用户确认；需要新视觉方向时按项目既有校准流程处理。
