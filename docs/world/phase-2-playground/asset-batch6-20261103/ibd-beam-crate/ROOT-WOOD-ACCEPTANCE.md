## 性能审查的边界

性能线只读复核未见源码集成阻塞：复用原非 normalized Uint8 角色属性，board 编码未溢出；围护角色 1–6、未标记角色 0、地坪和夜光分支保留。组合材质 key 独立，仍用原静态 draw 和卸载路径，没有新纹理/属性通道/定时工作。

木纹增加了分支、噪声及导数/法线运算，过滤到远处均值时仍会求噪声。减少几何不能抵消未知 GPU 开销。本轮没有正常游玩 FPS/GPU 时间结论，budget 是源几何边界。木箱着色坐标原点目前只适配这一只箱，扩展前必须改为每箱局部坐标并复验，不能直接复制当前角色。
