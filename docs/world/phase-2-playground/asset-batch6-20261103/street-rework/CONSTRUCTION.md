# 街道设施返修

基线为 689484b。返修队列与第五批验收给出的当前问题是普通距离收益偏弱。样板选 G-barrier，警示板、支脚和折叠支架都落在步行视线内。先看同机位原图，再决定是否向两类杆件应用同样的构造分面。

| 资产 | 普通距离应看见的结构 | 材质分工 |
| --- | --- | --- |
| G-barrier | 警示板由贴合板背的鞍座连到两副折叠支架。宽截面腿落进鞋座，横向锁撑跨住两腿 | 橙白板保持原色和原反光件，框架分涂层、镀锌和橡胶 |
| G-lamp | 灯帽罩口和悬臂承托关系，杆身、基脚和检修盖 | 涂层杆和灯帽，金属连接件，原透镜 |
| S-signal | 挑臂、两处信号头安装座、背壳与遮光檐 | 涂层骨架、金属安装件、原三色透镜 |

实际消费链由 WorldStreetAssets 生成，WorldStreetFacilityCraft 提供视觉变体并绑定原 hull，WorldStreetKnock 把变体装入 StreetBatch，WorldStreetMaterial 从 aMat 读取表面槽和发光码。几何、碰撞和发光指纹以 CPU 实际工厂输出固定。施工路障作为首件，其余两族等待首件普通图自审。
