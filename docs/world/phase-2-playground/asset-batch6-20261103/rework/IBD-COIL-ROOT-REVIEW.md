五个生产改动文件的差分已读。场景构建追加独立 `aIbdCladding`，实际 static mesh 使用候选材质，原台柜回退与 moving material 保持原路径。`applyCoilBayMaterial` 先运行原材质编译钩子，再追加表面响应和独立缓存键。角色 0 保留原地坪与材质响应。

主协调通过现有 TypeScript 测试加载器重跑几何合同和 21 项 `ibd-yard-art`、`ibd-yard-geometry`、`ibd-yard-safety`、`ibd-stock-craft` 测试。碰撞、步行、地面、站位、楼棚布局与分离台柜几何指纹保持；折板实际凸起约 0.056 m，两处檐口承托检查通过。直接 Node strip-types 的首次复验因无扩展名导入未解析而失败，改用项目现有加载器后通过，没有因此修改产品源。
