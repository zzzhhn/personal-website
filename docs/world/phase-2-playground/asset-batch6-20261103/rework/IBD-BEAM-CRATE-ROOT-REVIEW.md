## 判断

- **横梁：接受本轮构造样板。** 上下翼缘能把旧矩形杆读成有厚度的承梁，柱头承压件与原柱、暗轨连接在近图可核对。午夜端部仍暗，但连续翼缘与承托关系未消失，不以强行增加照明作为通过条件。此结论不代表整套吊机的材质/造型已完成。
- **木箱：构造方向成立，材质精修未通过。** 四层板、侧端、角柱和托脚较旧版具体，但正面/侧面大片木面仍接近平色，普通距离不能明确读出木材表面。顶点颜色的 2×3 分块与正弦变化没有达到此次材质升级要求。退回作者，仅修这只箱的方向性表面、端面与板间物性区分，保留已建立构造；不能用拉近镜头或更改曝光替代普通视距提升。

## 成本与证据边界

候选同时开启两个独立 QA 开关。静态几何从 47,329 增至 48,385 三角形，梁 +88、箱 +968；属性/索引合计从 6,957,565 增至 7,131,421 B。代表夹具 76,023 超出现有 75,000 的作者检查阈值。主未修改阈值，也不要求先削可见结构；性能线继续核查实际消费、覆盖与合理成本控制。

四对截图 draw calls 分别仍为 65/58，但 render triangles 增量为 3,168/3,148，不可直接等同于静态增量或 GPU 帧耗。所有记录均有 29 个场外资源加载失败，作者说明 IBD 设备/箱体已补齐；本组图只能作为这些 IBD 样板画面证据，不证明全岛完整或性能无回退。

作者提交的固定碰撞/走面/铺地哈希一致、27 项测试通过及 GLB 回读结果先按作者证据记载；主尚未独立重跑候选碰撞/预算夹具，性能线将确认现有测试是否实际启用候选。素材与源保留隔离分支，不为本次评审在主根重复复制一套资产。

### 性能线轻量审查回报

性能 session 已完成只读源与记录核查，主结合已读源码接受其范围内结论：两件沿同一静态 Builder 的 color/aMat，未进入围护角色标记，角色 0 沿用旧物性和夜光通道。没有新增材质批次、纹理、实例或每帧任务，属性随既有静态几何统一释放。它不能证明未知下一版木材 shader 的片段成本。

现有 27 项自动测试没有 `bridgeSample` / `crateSample` 入口，属于既有回归；启用两个候选并逐项比较固定数据、执行射线检查的是 `export-beam-crate.mjs`，不是这 27 项测试。主已把这一证据区别回传作者。梁单独代表夹具估计 75,055，箱单独 75,935；这些是静态增量加既有夹具的估算，未据此提高预算。

性能线指出 21 个外露板面为顶点色各分为六 quad，若方向性表面由材质表达，每面改单 quad 可去约 210 三角形且保留实体板缝。该建议交作者随材质修正评估，未自动实施，更未把节省算入结果。下一候选应独立开启木箱、记录实际角色和材质消费；若以后需要帧耗结论，再安排同状态短窗测量。
