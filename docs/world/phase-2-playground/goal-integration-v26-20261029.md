# 国投逐槽检验 v26

延续已经批准的国投作业场、现有角色与工具风格。本轮完善实体检验动作，没有扩大园区或另起视觉方案。Alpha 交易所继续使用已交付的 v25。

## 实现

- 一箱四个独立槽位。托架将所选槽的样件先抬起、越过箱沿，再降到身前，随后角色取样、夹量、放回原槽。后排样件由呈样机构送到手边。
- 玩家调节夹爪，实际间隙与样件杆径贴合后才记录规格。不同规格和空槽保留原有案例含义；空槽要完成呈样查看。所有槽位检查并归位后，才提供整箱的件数、规格和现场判断。
- 左掌携带样件，右掌接触卡规推片。动作以现有物理时钟推进，使用现有 G24 骨架的上肢 IK 和编排曲线，不声称增加真人动捕。骨长和下肢不变。
- 每次提交核对当前货物、轮次、revision、真实角色位置、姿态和双手世界坐标。走远、失去着地、切换模式、重置或换货不会接受迟到回调。
- 「归位并退出」将未检验样件放回，不伪造完成；回营地可以清理未完成动作。已完成槽位保留到本轮结束。
- 拆检时自动切入有碰撞检查的近景，台前标牌降到低位，隐藏重复的中央操作提示。滑杆直接控制场景里的夹爪，退出后恢复原漫游镜头。
- 复用原有货台、运输碰撞、灯光和材质。没有新增刚体、实时灯、反射相机或 UI 轮询；闲置呈样部件与已附着到手掌的样件跳过重复变换计算。

模型尺寸为游戏内夸张比例，不是实际毫米读数；四槽作业是原创玩法，不将其描述为真实实习中的工业鉴定流程。

## 验证

相关测试共 132 项。首次全量为 131 通过、1 失败：地块测试还使用旧的 35k 常量，而项目统一静态预算已为 48k。该测试改为引用现有 `IBD_GEOMETRY_BUDGET.static`，预算没有增加；该文件重新执行 3/3 通过。严格 TypeScript 检查、音频构建前检查、正式 Astro 构建及 diff 检查通过，构建仍有既有的大 chunk 提示。

测试覆盖四类订单、192 条引导恢复路径、实际 Rapier 胶囊通路、G24 双手接触、M6/M8 与空槽、取消、换货、迟到回调和音频重复提交。控制器测试中的掌坐标替身与实际骨架测试分开，不以替身测试冒充浏览器体验。

浏览器 DEV 实操：先使用现有 QA 接货台定位，实际步行取工具，再用 QA 定位 A 箱；之后以正常操作完成四槽取样、错误间隙拒绝读数、正确夹量、归位、整箱判断，并绕开滚轮床步行到装车杆完成装车。再步行到 B 箱，完成未夹量样件的归位退出，确认没有槽位被误记为完成。[装车状态](qa-20261029/ibd-v26-pack-a-loaded.json) 仅证明 A 箱已装车，其中槽位详情因 HMR 清空调试选项没有保存；不能把它称作完整接触轨迹。[取消状态](qa-20261029/ibd-v26-cancel.json) 保存了四槽均未完成且无持物的结果。

正式打包版关闭 QA 后，从园区入口步行领取货单和工具，关闭带路，走到 A 箱，以正常 UI 完成开箱、第一槽取样、夹爪调整、M8 读数、归位退出。没有使用调试传送或强制完成。控制台错误为零。[正式版检验画面](qa-20261029/ibd-v26-production-inspection.png)。空槽及 M6 由状态、几何和真实骨架测试覆盖，本轮没有重新逐一浏览器走完整个异常订单。

### 交互设计检查

| 检查 | 本轮处理 |
| --- | --- |
| 意图、负担、单一主动作 | 四槽选择；主按钮按取样、夹量、归位顺序变化 |
| 状态、可发现性 | 动作进行时禁用重复提交；槽位完成标记；近景直接展示实物 |
| 容错、节省时间 | 原位退出保留已完成槽位；错误夹量可立即调整；不重复开箱 |
| 轻界面、无需手册 | 复用随身货单，只加一句操作说明，不另开多层弹窗 |
| 无暗设 | 未夹紧不会给规格，明确提示如何修正 |
| 跨界面一致性 | 延续中文／英文、昼／夜、现有字体与侧边货单结构；无新增导航入口 |
