你不是唯一开发者。保留别人已有改动，不覆盖其他线的代码。共享文件确需改动时限制在所属功能，交接标明触点；需要改变接口或职责时向主 session 汇报。

## 本机资源

当前内存压力 warning、可用磁盘不足 20 GiB。代码阅读和编辑可并行，重型本地任务串行。

- 浏览器、Blender、图片服务、构建／运行测试前，执行用户指定的 `codex-resource-preflight.py`，先检查已有实例和标签页。
- 所有开发 session 使用共享临时锁目录 `/tmp/bobby-world-phase2-heavy.lock`。用原子 `mkdir` 取得锁，写明 session 和用途；只在持锁期间启动重型任务，结束后移除自己持有的锁。锁被占用时继续轻量工作，不能删别人的锁；疑似失效向主 session 报告。
- 主 session 的 4341 试玩服务与用户页面保留。各线如需临时服务，建议人物 4342、驾驶 4343、美术 4344；验证后关闭自己的临时服务／浏览器，不留三套渲染同时运行。
- node_modules 可以复用基线的依赖链接，不在共享链接内重新安装或修改依赖；确需新增依赖先协调。
- 若使用 subagents，遵守用户指定模型：Sol 使用 gpt-6.1-sol / high；Luna 使用 max 或更高。不要为满足流程而增加代理。
