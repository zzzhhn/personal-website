## 地表与海水着色

旧测试在当前版会因截取的材质工厂拿不到 `clubBasinMaskUniforms` 而退出。新测试由 Node 启动独立 Chrome，用同一相机和受控的扫描、岸距纹理及时间比较材质样本。将实际地形顶点的草和沙权重外推到三角边外，得到 `[-0.125,1.125,0,0]`，将该权重送入 WebGL 后读回的法线与纯沙一致。两张不同覆盖范围的水面图在 256 个相同世界位置比较，短浪随像素覆盖范围衰减时，法线平均差值约 0.01722，旧版长浪对照约 0.00013。近岸泡沫粗糙度约 0.92，角色触水提高水面亮度，扰动到期后恢复原像素。读回的深度也确认风驱动的位移在两个材质模式下相同。

只在测试服务器返回的模块中注入三项故障，均触发相应断言。删掉负权重钳制后，外推沙地法线的编码横向分量从 0.40886 偏至 0.40989。去掉透明孔的混合后，孔中心的 alpha 从 0.42 变成 1。把短浪衰减移到过粗的像素范围，两个采样尺度的法线平均差降到 0.00028。复测 5 项通过，另有 35 项独立边界、波形、接触、光学和诊断检查通过。

在仓库根执行 `WORLD_BROWSER_MODULES=<安装 Playwright 的目录> node tools/world/nature-craft/ground-water.test.mjs`。可用 `WORLD_CHROME` 指向本机 Chrome。此项在独立的小画布用软件 WebGL2 编译、绘制和回读，单次约 22 至 24 秒。普通 Node 门禁仍可独立运行，无需浏览器。
