# 城岛行为测试盘点

在游戏提交 `02828b5` 的 `src/components/world` 和 `tools/world` 下，通过 Git 文件树枚举文件名以 `test.mjs` 结尾的 298 个文件。50 个含 `readFileSync`、`readFile(`、`createSourceFile` 或 Git 的 `show` 字面量。以相同方法复算 `06dd82f`，303 个文件中有 47 个命中。这个数量也包括 GLB 加载辅助文件和读取二进制数据的行为测试。间接从 fixture 截取代码可能躲过这次文本筛选，因此不能把命中数当作剩余缺陷数。

| 故障 | 当前检测方式 | 后续 |
| --- | --- | --- |
| 栈道近远变换错误、材质 LOD 掩盖穿模 | 运行完整的栈道组件、实际 Three 批次和 Rapier，按景物姿态射线和胶囊复走。 | 继续保留正确的资产指纹，核对间接测试宿主。 |
| 营地资源重挂时过早释放材质，或者销毁共享几何 | 从公开组件渲染已发布 GLB，先卸载、立即重挂，再走真正的微任务队列。逐个计数，确认各材质只释放一次，原 GLB 几何保持可复用。 | 与行李箱接触贴花共用宿主。材质像素另用 WebGL 验证。 |
| 山路木护栏被行人推走、车辆撞不动或回位后仍醒着 | 旧套件拿整个控制器和 `97c9546` 的代码比较，也因无关的长椅哈希失效。替换后装配当前斜木梁，在 Rapier 检查质量、重心、行人锁定、接近车辆解锁、受力偏移及 30 秒后的回位休眠，同时比较近远顶点和实际绘制槽。 | 原有海堤段端点、木表面 UV、连接销与坡梁垂直等独立断言继续跑。 |
| 货场或交易所待机仍每帧重写几何 | `idle-prop-updates.test.mjs` 从 AST 截取局部初始化器和帧回调。 | 接入完整导出组件，保留真实 Three 节点的写次数及换手、换父节点、资源更换用例。 |
| 恢复窗口时物理追赶长时间停顿 | `world-resume-time.test.mjs` 执行 R3F 的真实帧分发，但从已安装的 React Rapier 提取闭包。 | 增加真实 Physics 组件暂停及恢复样本，对照固定步数和恢复后第二帧，再移除闭包提取。 |
| 地表和海水程序正确编译但结果改变 | `ground-water.test.mjs` 截取材质工厂，与 `362e68d` 的 GLSL 字符串对照。 | 同一相机、受控纹理和时钟下渲染浅岸、沙地、水面透明孔和移动扰动，再代替字符串检查。 |
| 资源变坏、音频误入启动包、核心反向依赖场馆 | 地形与洞体解码、真实音频文件校验及 bundle 依赖检查涵盖独立故障。 | 保留。行为与依赖方向各自报告。 |

行为测试覆盖已进入 `npm run check:grounding`。固定机位运行使用相同的画质、视角和曝光。键盘路线、合成故障、同机性能以及目标机的待验项分别记在[区域实测](readiness-audit.md)、[交互记录](interaction-audit.md)和[工作机台账](workstation-20261119.zh.md)。
