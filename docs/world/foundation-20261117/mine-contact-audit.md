# Alpha 矿区入口工具架与西坡道碰撞

从公开矿区入口 `/world/?start=brain` 穿过入口栅栏，沿前场往左到工具架。按一次 E，角色走到探测器把手前并取得探测器和镐。离开工具架后沿西侧木坡走到中层，再回到前场和低层通道。生产版实键路线完成了取工具和登中层。坡上最后一个采样点的角色中心高度为世界 y=4.866 米，角色保持落地。

原始 Draco 包保留。只从木材、金属两个合并批次拆出五段索引，继续使用原顶点和材质属性。区域旧 `surface`、`solid` 对应的原数组与作者输出已逐数比较，两个大碰撞体仍供到站检查。与本批零件对应的旧平面和 46 个盒已经从大碰撞体移出。

## 校验范围

- `alpha-mine-entry-tool-rack` 和 `alpha-mine-west-ramp` 各有两个具名固定碰撞体。生产构建中工具架的 17 个真实工具材质网格在取用后离开原架，木架和钩的两个碰撞注册持续有效。无矿区子根校验错误。
- 36 项定向和原有矿区回归通过。真实标准胶囊沿西坡、箱子东侧到坡脚、西侧低层出口双向、峡谷回前场连续步行，并通过原有拾取和矿区内部低层出口检查。独立生产构建和 TypeScript 检查通过。
- 日夜固定机位的相机和曝光一致，四帧逐一对照。矿区范围的未分类提交网格均从 49 降至 32，未分类挂载网格从 65 降至 48。工具架和西坡道各有两个活动注册。近处入口传送门遮住一部分工具架，因此实际取用另由普通键盘路线验证。
- 矿床的三档模型、其余坡道与桥、水池、标牌及效果仍属各自后续审计范围。此轮严格校验限于入口架和西坡道，不覆盖矿区总根。

接触配对可用 `node tools/world/alpha-mine/build-contact-sources.mjs --check` 复算。测试和浏览器证据位于 `mine-contact-tests.log`、`mine-contact-play.json` 和同名机位帧。
