# 货场静态合批、围栏和高廊接触

生产静态合批的 73,489 个渲染三角形现可逐段追到实物与通行属性。66,857 个三角形参与 74 个具名接触面，覆盖原有三仓和货架、滚床、铺地、高廊，以及补齐的围栏、花槽、灯具、车道护栏、观测仪、标牌和固定控制面。原 153 个剩余盒体由同批实体网格接替。顶点、索引、材质和原来的单 Draw Call 保持一致。

| 旧物理漏接触的实物 | 当前实际命中 |
| --- | ---: |
| 西北围栏第一段斜撑的交点 | 0.432000 米 |
| 高廊坡道右侧两横档之间的立柱 | 0.650002 米 |
| 主入口两根柱之间的横招牌 | 0.709999 米 |
| 西花槽外伸压边 | 0.650000 米 |
| A 秤柜上方的操作面 | 1.104872 米 |

同姿态下，当前的实物画面与 Rapier 射线最大差小于 0.02 毫米。主入口中央走道、东侧低排水缺口、发运仓的侧口、两条滚床横通道和高廊平台保留可通的实际宽度，并通过实际玩家胶囊的连续扫掠。五类路面标记、三处低排水篦和排水洼地使用下方可踩实体，两处花槽和洼地的叶片保留柔性通行。印刷板面、货单、可手取检验工具和引导标记分别保留原游戏行为。

生产页从公开货场入口用 WASD 沿广场西侧登上高廊，绕过后卷观测仪立柱抵达前卷观测仪。17 个记录点均落地，两个观测仪附近的角色中心约 5.919 米。旧直线曾穿过后卷立柱，新增实体会在原直线挡住角色，指引线随实测净空移到高廊内侧。两根装车杆的指引站位各向走道退 30 厘米，避免伸出的台盖。原 E 锚点和触发距离保留，所有四轮任务的引导路径已使用当前静态、工作台、货车和货箱碰撞扫掠验证。

静态合批的严格归属为 `ibd-static-yard-contact`。停放货车和工作台各由已有独立根负责。本轮的固定秤面和手动操作柜底座属于静态模型，运动吊车、钢卷、箱体、箱内的可持样品及发运升闸仍在 `ibd-mechanisms` 的独立核查范围。

独立生产 4380 的货车昼夜固定机位各有 74 个有效接触注册，货车前后画面 8 位 RGB 逐像素一致。货车机位的货场未分类提交从 12 降至 11，营地机位从 33 降至 32，两处未分类挂载均从 61 降至 60。其余 60 项来自动态机构。全部 200 项 IBD 回归通过，TypeScript、差异检查和生产构建通过。

取证为 `ibd-static-yard-contact-tests.log`、`ibd-static-yard-contact-all-tests.log`、`ibd-static-yard-contact-guide-tests.log`、`ibd-static-yard-contact-direct-block.log`、`ibd-static-yard-contact-frames.json`、`ibd-static-yard-contact-walking.json` 和生产昼夜 PNG。
