# Alpha 交通载具和接驳实体碰撞

本批检查渡船、缆车和雪橇。保留三套现有 GLB、景观、乘坐姿态、出入口和主运动轨迹。缆车在舱门内增加避开扶手和抬脚板的转折，保留原乘坐点前的站立位置。过山车继续由其场馆处理。

| 路线 | 修前复现 | 修后实测 |
| --- | --- | --- |
| 大陆木栈桥 → 渡船 → 山岛 | 真实 GLB 船首甲板伸到局部 X=3.60 m，旧统一甲板止于 X=3.50 m。从 X=3.54 m 向下的旧形状射线不着地。外栏与柱子也没有相应碰撞。 | 船的 45 个可见源部件共 5,842 个三角进入一个移动碰撞体。原测试点命中真实船首，栏杆位置阻挡横向扫掠。大陆与山岛两端原踏板、过舷开口和走出路线均通过实际胶囊检查。 |

三套移动模型目前分别使用同一套 GLB 材质合批，视距变化时无独立近景或远景网格换档。每件渲染源记录索引范围并引用本车实际装载的 collider。角色和载具都使用轨道同一个采样位姿，缆车夹爪另外采样与画面相同的局部关节俯仰。六段采样位置用于核对推进后的物理和渲染甲板。没有改资产文件。

舱体网格没加载或失效时站台不会提供登乘，已接管的行程和空载调位暂停，重挂后继续。Rapier 用例验证载具碰撞缺失、传感器化、刚体禁用、旧碰撞移除和真实重挂。11 个独立严格根进入全图检查，昼夜图集等待三套实际载具模型、两处固定顶棚和六条步道。

## 验证

- 交通/乘具套件 51 项通过，包括实际打包 GLB、同组碰撞合批、六个终端、真实 Rapier 安装与重新挂载、实物船岸包络、雪橇滑槽净空、坐姿、相机、阻塞后继续、跳过到站和到站落脚。复跑命令为 `node --import ./tools/world/alpha-mine-tests/register.mjs --test --test-concurrency=1 src/components/world/alpha-island/transports/*.test.mjs src/components/world/rides/ride-passage.test.mjs src/components/world/rides/transport-driver.test.mjs src/components/world/rides/transport-boarding-motion.test.mjs`。
- 独立生产构建输出 8 页，全仓 TypeScript 和 `git diff --check` 通过。默认 V4 与 V3 的生产 Chrome 都读回 11 个交通严格根和 20 个有效 collider，交通组错误为零。V3 可在浏览器复跑命令后加 `--registrations-only --layout=v3`。
- 隔离生产 Chrome 1440 × 900、默认 Balanced。QA 仅把胶囊放到真实登乘口，随后用真实 E、HUD 跳过行程和 W。渡船、缆车、雪橇均成功穿过到站出口，胶囊接地，按 W 实际走离 1.42 m、1.61 m、1.61 m。复跑命令为 `WORLD_BROWSER_MODULES=<Playwright 所在项目目录> node tools/world/alpha-island/transports/vehicle-collision-browser.mjs http://127.0.0.1:<生产端口>`。

### 普通营地出生到渡船双向往返

两根 L01 固定灯柱之间是正式营地出口。旧版即使避开柱子，也会卡在铺装起点 x = −30 的竖面。Chrome 在 z = 34.42 和 z = 35.68 两处读到约 4 cm 的高度差，接触项为 `paving-v4-3-top` 与 `paving-v4-3-walls`。步行者脚底仍在 y ≈ 4.80 的草地上。修复 `501acce` 在原铺装内用 0.75 米接坡连接草地与 y = 4.84 的原路面，渲染与碰撞共享顶面三角，铺装外侧立面及灯柱、越野车位置保留。同样的发布地形和角色胶囊沿 z = 32.20、34.42、35.68 实测。旧版从草地进坡的三条线卡在 x ≈ −30.16。修后六个双向样本全过且始终接地。

修复后的独立生产 Chrome 从默认营地出生体心 `[−41.999,5.619,35.007]` 起，用 WASD 穿过两灯中间，绕过停放的越野车，走下坡后沿沿海公路绕开抬高的 Contact 地坪，再走上大陆木栈桥。21 个步行点均接地，无跳跃、传送或物件调整。大陆登船前体心为 `[−10.090,1.960,108.812]`。在两端分别按真实 E 并点击 HUD 的 `Skip travel to arrival`，山岛接地 `[156,2.348,148]`，返程在大陆接地 `[−10,1.960,109]`。返程后按 W 走离 1.241 米，页面错误为零。

生产 HTML 的 SHA-256 为 `75f121102f9c8cf8d868bbee7129aa52cebc100677d6e05a6234f9fe8ef31c5c`。原始逐步输入及两端登乘记录为 `evidence/city-foundation/transport-ferry-public-roundtrip.jsonl`。复跑命令为 `WORLD_BROWSER_MODULES=<Playwright 所在项目目录> node tools/world/alpha-island/transports/ferry-public-roundtrip.mjs http://127.0.0.1:<生产端口>`。
