# Alpha Agent 交易所接地与碰撞

## 普通玩家路线

从公园木栈道拐上 3.1 米宽的入口桥，过门廊和正门，沿低坡下到圆形交易台。由西侧档案台取票或走到后排抽屉。回到大厅，经中央后坡到开盘钟，从东侧门下坡，越过石铺外缘走上岛地，再沿同一路线返回。楼上复走西坡、东阶和后廊。

## 修复依据

| 位置 | 交接构建和修复前物理结果 | 修复和回归 |
| --- | --- | --- |
| 侧门至岛地 | 原实测只走到外侧铺地 `x=84.2`。加入真实岛地并继续向外走后，角色在 `x=84.680, y=1.930, z=-88.999` 失去支撑。铺地外缘比地形高 14 厘米。 | 加 0.6 米同材质缓坡，末端取渲染地形三角面的高度，坡面与侧面的可见三角形直接进入实际碰撞。中心线及左右各 1.5 米的路线均双向连续接地。 |
| 正门门廊、平台与两层楼板 | 入口路线基线通过。`site-exchange-foot` 昼夜各有 20 个交易所已上镜网格未分类，同一场馆也有镜头外组件。 | 实际桥、门廊、正门、入厅坡面、楼板及台阶从同一来源生成可见批次和碰撞分区。保留楼上及下方地面的独立查询高度。 |
| 圆形交易台操作轨 | 从交易台站位一侧在轨道高度投射，渲染首击约 0.3755 米，Rapier 命中后方键盘约 0.5405 米，相差约 16.5 厘米。 | 操作轨、固定脚和黄铜票口边框使用可见实体面。保留约 5 毫米的台沿装饰嵌条为 `none`。 |
| 档案台票口 | 同一条射线扫过可见黄铜托板，原 Rapier 查询未命中托板。加入实体面后，原站位上的胶囊会重叠票托。 | 可见票托和两侧票口框进入碰撞，脚点后移 8 厘米，手取点仍落在纸票范围内。档案室四个原有抽屉继续使用其真实抽屉底、前唇、侧壁和后板。 |
| 清算台和后廊钟 | 清算台实体柜体背后仍有视觉独立的出纸托板和导轨。挂钟壳与黄铜外框已具有实体面，但在审计中无法定位其所属范围。 | 清算托板及导轨用可见实体面，站位后移 4 厘米留出胶囊空间。纸回执与取件锚点按托面定高，上移 2.75 厘米。分开记录挂钟外壳、边框和图集表盘，保留纸片和动作驱动机关的通行行为。 |

每段合并建筑几何都有三角形范围。穿行支撑面映射到 `alpha-exchange-surface`，其余实体面映射到 `alpha-exchange-solid`。两者和渲染物都使用同一入口原点。12 块独立排序的玻璃各自绘制共享缓冲的实际范围并复用同一实体碰撞体。招牌、图集平面、薄嵌条和纸片为 `none`。按动作时钟转动的滑块、铃和清算压印件继续使用交互锚点，玩家胶囊与它们所在的固定工作台、支架和柜体接触。

## 验证和余项

```sh
node --import ./tools/world/alpha-mine-tests/register.mjs --test src/components/world/*exchange*.test.mjs src/components/world/facility-site-contact.test.mjs
```

- 来源测试要求每个可见范围连续、所有 Rapier 三角形各有一段对应来源，并逐顶点比对两边坐标。空间测试在世界坐标比较 Three.js 与 Rapier 首击，门槛、坡道、上下两层、交易台、票托、挂钟外框、玻璃与四个抽屉的容差为 1 毫米。还验证清算回执底面落在托面。
- 路线测试运行实际玩家胶囊、移动与接地逻辑，以及与运行时同源的岛地形状。侧出口三条线位与既有桥、正门、交易台、钟、东阶、西坡及回廊回归均有覆盖。键盘操作、逐步手臂姿势和跳跃擦碰动态机关仍待实际试玩复核。
- 交易所根节点进入严格盘点。公园木栈道的物理依然由 `park-walk` 管理，外围地形由主岛地形组件管理。交易所内部回归覆盖两处接缝，整块公园和全岛仍需各自验收。
- 生产构建的 `site-exchange-foot` 昼夜均从 20 个交易所上镜网格缺口降到 0，已挂载交易所网格也无缺口，严格盘点认出两个实际注册。固定机位复看可见的西侧外立面与地脚，东侧坡末端通过胶囊和网格探测核验。目标机的普通 Balanced 路线和手感待统一实测。
