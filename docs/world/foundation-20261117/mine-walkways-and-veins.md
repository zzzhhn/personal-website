# Alpha 矿区坡桥与三层矿床

从前场上西坡，向东跨中层主桥，再上东坡到顶层。外侧路线从西廊的两段坡道登顶，跨北峡谷桥后先在东岩台的内侧转弯。下层矿床从工具架沿前场和低层通道抵达，按 E 探测，再按三次 E 开采，最后用 E 从石托盘取矿。

## 坡桥、扶手和桥下

七段木结构均使用出货 Draco 网格和原摆位。每处的板面与扶手、立柱及桥下木架各有一个具名三角碰撞体。绑带与螺栓的可见范围单独保留，其附着的实体木构仍提供角色接触。旧的七张连续斜面、木构盒和对应托盘三角面已从原矿区大碰撞体移出，其余区域沿用原数据。

沿板缝中心的 306 条短射线，在旧版全部打到连续面，在新版全部贯通。往相邻板心下探均接触实木。80 条侧向探测命中实际扶手。西廊跨接桥两端保持原有 1.55 米栏杆留口。标准角色胶囊从主线入口连续步行至顶层，双向约 98 米。生产版由普通入口实键走完整段主桥和东坡，最终在顶层平台落地，角色中心世界高度 y=7.959 米。西廊到北峡谷桥和东岩台的双向路线约 92 米，矿区低层出口也保持通行。

原诊断线路在东岩台 x=17 米折向，角色带前冲到原有下降崖面，旧版与新版都能复现。验收路线将转弯点放在仍为水平的平台内侧 x=16 米，原岩台形状保持。

## 三层矿床与拾取

每层石托盘使用当前可见网格，另有一个矿面碰撞体随完整、开裂和打通状态切换。每档只有当前显示的岩面和矿物材质批次挂载，三种形状共用稳定的具名注册。局部打开的凹陷沿用原艺术网格，矿石仍由既有拾取交互处理。

| 矿床 | 旧物理相对画面的中心偏差，完整 / 开裂 / 打通 | 新版对照 |
| --- | --- | --- |
| 下层 | 40.5 / 31.0 / 20.0 厘米 | 三档均命中当前面，打开后站在本层可伸手取得回声矿。 |
| 中层 | 40.5 / 31.0 / 20.0 厘米 | 三档均命中当前面，低一层和高一层的站位不能取到本层托盘矿石。 |
| 上层 | 36.7 / 27.2 / 16.2 厘米 | 三档均命中当前面，托盘的实际高度和原有拾取范围吻合。 |

新版九组中心射线的物理接触与可见面最大差小于 0.003 毫米。三层分别验证打开状态的标准胶囊拾取站位。独立生产版从普通入口实键取工具，在下层依次探测、开采三次和拾矿。实际 Rapier 顶点散列跟随三档改变。每次查询下层依旧只注册矿面和托盘。矿石取走后，托盘保留，界面切换为持矿返回回测池提示。

入口工具架加七段坡桥和三层矿床，共 11 个严格子根，22 个活动碰撞体。同机位昼夜都检出这些注册。相机和曝光完全相同，矿区未分类提交网格从 32 降到 26，挂载未分类网格从 48 降到 30。原始 `quarry-static.glb`、`veins.glb` 的顶点、材质和摆位未改写。其余岩体、回测池系统及标牌和效果仍在本批以外。

现有及新增矿区测试 56 项通过，覆盖坡桥、低层出口、三种矿面、各层拾取以及矿区玩法状态。来源提取、独立生产构建和 TypeScript 检查通过。证据见 `mine-walkways-and-veins-tests.log`、`mine-walkways-and-veins-mine.json`、`mine-walkways-and-veins-hike.json` 和对应昼夜帧。
