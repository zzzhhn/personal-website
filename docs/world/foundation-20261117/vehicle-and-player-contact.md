# 可驾驶车辆与 G24 接触

| 实物 | 接触来源 |
| --- | --- |
| 越野车、跑车、厢式货车车体 | 保留原车身主要凸体、原降重心和质量载体。车体合批的近远模型按实际接触来源追溯三角形。凸体外的小件单独注明用途，灯光贴图、加速尾气和内嵌手控开关各有分类。 |
| 越野及厢货车顶架、厢货警示灯 | 两台车原车顶架的单个凸体改为从实物取出的杆件、支脚和备胎分段凸体。原凸体的摩擦、弹性和零质量保留。厢货警示灯独立生成具名步行接触，随车体移动。 |
| 六扇车门 | 从实际车门顶点拟合封闭凸体，偏移和旋转使用相同铰链与开度。开门请求保留原路径与扫掠。人车换位期间由原有转移动画接管，门叶的附加接触仅作用于启用的步行胶囊。 |
| 十二个轮胎 | 每个实际轮胎实例与自己零质量的可见几何凸包配对，位置、转向、滚动和左右镜像都采用原悬架输出。车辆与地面仍由原射线悬架和车体凸包负责，轮胎接触仅给步行胶囊提供响应。 |
| G24 | 可见角色部位共享原半径 0.34 米、直段 0.96 米的中央胶囊。手持票据、工具和矿石由现有持握动作控制。上车、入场等待、落座、乘具停用的胶囊会核对真实注册和持有状态。模型加载失败时可见低成本胶囊提示当前接触，玩家刚体停用时提示隐藏。 |
| 车辆资产加载与回退 | 模型未就绪时，回退车身以原凸体的可见几何和灰盒材质呈现。回退轮胎用同尺寸十边外轮廓，挂载 GLB 后再绑定实际轮胎与门叶。旧驾驶试验参数继续使用原盒体。 |

车体近远六份可见几何均能追溯全部对应物理件。归属用三角形重心的凸面距离判断，8 厘米是原凸体归属采样的上限。远模型简化了越野车顶架的六个小支脚，场景继续保留其实际近景数据和接触，免去远景绘制。门叶关闭、半开、全开共 18 个实际射线命中与可见面相差至多 9.71 毫米。胎侧指定测点，凸包与近景轮胎横向表面的差为 4.0／2.4／1.6 毫米。旧凸体在三种轮胎的实心部位及六扇全开门叶均存在漏检，新增接触在相同坐标命中。

车体尺寸、原质量分配、质量中心、悬架与驱动参数沿用原值。独立 Rapier 支撑对照在质量、重心、惯量和静态高度得到相同值，步行胶囊在加入轮胎后先碰到胎侧。G24 的胶囊是步行与支持面交互的稳定包络，手脚等动画部位仍按现有动作贴合。

普通构建的三台车及 G24 共 29 项挂载网格的未分类数归零。凸块版应登记越野 39、跑车 16、厢货 33 与玩家胶囊 1。轮到 E 上车时，玩家胶囊由驾驶状态持有，登记为暂停接触。落地后同一胶囊恢复为活动接触。

对发布大陆地形的 599,708 个三角形和三台发布车辆执行连续碰撞检测。每物理步中位数为原车身 0.690 ms、动态精细三角网 44.415 ms、独立凸块 0.805 ms。Rapier 在此工况仍会用到刚体中逐个停用的三角碰撞，停用后的中位数为 40.725 ms。

独立生产场景使用实际南侧滨海环路，先设测试起点，再用 E、W、D、Space、E 依次上车、行驶、转向、制动和下车。记录包含实际四轮支持、接触计数与位置。浏览器负载使按键在物理步之间的落点变化，短程位移只作通过性证据。42 项专项及相关回归、TypeScript 和生产构建通过。

同时给 G24 和车辆六份近远 GLB 返回实际 404，仍能建立越野 15、跑车 14、厢货 16 组车身及轮胎接触，以及玩家胶囊。记录列出了故障注入产生的已知资源异常，已加载场景的接触账簿无错误。

可复跑入口为 `tools/world/playtest/vehicle-contact.mjs`。日常场景用 `normal`，旧构建用 `baseline`，真实资产 404 用 `fallback`。几何探针为 `src/components/world/world-vehicle-contact.test.mjs`。
