# 园区 P13–P18 装置接触

旧版课程棚的固定三角网只有 P18 的外架和讲台。Chrome 中，在正常提示处按 E，板面静置时的可见命中距离是 0.878 m，转到 1.111 rad 时是 0.447 m。同位置的 Rapier 探针两次都落空。新版本从同一份 GLB 取木框、板心和两侧板面，将三角形变换到实际转轴，再随原有课程翻板动作驱动一个运动刚体。板面转动范围内有人时会停并提示让开，角色退开后继续这一轮翻板。板身与支架分别注册。旧提示中心离轴 90 cm，会在接近水平时被角色占用检测挡住。提示中心沿棚口方向外移 15 cm，为原翻板动作留出空间。

| 装置 | 接触来源 |
| --- | --- |
| P13 评审台 | 台身、两块屏幕与屏壳归固定面。按钮随下压和回弹移动。票数柱与薄箭头分别是外壳内的显示和台面上的指示。 |
| P14 DJ 台 | 台身、两个唱盘和推杆归固定面。原有唱片箱保留可推动凸包，由同一渲染几何生成并沿用原质量与复位。 |
| P15 唱片墙 | 墙架固定。九张唱片的碰撞各随它所显示的位置。当移动路径有人占用时暂停交换。连接软线为柔性视觉件。凳子继续使用原有可推动凸包。 |
| P16、P17 双椅与灯 | 两把椅子的固定接触沿用原几何。侧桌、灯座及玻璃罩归固定面。内部火焰只发光。 |
| P18 课程板 | 立柱、底座与讲台固定。板框、板心及两侧板面共享一个同轴运动三角网。 |

固定面沿用原始三角形和摆放矩阵。分批渲染仍由原来的几何合批提交，每段指回原来的 GLB 部件和实际碰撞注册。Rapier 回归读取六份随游戏发布的 Draco GLB，核对所有命名部件的接触分类。P18 在九个姿态测了 54 条板面、木框及留空射线，最大边界差为 0.000002 m。真实角色胶囊于第 18 物理步停住翻板并保持原位，让开后完成半周。P15 下排唱片完成了同类挡路和继续移动的回归。
