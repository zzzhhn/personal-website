# 城岛角色与区域就绪

基线为 `dc8d8d4f`。本轮在同一个城岛上修复出生、区域加载、人物和车辆的物理等待，以及营地恢复。实测使用工作树内的场景和打包网格。浏览器使用 1920 × 1080、DPR 1、默认 Balanced 和系统 Chrome。Rapier 注入测试单独标明，真实路线的试玩及目标机 Safari 验收另有余项。

## 入口和路线

| 玩家路线 | 原问题与复现 | 修后实测 |
| --- | --- | --- |
| `/world/` → 营地，`?start=town` → 城镇 | 正常入口等大陆两组地形，初始遮罩只检查句柄。若物理出生尚未结束，遮罩也能退出。 | 普通 Chrome 检查了营地和城镇初生，城镇通过页面按钮回到营地。运行态要等实际胶囊激活才退出遮罩。暂停和固定机位可以先在真实碰撞注册后显示场景。 |
| `?start=brain` → WorldQuant 矿场 | 阻断 `/world/alpha-mine/layout.json` 时，旧矿场错误边界吞掉异常，入口门禁一直等矿场 collider。 | Chrome 阻断真实请求后显示可操作的出生区域错误。保持故障，点击「回到营地」后普通营地可用。未故障时同一入口正常出生。 |
| `?start=exchange`、`?start=club` | 两个场馆已分别使用场馆网格，之前各自的错误边界只在控制台记录失败。 | 普通 Chrome 检查两个入口和各自返回营地。各自加载故障进入同一地区诊断通道，两个场馆的故障注入仍待浏览器复测。 |
| `?start=factory`、`?start=ibd`、`?start=coaster` | 北区各自的异步模块出错会越过本地 Suspense，可能让整个世界进入错误界面。 | 普通 Chrome 检查三个出生入口与返回营地。真实 factory 模块请求失败后原入口提示重试或回营地，点击回营地时同一注入仍在，营地可用。IBD 与过山车同用边界，独立故障注入仍待复测。 |
| `?start=alpha-cave` → 回音洞口 | 旧点 `[220, 24.12, 155]` 在打包洞底、洞壳和台架装入真实 Rapier 后，支撑环和逃逸查询无法通过。旧遮罩已退出时角色仍未启用。 | 改用同一洞口前约 1.41 m 的 `[219, 23.69, 156]`。打包碰撞夹具确认旧点拒绝、新点安全落地。沿用角色移动制动、坡面重力补偿和贴地逻辑，120 步内胶囊中心从 `[219.000, 24.667, 156.000]` 稳定到 `[219.001, 24.512, 155.999]`，脚下仍有支撑。生产 Chrome 验证了普通出生和顶部按钮返回营地。 |
| Alpha 浅滩、风口、山顶和水车出生 | 旧 Alpha 专用启动门禁只需一片地形。洞壳、洞底与其他山岛资源的网络故障同时影响整个城岛启动。 | Alpha 等真实地形的表面和陡面。回音洞和水车分别另等独立实际结构。生产 Chrome 断水车产物请求时，水车出生显示失败，营地和山顶均可进入。放行同一请求，点击「重试」到达水车。风口和山顶有既有真实地形落脚测试。浅滩的两件地形、禁用、删除检查已覆盖。 |
| 山路 → 水车水幕后通道及洞口 → 洞内 | 通道东端能走出旧水车矩形，进入洞口只靠 Alpha 地形条件。 | 水车边界覆盖通道东端。洞口门禁覆盖主洞和侧洞的近地高度。高处经过时仍按各自所在区域执行。打包洞灯和水车碰撞回归通过。 |
| 大陆 → 木板渡口 → 上船／下船 | 渡口有显著高出水面的独立木板，原地区门禁只等大陆地形。 | 生产 pier 184 件圆角盒碰撞全齐才通行。真实 Rapier 一件未挂要等，远端木板删除后站点关闭，重新挂载后原路线放行。上/下船仍使用完整实际路线扫掠。 |
| 徒步／开车跨界，脚下区域卸载 | 步前限速之后 Rapier 接触仍能把人物和车辆推过冷区边界。区域卸载后原代码还会保留下降速度与重力。 | 真实 Rapier 接触尝试跨界后，守卫恢复进碰撞求解前的姿态。人物和车辆在当前区域卸载时暂停物理，连续 120 步位置不变，重挂后原地恢复。原本由座椅、载具或乘具停用的胶囊继续由各自拥有者控制。 |
| 上下车／渡船、缆车、雪橇和过山车跳过 | 原场景已有途经和到站门禁。本轮增加的区域边界可能改变入站放行。 | 定向回归涵盖车门路径与车体扫掠、实际运输路线每个支持的方向、未就绪目标处保留已请求的 skip、分段恢复和车厢完整包络。全路线的真人浏览器复跑还未完成。 |
| 顶部与暂停菜单的「回到营地」、进水自动回落和车辆翻覆恢复 | 返回营地可直接写入出生坐标，缺少区域与物理落脚复核。 | 返回营地先检查现有门禁、胶囊净空和逃逸路径。没找到安全点时提示稍后重试，保留当前位置。已对正常入场的城镇、矿场、交易所、Club、工厂、货场和过山车执行真实按钮返回。原进水救援仍筛掉未就绪候选，翻覆复位也检查车体包络就绪。 |

## 验证

- `npm run check:grounding` 42 项通过，包含打包回音洞新旧出生点、真胶囊、渡口结构下架/重挂及资产数据验证。
- 角色边界、出生、物理门禁、车和乘具重点套件 28 项通过。套件直接执行 `world-arrival-readiness`、`region-body-guard`、`actor-world-boundary`、`vehicle-passage`、`ride-passage`。
- 浏览器的故障、延迟、重试和普通入口回归可用 `WORLD_BROWSER_MODULES=<Playwright 所在项目目录> node tools/world/playtest/arrival-readiness.mjs http://127.0.0.1:<隔离预览端口>` 复跑。隔离生产构建 8 页，3 组通过。矿场延迟、放行和暂停菜单回营地用例合计 9.8 秒。水车故障、回营地、同一故障时进入山顶及恢复请求后重试合计 42.6 秒。洞口普通出生并通过顶部按钮返回营地合计 9.8 秒。开发运行曾出现 Vite 504 `Outdated Optimize Dep`。

## 尚待验收

- 城镇、项目广场、街道以及 Alpha 的独立旅站内仍需细分室内/甲板 collider 的就绪要求。大陆主要地形和各独立设施的规则已在场景装配路由登记。直接资产错误已反馈，已成功下载但一直不注册的场景仍持续等待。
- 响应按站点处理失败，重试重新加载页面。可恢复的 collider 卸载/重挂不需要刷新。同一视图中独立失败场景的热重试尚未实现。
- 核心 actor bundle 的依赖边界继续通过。世界装配持有地区表，仍有场馆字段留在共享 store 和各自 HUD。空载乘具的调位动画尚未纳入本轮行为验证。
- 逐区长路线的真实键盘行走、驾驶、四类乘具 E→跳过→出站、昼夜固定机位与 M3 Air/Safari 目标机体验仍需验收。
