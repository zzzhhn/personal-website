# 城岛角色与区域就绪

基线为 `dc8d8d4f`。本轮在同一个城岛上修复出生、区域加载、人物和车辆的物理等待，以及营地恢复。实测使用工作树内的场景和打包网格。普通出生与模块故障使用 1920 × 1080，区域跨界与救援使用 1440 × 900，均为 DPR 1、默认 Balanced 和系统 Chrome。目标机 Safari 验收仍待执行。

## G28 跨区出口就绪

旧版选中冷过山车出口时，立即从候选里跳过该出口并抵达矿区。过山车的远景已在渲染，但站台与地形细节的真实碰撞仅随附近玩家注册，营地穿门无法触发。修复后，穿过传送门光幕才进行一次随机选择，并仅请求该候选缺少的实际区域。角色在原门等待，出口必须通过区域注册、真实胶囊落脚和逃逸路径检查。加载失败或 8 个模拟秒后，顺序检查其余候选。后退或按 Esc 会取消本次请求，离开门口后可再次穿行。矿区、过山车远轨保留普通入口原有的远景生命周期。

| 普通 Chrome 路线 | 实测结果 |
| --- | --- |
| 营地穿门，延迟过山车近景 worker | 步行到光幕前无近景 worker 请求。穿门后保持原输入，750 ms 内位置停在 `[-33.715, 33.980]`。放行真实 worker 后到达 `[60, -119.443]`，再用键盘步行约 1.05 m。 |

另用只读 QA 对照 4366 与 4384 营地初生场景，保持普通跟随相机和默认位置。两版均挂载矿区和过山车远景，过山车组均有 44 个网格，几何缓冲区哈希完全一致。两版均未启动过山车近景 worker 或挂载站台、地势近景碰撞。
