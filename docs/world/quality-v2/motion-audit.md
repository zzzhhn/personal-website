# 自然运动验收记录

正常速度证据入口：`review.html`，详细日志 `playtest/acceptance-r3/report.json`、`playtest/motion-r4/report.json` 与 `wind-views.json`。不把 shader 存在视为画面通过，最终观感由 Fable 审阅。

| 对象 | 本轮实现 | 固定约束与实测 |
| --- | --- | --- |
| 树 | 低频枝端摆动、叶尖微颤；实例位置产生错相 | 根部权重 0；位移解析上界 <13 cm；18 个材质分支绑定对应阴影；完整树正常速度录像 `tree-full.webm` |
| 灌木 | 外叶/细枝风动，实体核心静止 | 核心组合碰撞不移动；不整球平移；黄昏/夜间同屏录像 |
| 帐篷 | 运行时布面细分；布中部约 2.8 cm 鼓动、两侧收束帘约 1.6 cm 微动 | 脊、缝、檐、端部固定；每顶明确两片帘；方向光深度材质同公式；`tent-front.webm` 完整门洞与绳桩视图 |
| 旗 | 以挂点为轴轻摆，统一时钟 | 旗杆静止；两频率周期 3.49/2.03 秒；角度解析上界 7.45° |
| 篝火 | 火舌形体与亮度缓变 | 坑、柴、石头静止，不缩放整坑；使用同一暂停时钟 |
| 海面 | 小幅交错法线涟漪 | 不移动水面几何，不改变物理水位或掉水判定 |
| 人物 | 自制 18 骨骨架、Idle/Walk/Run/Jump/Land；动作按真实速度驱动 | GLB 源与动作 QA 在 guide；正常速度真实按键录像；走跑混合的微小鞋底下沉由上限 2.5 cm 的视觉补偿处理，最终专项实测最大约 1.53 cm，不改变刚体或跳跃 |
| 车轮 | 保留当前滚动、转向、悬挂视觉 | 本轮没有认证侧向轮胎实体接触，不用视觉动画冒充解决物理问题 |
| 石块、桌凳、灯杆、支架 | 静止 | 同源最终 GLB 碰撞；不为动态而摇动硬物 |
| 地面、灰盒建筑 | 静止，世界尺度材质层次 | 没有独立草叶资产，不用地面上下运动模拟草叶，不扩正式资产范围 |

Esc 暂停与固定取证机位下，物理、环境时钟和角色 mixer 的冻结检查通过；减少动态下风浪强度降到零。必要的主动角色动作保留。实际完整录制在普通跟随机位进行，固定全景截图不被用作动画证据。

限制：树叶及布面法线响应使用轻量近似，未实现逐顶点精确变形导数；布面只为当前有阴影的方向光绑定深度材质，点光不投射阴影。人物补偿不是复杂坡面双脚 IK。环境位移上界来自参数解析，录像负责连接和观感审查；不声称做过全岛每一帧的像素级运动证明。
