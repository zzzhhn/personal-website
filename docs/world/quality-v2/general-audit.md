# 通用问题审查

本轮覆盖源代码共性、实际运行清单与规定的三条跨区连接回归；正式美术仍只扩营地与 G24。

| 范围 | 发现 / 修正 | 证据与边界 |
| --- | --- | --- |
| 营地自然物 | G19–23 原来仅视觉；现在灌木闭核组合实体、石块精确静态网格，树干也用最终 GLB | 16 类首实例四方向复合案例；其余实例同一矩阵源，未逐个穷举 |
| 帐篷 / 家具 | 旧盒子/整件凸包造成门洞封死、桌端穿行、家具空隙空气墙；改为同源墙壳与硬件三角网格 | C03/C04 真实进出，桌椅/火圈/架/杆接触误差；C08 高处书堆按 C1-a 分离查询 |
| 低矮地面边缘 | 原平均摩擦使圆脚粘在 10 cm 石板；人物 friction=0、combine=Min，水平控制停步；soft CCD=0.1 m 改善落地接触 | 独立复现先失败后通过；连续 11 路点无恢复；已有三条连接回归 |
| 营地出口 / 公路 / 桥 / 栈道 | 视觉与表面代理同源 block/segment，坡道端接既有修复保留 | `playtest/connections/`；未新增全量测试 |
| 园区小屋 / 建设区 | 六个小屋前展示台、建设中立牌误放 decor 导致无碰撞；转入 solids，同一位置/尺寸生成视觉和实体 | 源代码复核 + 运行 physicsInventory；非每块牌四向键盘实测 |
| 城镇楼体 / 灯杆 / 护栏 | 已有明确固定代理；命名补齐可定位接触。楼体遮挡淡出逻辑保留 | 运行清单；没有把灰盒立方体说成正式模型 |
| 水下 | 已有闭合海床和岛体水下延伸，掉水两秒恢复契约保留 | 本轮未改变高度/掉水架构；海床视觉闭合不代表可潜水游玩 |
| 画质 | 原 DPR1.5 上界、过大的阴影覆盖区、地面缺少中小尺度层次；高质量像素预算、跟随玩家的阴影投影、世界尺度沙草材质 | 实测 1080p/1440p buffer；不把视口截图缩放算提高分辨率 |
| 动态 / 暂停 | 枝叶、帆布、旗、火、水同一时钟；不整树刚性摇动；角色真实 mixer | 暂停/取证机位/减少动态机器检查 + 另附正常速度视频 |
| 异步载入 / 错误 | 资产加载失败保留明显 fallback 与保守代理，QA 不把 fallback 认作正式形状 | 最终批次无 fallback / JS / HTTP 错误 |

仍未认证：三辆车的视觉轮胎侧碰（raycast wheel 机制，不在本轮营地门内）；M1 Air 性能；任意移动物/高速冲撞的所有角度；非营地区域正式模型；人物复杂斜坡脚 IK。帐篷和树冠仍可能遮住近处人物，当前冻结的固定机位仅楼体有淡出，不能宣称解决任意遮挡。全部“未认证”保留为下一阶段事项，不能藏入通过统计。
