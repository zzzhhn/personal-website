## 结构与面数

三种轮廓分别为圆冠三叉、横向展冠、向上分叉五簇。木体由带锥度的放样管做 Exact Boolean union，形成连续闭壳；叶团核互相嵌入、分枝伸入叶核，叶片以埋入核体的叶柄连接。叶片每片 6 个三角，折线与轮廓有用途；不是给旧球体全局细分。灌木保留单丛和双丛的高度差，内深外浅。岩石用切面、凹台阶和一段倒角，三种轮廓不同。

## 四份 skills 对照

- 家具设计 skill 的结构/连接原则用于枝、叶核、叶柄、岩面角色，未照搬家具的特定面数。
- low-poly pipeline：米制、底面原点、+X 前、GLB +Y 上；原生源和最终 Draco 文件分别检查；六视图直接从最终 GLB 重新导入渲染。
- connected refinement：闭合木体要求单组件；叶核/叶片是有意分离的嵌入件；所有开放叶面明示为双面叶片，不能把原始 component 数写成坏网格，也不能焊掉材质缝冒充导出质量。
- rig animation smoke：自然物不伪造骨架动作；按其导出/运行检查原则验证 `_WIND` 保留、固定根部、实际运动和阴影一致。角色骨架另见 guide/。

## 检查与修订

`qa_v2.py` 独立读取 blend 和最终 Draco GLB：有限坐标、重复/退化面、闭合硬部件、连续木体、叶根接触、native/回读三角及边界、接地、居中、预算、无摄影棚对象、风属性。全部机器项通过。第一轮曾检出叶柄悬空最多 3.1 cm 和 G21 数值退化面，已在生成源修复后重导出；没有在 QA 阶段修补待交付模型。

`leafRootsEmbedded` 使用最近有向核面诊断，仅证明这个明确的叶根检查，不宣称任意自交或所有内部面的完备检测。每件原始检查仍保留 `unproven_checks`。六视图、clay、wind mask、游戏距离图保留在 views/。

## 风与碰撞契约

`_WIND` 四分量是主弯、枝响应、叶尖、枝相位；三种绿色和木石颜色遵守冻结表。运行接入只有 `attachNatureWind(mesh)`，统一 WorldWind 时钟；没有额外时钟或全树刚性摇动。根固定，单轴主弯 6.5 cm + 枝 3.5 cm + 叶 1.8 cm，合成顶端位移保守界小于 13 cm；有实例相位。叶片 doubleSided，deformed depth/distance 阴影一同绑定。

树干和岩石取最终 GLB 的静态三角网格；灌木取分开的闭合叶核组合凸包并水平外延 6 cm。全部声明为 **solid**；G23 被胶囊跨越仍需真实接触与抬升，不是 trigger-only。GLB extras 也声明相同的生成策略，具体碰撞顶点由最终视觉网格推导，避免另存一份漂移的代理。

## 可复现

从仓库根目录运行（`blender` 指本机 Blender 4.2 LTS 可执行文件）：

```sh
blender -b --factory-startup -P tools/world/camp/nature/build_nature.py
blender -b --factory-startup -P tools/world/camp/nature/qa_v2.py
blender -b --factory-startup -P tools/world/camp/nature/render_views.py
python3 tools/world/camp/nature/compose_sheets.py
```

`manifest.json` 绑定最终 GLB 的 SHA-256。`views/raw/*_rendered_from.json` 绑定实际渲染源。旧 `inspect_nature.py` 与 `PLAN-interface-*` 仅为历史基线/早期提案，不是本轮最终接口和通过证明。
