旧家具制作没有事先逐件声明预算的历史事实无法补写成已执行；本轮记录实测和适用结构，没有伪造前置计划。C06/C07/C09的可读性、比例与支撑继续作为Fable视觉审查项，书桌及柜子没有为了面数指标增加无用几何。
