# Alpha 山上半程互动与探索反馈

2026-11-15。本轮按用户最新分工：Agent 做有针对性的技术检查，技术通过后更新 4341 供用户体验；不以重复 computer use 漫游作为开发前置条件。试玩手感、普通视角质感及趣味性仍待用户反馈。

## 本轮交付

- 纸灯的放飞交互跟随携行玩家，不再停留在取灯时的位置。取灯和风闸操作预检实际手臂可达范围；完成仍需原有真实掌心误差，不放宽接触阈值。携行取消、失手和其它设施抢占手部时不能误放飞。
- 风闸显示当前档和下一档，完成后提示旗面、路牌的实际反应。发现坡路覆盖原平台高度后，风闸与手柄整体降低 0.20m，保持横轴连接；原石脚向实际坡面延伸，地形和旁路不变。铜铃、沙盘、树绳和添石保留原操作流程，增加完成反馈。
- 回声洞沿既有路线提供下一处低亮度矿环，玩家真正走近才推进。低磬引向壁画侧室，读壁画后沿原支路返回岔口；清磬引向通路出口。没有新增分数、通关门槛或存档结构。
- 浅滩石块真实入槽时，原水面产生局部法线扰动；暂停、离开和重置清理反馈，不补播积压效果。入槽短音尚未补充，未为此另建音频上下文。
- 登山卡可展开并选择九处站点，查看玩法及相邻路线，不强制任务顺序。卡片仍需在小屋领取，试玩入口不会自动授予。
- 新增 `start=alpha-wind`、`start=alpha-summit` 入口，沿用真实地形准备和安全落地逻辑。

## 质感与性能边界

保持 Balanced 默认、现有建模细节、贴图、材质主参数、曝光和固定灯槽。风闸只调整整体标高及原两块石脚尺寸；洞内复用已有四个矿环；浅滩复用原水面，不增加灯、纹理、几何数量或渲染 pass。水波最多八个固定 uniform 槽，闲置时跳过扰动；路径数组预先计算，登山卡不订阅每次玩家位置更新来重绘。

这只说明代码结构上的成本约束，不代表实机帧时间已经改善。新水波 shader 的替换位置由当前 Three 源码检查覆盖，实际 WebGL 编译、动态水面观感及昼夜可读性待普通试玩确认。

## 建议体验

1. `start=alpha-summit&quality=balanced`：走到纸灯架前取灯，带着走远，再按 E 放飞。关注取灯是否自然、放飞提示是否一直可用；也可试添第一块石头。
2. `start=alpha-wind&quality=balanced`：靠近手柄逐次切换三档，观察旗布和路牌是否与提示一致。
3. `start=alpha-cave&quality=balanced`：取矿灯，试低磬的壁画支路和返回，再试清磬出口。无需贴着线路中心走。
4. `start=alpha-shallows&quality=balanced`：推一块石头，观察真实停稳后的局部水波；暂停再继续，不应补播旧效果。

缆车、雪橇完整乘坐和各处自由走位仍保留用户体验待确认状态，不用本轮纯技术检查替代。

- 44 项定向检查通过：洞内实际地面与有序探索、石桥入槽和取消、水波固定槽、登山卡空间选择、真实 G24 骨骼接触、纸灯生命周期以及上山试玩点 Rapier 落地。使用项目的 `tools/world/alpha-mine-tests/register.mjs`，串行执行。

- 纸灯取用掌心误差 0.00319m 以下；三档风闸实际可达站位分别 49、43、37 个，网格最大掌心误差 0.01810m 以下，均保留原 0.06m 完成门槛。首块添石弧线最大掌心误差 0.04843m。数值证明测试站位可达，不代表鼠标键盘操作的主观手感已获确认。

- 构建前可用磁盘约 5.09GiB，内存压力等级 1。重工作串行，不开额外浏览器，不做可比帧率结论。
