## 空间和玩法合同

- 石滩位于小屋至语法树之间。八块石墩可推入导槽；咬合后成为固定支撑，解锁移动前必须确认其上无人。不要让动态刚体承载站立角色，也不修改 `player-ground.ts`。旁边始终有静态踏石与浅水通道，失败、重置、未完成搭桥均不封路。
- 语法树后形成两路：左路水车，右路岩洞，均回到风口旗坡。保持现有主路通行，新增高度及坡度由实际地形测量确定，不能把概念图当坐标数据。
- 水车三闸可独立操作。流量改变水流、转速与斗内水量；过快可见水洒出，中速稳定提水，浇灌崖花后瀑后路露出。让玩家从运动与结果理解因果，不用答题或隐藏正确数字。普通主路始终可走。
- 洞口提矿灯，分岔处敲磬；清亮延迟回声和逐段暖色矿环指向通路，闷响带向壁画侧室。耳机、静音两种情况下均能理解反馈，壁画支路允许原路返回。矿灯与峰顶放飞纸灯是不同对象，复用手部动作仲裁，不能互相抢手。

## 独立验收

1. 交通：缆车/渡船/雪橇前侧方合法按 E，接入不折返、不穿壁，转弯面朝位移，暂停/取消/受阻恢复正常。
2. 路线：两条分岔都可从语法树走至风口；未搭桥可走旁路，洞内死路可退回，瀑后路头部和相机净空足够。
3. 互动：八石逐一推动入槽，三闸所有档位有效，快流洒水与中流提水可观察，洞内回声有空间与时间差，退出恢复手部和灯槽。
4. 画面：实际引擎同机位正午/午夜，Balanced、固定曝光，并记录实际视口；高档专项对比另行说明。先验普通距离与夜间可读性，再看近景接缝、支撑与材质。
