# Alpha 山与全局交互修复

2026-11-15。承接用户四张截图和五项反馈。沿用「Agent 技术核验，用户定点体验」分工；默认 Balanced，材质、贴图清晰度、曝光和灯光预算不降级。

## 原因与改动

- 陡坡：动态胶囊的向内水平速度仍可能被碰撞解算转成向上冲量。新的接触约束移除不可行走坡面的向内分量，保留沿壁移动和重力。恢复真实面法线，另用脚底附近的顶面探测区分小台阶，避免阻断正常平台接缝。
- 山洞：旧地形只挖低了洞底，外部没有连续山体覆盖，薄地板露在半空。补充与实际地形相接的外部岩体和厚地基，保留双洞口、内部路线与侧室。将穿过洞侧壁下方的旧旁路接入正式洞口，露天主路继续开放。
- 取物：此前发现提示、严格站位和手掌接触是三个分离的条件，玩家看到提示并不代表能执行。新增共享的短距离自动就位能力，E 先走到安全站位并转身，再调用原有实际伸手动作。已在营地工具、哑铃、行李箱、手记，Alpha 矿灯、纸灯、风闸、添石，以及旧矿场的工具、接石台、回收台和暂存矿石接入。工厂及证券设施已有的专用靠近流程保留；矿场辨矿、挥镐和存放规则不变。
- 图四符文机关：从运行场景移除整套石桥、水池、拉杆及其提示；撤掉矩形水池的挖方，恢复自然坡面和可行走的海侧步道。旧 `start=alpha-shallows` 入口保留兼容。
- 乘坐：渡船、缆车、雪橇和过山车增加「跳过行程并到站」按钮，只跳过移动路程。正常起身、安全下车、控制权归还仍执行；船与缆车若已返程，跳至原站，雪橇保持下站安全退乘。暂停、重复点击和旧实例不能重复完成行程，也不改变任务或奖励。

本轮没有新增贴图、灯光或渲染 pass。山洞外壳为静态合并网格，取物路径只在按键后或自动就位期间检查；没有后台全图寻路。正式可比性能数字需同条件运行测量，本轮不作 FPS 改善声明。

## 玩家体验位置

1. `start=alpha-cave`：从洞口外侧观察它与山坡的连接；靠近矿灯按一次 E，试着从正面和稍偏的位置取灯，再沿洞内主路和侧室走一遍。关注是否仍需挤到极窄站位、是否被洞顶/路边卡住。
2. `start=alpha-wind`：走向陡壁，再回正常山路；靠近风闸按 E，乘缆车并点跳过。关注陡壁是否仍能漂浮爬升、到站后是否能自由走动。
3. `start=alpha-summit`：取纸灯、添石，随后坐雪橇点跳过。关注自动转身、伸手与落脚是否自然。
4. 营地及意图过山车：工具墙、哑铃、行李箱、手记各选一件尝试；过山车出站后点跳过。原符文石滩处现在可直接沿步道通行。

所有入口均使用 `quality=balanced`。若有反馈，只需地点、刚做的操作和截图或文字；不要求用户执行完整 QA。
