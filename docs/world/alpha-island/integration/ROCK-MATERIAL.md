# Alpha 岩坡材质收尾

来源是项目已使用的G21自然岩面：Poly Haven rock_face_03，摄影Dario Barresi、处理Rico Cilliers，CC0-1.0。使用现有512px色图/GL法线/ORM，无新下载；不使用G21专属烘焙AO。

R1程序阈值裂缝在实际图出现迷彩等高线和三角硬块，拒绝；R2纯颗粒消除轮廓但缺乏岩石细节，保留为中间证据。最终采用现有岩面扫描，米制1.65m三平面，颜色sRGB，法线/ORM线性，法线按各投射轴重定向，roughness取G、metal仍0。两次偏移采样混合抑制规则重复，用显式UV梯度保留mip精度。

成本：3个附加texture对象，借用现有文件；岩材三平面每个贴图6采样，总18附加采样，加上原草/土4采样；没有新draw/三角/光源/动画或碰撞。这个成本必须以实际本机Chrome/WebKit检查，而非假称免费。与R1相比去掉重阈值裂缝和height导数，保留夜间照明与路径/草/雪/沙遮罩。

同机位实际图见rock-scan-r4-dev与后续最终production组。表面细节可以改善读感，但不能将平滑大地形轮廓冒充已具备参考图中的岩体结构；后续更大岩层造型另作范围，不在此偷偷改变已核验路线。
