# Transport r3 engineering freeze

2026-11-13. This is an integration candidate; vehicle art remains a functional prototype, not accepted final art. Scene-owned r4 survey was imported via f1881f2; coordinator baseline type repair via c5b0b9d. No main, push, 4341 change or deployment.

Source/native/export inventory and exact GLB/scene dependency hashes: resource-hashes.json, tools/world/alpha-island/transports/export-report.json. Runtime consumes those exact public GLBs. Cable grip-labelled parts are separated before batching and rotate about local [0,3.5,0] along cable pitch; the passenger cabin stays level. Cabin-only door is +local Z to match both station aprons; ferry retains -local Z for east-side piers. Footrest/seat native top=floor+.13/.48, sled runner bottom=floor-.16. Manufactured decks now have actual top=0 (old planks protruded .024m).

Structural data is generated once per route in transport-infrastructure.ts, shared by visible geometry/colliders/clearance fixtures. Cable has two legs outside the vehicle envelope, a high crossarm and narrow guide roller under the cable. Sled has upward triangle winding, a matching Rapier deck, upper snow/wood transition and braced paired bents. No DoubleSide workaround for the sled floor. Boarding incoming/outgoing coplanar strips are subtracted before triangulation; no polygonOffset. Scene must exclude terrain/grass drawing inside the exact exported alphaTransportBoardingFootprints() to avoid a second coplanar surface.

The HTML HUD now imports only React/store/pure transport-status, with commands attached by 3D owner. Scene should import default AlphaTransportHud from transports/AlphaTransportHud.tsx. Original re-export is temporary compatibility only.

Door portal camera verifies seat-eye→portal and portal→camera, then verifies direct sight of the passenger. Invalid initial overlap or degenerate portal is recorded as invalid and triggers a safe-exit request. Read-only camera QA data includes firstLegHit, validOrigin, effective origin and visibility limit. Opaque cabin faces, floor, roof and station supports retain physical collision.

Boarding preflight uses physical capsule centre .82m above foot, 12mm flat skin, plus the explicit round-foot/slope tangent correction per segment. The old .88+.04=10cm raised query was discarded. Each subsequent approach/walk-out movement segment is also checked, including the last approach→turn-in step. Blocked movement freezes the final actor/camera frame; removal resumes. Stand checks the complete exit repeatedly; blocked exit does not enable the capsule. The final actual landing remains independently revalidated. E during an unseated approach releases at the current verified foot point, without completing unnecessary boarding.
