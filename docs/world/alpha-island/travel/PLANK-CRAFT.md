# Transport wood surface refinement

The accepted functional freeze is0ac66c7. The current visual revision changes only the wooden trough/fixed boarding rendering and the UV/material of existing sled beams. Original routes, moving body colliders, top collision arrays, supports, rollers, ground samplers, stations and all3 GLBs are retained. The paired capture tool hashes those exact original data and vehicle-collider JSX against the fresh0ac baseline before rendering the candidate.

Four longitudinal staves span each1.3m walkway/1.46m trough.1.8m joints are staggered;6mm real geometric seams expose8cm walkway or12cm trough board edges. Every retained top fragment is clipped from its original surface triangle, preserving the surface plane. Existing trough shell/backing and snow-side surface remain. Two under-board stringers occupy the fixed walkway footprint; the trough's existing braced supports remain. No collision or player path is generated from this new visual mesh.

A single owned wood material borrows the existing facility wood/albedo/normal/roughness maps and existing environment registration. Grain UVs follow the actual path length and beam axes; there are no new textures or lights. Wood state/geometry are memoized, disposed explicitly and counted. A DEV qa-only visual switch unmounts the craft meshes and releases the single material, then restores them without replacing Physics/Transport bodies. The lifecycle capture must return live owned counts to the same values; no FPS or memory-benefit inference is made from these counts.

Baseline lodge matrix is taken from scene0c3e657's recorded camera and recaptured at0ac66c7; older scene images are not reused as this candidate's baseline. Conditions are fixed at1440×900 CSS /1728×1080 draw buffer, high quality, clear weather, exposure1 and noon/night presets. Dynamic sea/cloud phase is not pixel-locked. `capture-planks.mjs` records runtime hashes, original physics data, actual camera and resource lifecycle; these are visual fixtures with ordinary HUD, not additional full-route passes. Candidate paired views and visual acceptance remain pending.
