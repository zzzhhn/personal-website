## 技能方法与分项验收（生效口径）

预算与建模方法采用已注册的 [low-poly-furniture-design](/Users/bobby/Desktop/cursor-to-others/.workbuddy/magpie-lab/home/.codex/skills/low-poly-furniture-design/SKILL.md)（含 design-guide）、[blender-low-poly-pipeline](/Users/bobby/Desktop/cursor-to-others/.workbuddy/magpie-lab/home/.codex/skills/blender-low-poly-pipeline/SKILL.md)、[blender-connected-refinement](/Users/bobby/Desktop/cursor-to-others/.workbuddy/magpie-lab/home/.codex/skills/blender-connected-refinement/SKILL.md)、[blender-rig-animation-smoke](/Users/bobby/Desktop/cursor-to-others/.workbuddy/magpie-lab/home/.codex/skills/blender-rig-animation-smoke/SKILL.md)。JSON 为每件记录 `skillGuidance`、`acceptanceProfile` 和尚未执行的 `acceptancePlan`；按资产类型适用，不把其他项目的果实/动物数值、验收状态或批量授权继承到本项目。

1. **先声明设计与预算。** 以米记录完整资产尺寸、朝向、接地原点、部件角色、板腿比例/负空间或车型/建筑剪影、材质语义及逐件面数目标。使用本机实际 Blender 版本和 operator RNA，不把技能示例版本当作本项目实测。先低复杂度设计，Decimate 只是可选清理，flat shading 不代表减面。
2. **评估后与导出后都数。** 排除地板、灯光、相机等展示对象，统计所有修饰器评估后的实际 loop-triangle 总数；最终 GLB 在全新空场景回读，再比较三角数、包围盒与材质清单，并重开 BLEND。硬边/UV/材质可造成合法顶点拆分，不能拿原始顶点数当三角数；记录绝对面数和相对基线倍率。
3. **几何与连接按角色验收。** 检查有限坐标、退化面、重复/共面面、法线/绕序及适用的流形性、支撑接触。固定连续表面确需连接时验证共享顶点/边；嵌入式独立部件允许分离但不能悬浮；轮轴、铰链、骨骼关节保留运动间隙。Join 不等于焊接，不能为单一连通分量强融所有零件。内部表面采样只是诊断，不是穷尽自交证明。
4. **尺寸与交换单独验收。** 保留目标 GLB +X 前、+Y 上、+Z 右及车辆触地原点契约；Blender 使用米制/Z-up，明确转换且只做一次轴变换。导出仅选资产根与组件，排除展示对象；回读不以任意对齐掩盖位移/缩放。静态件记录完整边界、底心与变换；骨骼件另声明 rest/root 与运动边界，不逐帧强制重心归零。
5. **材质另设门。** 按 stone/wood/canvas/paint/glass/metal/rubber 等语义检查，延续 Art Lock 色板及限制，不拿技能的示例家具色板覆盖世界美术锁。程序写材质时把 sRGB 转线性；在相同相机、光照、曝光和色彩管理下对比，核对 BLEND 与回读 GLB 的持久化 PBR 值、材质清单和有效面覆盖。几何合格、材质名称存在均不等于材质合格。
6. **动画仅对适用资产执行。** 向导检查连续皮肤、非负归一化权重、每点最多四个有效影响及关节极姿/接触；刚性机构保持每部件刚性和真实枢轴，不能把金属混合权重弯软。明确片段名、帧率/帧段、原地或 root motion；实际最终 GLB 全新回读后逐段激活，检查关键帧与代表性子帧、接触/间隙与源场景对照。角色动作、轮轴/风车机构或可动展位只声明实际测过的覆盖，不把静态检查或能导入当作动作通过。
7. **图像与交付证据分开。** 保存可编辑 BLEND、便携 GLB、可重跑生成/渲染/检查脚本、实际尺寸/三角数/材质报告、中性/灰模多视图及黄昏/夜档图；真正查看图像和适用动作回放。数值门、材质门、动作门、视觉方向审阅和 Bobby 接受各自记录；未执行就是计划，不靠加面或脚本退出码宣称质量。营地 L1 样片及 G24 替换已有单独授权；其余正式生产仍须后续门，不随本次返工扩张。
