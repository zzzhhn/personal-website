## 唯一优先候选：阴影代理矩阵上传守卫

保留每个级联现有的可见性筛选、caster 标志、几何选择与实际阴影渲染。对非动态源，仅当该代理的有序实例索引、源 instanceMatrix 引用／version、world matrix 和代理容量均未变时，复用上一份矩阵缓冲，不再复制和置 needsUpdate。每个代理／级联独立缓存，重建或上下文恢复必须失效。动态物理实例继续原路径；树叶的风仍由每帧深度 shader 计算，不冻结阴影贴图。

不能只比较实例数量，也不能只比较相机是否移动：同数量可以换成员，同成员可以换矩阵。预计减少 CPU 复制与 VBO 上传，draw calls／三角形应相同；没有证据承诺帧时间降幅。若有效代理很少，或 GPU 片元才是主要限制，此候选收益可能很小。

3. 补一段很短的转镜头、角色移动及树叶风动检查，验证相同数量换实例、动态阴影和失效恢复。只有上传确实下降、画面相同且帧时间未回退才保留；否则先停止实施，下一优先是定位池面片元或主阴影 GPU 时间，不继续盲目降画质。
