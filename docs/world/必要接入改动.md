## 实际安装结果

以上版本已安装。ecctrl 2.0.2 的 peer 要求 React ≥19.2.7，因此 react/react-dom 从原 npm 锁定的 19.2.5 升到并固定为 19.2.7；scheduler 随之从 0.27.0 升到 0.28.0。没有接受安装初次自动解析出的更高 React 次版本。

npm 锁中其余已有包版本保留。原 pnpm 锁落后于既有 npm 锁（例如 Astro 为 6.1.3，而原 npm 锁已为 6.2.1），通过 `pnpm import` 从最终 npm 锁同步，所以 pnpm 差异也含这些已有版本的对齐，不代表另行升级现站依赖。未改 package manager 配置。
