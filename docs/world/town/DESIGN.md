# 城区正式资产设计（town 会话，2026-10-24）

每轮开工先读本文件，不再重推设计。改动直接改本文件并在末尾记一行。

## 0. 共同约定

- 坐标与尺寸以 `layout-v4-flag.ts` 的 `BUILDINGS_V4` 为准，不改。楼的正面朝东（+X，大道一侧），正面在 x = 11.5；前广场 x 11.5–15（顶面 y ≈ 1.15）；年份灯柱 (x+w/2+5, z) = (16.5, z) 在人行道上；展板 (14.5, z+2.7)；前广场护柱在 x 14.8、z-3.6 与 z-1.2（street 会话负责，不能被楼体侵占）。
- Blender：Z 上、+X 为正面、原点在底面中心（最小 Z = 0，XY 包围盒中心 = 0）。glTF 导出一次转 Y 上；运行时直接放在 `position`，不旋转。
- 楼底 y = 1.0，前广场顶 ≈ 1.15。凡是能走进的门廊／骑楼／门厅，地坪做成局部 z = 0.16 的石材平台，与广场齐平（≤ 2 cm 落差），不做台阶（胶囊没有自动上台阶）。
- 所有楼体在 footprint 内，入口用「首层退进」实现：门廊、骑楼、门厅都在 footprint 里面，不往广场伸。唯一的例外是二层以上的阳台、雨篷、檐口，可出挑 ≤ 0.8 m，高度 ≥ 3 m（不挡人和车）。
- 文件：生成脚本 `tools/world/town/build_town.py`（共享工具 + 每栋一个 `build_Txx()`），GLB `public/assets/world/town/<ID>.glb`（Draco），.blend 放 `tools/world/town/blend/`，预览 `docs/world/town/views/`（JPEG ≤ 400 KB），大图放 `evidence/town/`。

## 3. 前广场件（`building-forecourt` 认领后由本会话提供）

- **年份灯柱** `T08`（同一 GLB 实例化 6 次）：石基座 + 0.36 m 方形石板蓝柱身 + 柱帽；朝路一面一条青色灯条（`town_cyan`）；顶部双面年份牌（Canvas，`YYYY.MM`）。坚硬（fixed，凸包）。人或车 9 m 内时灯条从 0.15 亮到 1.6，同时本楼招牌点亮，离开 2 s 渐暗。
- **展板** `T09`（实例化 6 次）：两根金属腿 + 石材底座 + 斜立框，正面朝东；板面 Canvas（日期 + 职位 + 机构，双语随语言切换）。坚硬。`useInteractable({ kind: 'exhibit' })`，按 E → `store.card = { kind: 'experience', id: startDate }`。
- 窗格夜光：由 `town_glass_lit` 承担，灰盒 warm 窗块随认领一起去掉。

## 4. 背景与南滩（`massing` 认领后由本会话提供，仅 v4）

- **T07 背景矮楼**：一个 GLB 内 7 个子节点 `T07_0..6`，尺寸与 `solidsV4()` 里 kind = massing 的 7 个盒子一致（运行时按顺序取位置并校验尺寸）。地中海删减版：平顶 + 女儿墙 + 水箱或烟囱；窗洞带窗套窗台、门带门框与台阶石；底部砖褐勒脚、隅石带；不做外楼梯、藤架、密集栏杆、拱门（审阅 codex-native-v2 的删减要求）。后街 4 栋面朝 +X，西岸 3 栋面朝 -X（向海）。坚硬。
- **南滩小亭** ×2（`beach-kiosk`，2.6 m 立方占位）：木框售卖亭，前台窗口 + 台面、帆布遮阳篷（橙 / 奶白两款共用几何、换材质）、平顶出檐。坚硬。
- **救生塔**（`beach-lifeguard`，2.2×5.8×2.2，底部埋入 1 m）：四根木桩 + 斜撑、平台 + 栏杆、小木屋 + 坡顶、斜梯、橙旗。坚硬（桩与平台、屋体凸包）。
- **T12 棕榈** ×2：弯曲分节树干（平滑着色）+ 9–11 片羽状叶（每片中脉 + 两侧小叶片带折角）+ 椰簇；叶片带 `_WIND`，接 `attachNatureWind`。树干坚硬（细凸包），叶冠无碰撞。

## 5. 碰撞（与视觉同源）

- 每个 GLB 内带 `col_*` 子网格（不渲染）：都是凸体，由生成脚本用同一组尺寸参数生成（墙块、柱、门廊楼板、骑楼柱、旋转门鼓等）。运行时对每个 `col_*` 建 `ConvexHullCollider`，用与视觉相同的放置矩阵。门廊、骑楼、门厅只有柱和退进后的墙有碰撞，开口真实可走。
- 楼体与背景楼、小亭、救生塔、灯柱、展板、棕榈干：坚硬（fixed）。棕榈叶：无碰撞（高于 3 m）。本区没有软件或可推动件（路灯、垃圾桶等属 street 会话）。
- 大楼体网格加 `userData.occluder = true`；`col_*` 不渲染、不参与遮挡。

## 6. 三角预算与 draw call

| 件 | 目标三角 |
| --- | ---: |
| T01–T06 每栋 | 6k–10k（合计 ≤ 50k） |
| T07 七栋合计 | ≤ 12k |
| 小亭 ×2 + 救生塔 | ≤ 4k |
| T12 ×2 | ≤ 4k |
| 灯柱 ×6 + 展板 ×6 | ≤ 4k |
| 合计 | ≤ 74k（城区上限 80k） |

- 运行时把所有城区 GLB 的网格按材质合并（同材质一个 BufferGeometry），约 16 个 draw call；招牌、年份牌、展板用一张共享 Canvas 图集，各合并为 1 个网格（亮度用每顶点属性），共 3 个；棕榈 1–2 个。目标 ≤ 25 calls。
- LOD：六楼全部近景三角已低于城区上限，所以最坏视角（全城俯视）也不超；按 SESSION-RULES 60 m 外降级要求，合并时分「近」「远」两组：每栋另有 LOD1（由 `col_*` 凸体 + 窗带色块组成，≤ 30% 三角），运行时按相机到每栋距离切换整栋的显隐属性（每材质合并网格用 geometry group/drawRange 不行时退回 BatchedMesh）。先交近景版，LOD 在运行时阶段落地并实测。
- 阴影：细节网格 `castShadow = false`、`receiveShadow = true`；另由 `col_*` 凸体合并成一个阴影代理网格（只投影，主画面不写颜色和深度），门廊、骑楼、门厅的开口在代理里同样是空的。
