# 三车 L1 设计（G25 越野 / G26 轿跑 / G27 小货车）

2026-10-24，vehicles 会话。依据：ART-LOCK-v3（车型、色板、共同契约、v3.6）、PRD §4.3/§5/v1.13、规格 quality-v3 §10.2/§10.3/§15、`round3-lock/*-ortho.png`。每轮开工先读本文件。

## 1. 物理基准（不改）

来自 `layout.ts` VEHICLES 与 `actor-physics.ts` wheelGeometry。车体坐标 +X 前、+Y 上、+Z 右，原点 = 刚体原点（旧底盘盒中心）。

| | size L×H×W | 轮半径 r | 轴距 / 轮距（轮心） | 静止悬挂长 s（实测） | 地面在车体系 y | 质量 / 发动机 / 抓地 / 悬挂 |
|---|---|---|---|---|---|---|
| G25 越野 | 3.9×1.35×2.0 | 0.378 | 2.652 / 1.92 | 0.3006 | −1.0566 | 1400 / 9200 / 1.35 / 26000 |
| G26 轿跑 | 4.3×1.05×1.9 | 0.340 | 2.924 / 1.824 | 0.3619 | −0.9959 | 1100 / 12000 / 0.88 / 42000 |
| G27 货车 | 4.5×1.9×2.2 | 0.500 | 3.060 / 2.112 | 0.2830 | −1.3150 | 2100 / 10500 / 1.10 / 34000 |

静止悬挂长由 `tools/world/vehicles/probe-rest.mjs` 在 4335 实测（证据 `evidence/vehicles/rest/rest.json`）。GLB 按 ART-LOCK 契约原点在四轮触地平面中心、轮心 y=+r；运行时把车体 GLB 放在车体系 `y = 地面 y`，悬挂压缩只移动轮子与刚体，不改 GLB。

## 2. 比例与轮廓

- **G25**（Defender 90 类）：全长 3.90（前后悬各 0.62），车身宽 1.96，翼子板外沿 ±1.125 包住轮胎外沿 ±1.11，车顶 1.88，行李架＋备胎到约 2.12。直立前挡、平机盖、方正车厢、短悬。
- **G26**（长头溜背）：全长 4.30，腰线宽 1.88，后轮拱外沿 ±1.06 包住轮胎外沿 ±1.042，车顶 1.30，前唇最低 0.17。长机盖、座舱后置（A 柱在前轴后约 1.2 m）、溜背到短尾、小鸭尾。
- **G27**（单厢厢式）：全长 4.50，车身宽 2.20，轮拱唇 ±1.19 包住轮胎外沿 ±1.176，驾驶室顶 2.05，货厢顶 2.45，梯架约 2.55，顶灯 2.20。前置短机头＋斜前挡，方货厢，石板蓝下裙与大保险杠。
- 视觉胎宽：越野 0.30、轿跑 0.26、货车 0.24（原探针统一 0.30；改为按车读 `WorldVehicleRig.ts` 的真实胎宽，见 §6）。

## 4. 材质角色

GLB 内按角色分材质（每个材质 extras 带 `materialRole`）：`paint`、`accent`、`rubber`、`glass`、`metal`、`light_front`、`light_brake`，另加两个扩展子角色 `light_reverse`（倒车灯）、`light_beacon`（货车顶灯）。颜色只用 Art Lock 色板：石板蓝 `#4E647D`、奶白 `#E6DCCB`、营地橙 `#E8803A`、深灰 `#3A3F47`、科技青 `#63BEB3`。玻璃不透明、哑光偏深蓝。无贴图。

运行时把一辆车的全部车身材质合并成 **1 个网格**：颜色写进顶点色、角色写进一个 `role` 顶点属性，一个共享着色器按角色给粗糙度／金属度／发光（玻璃 0.3、金属 0.5、其余 0.78；灯按状态发光）。三车共用一个材质实例；轮子每车 1 个 InstancedMesh（4 实例）。

灯：前灯只在驾驶时亮（黄昏弱、夜间强，夜间加一块地面光斑贴片，不加光源）；尾灯驾驶时常亮、刹车加亮；倒车灯倒车时亮；轿跑青色尾灯条黄昏微亮、夜中亮、刹车更亮（停放也亮，是六处轻科技之一）；货车橙色顶灯黄昏弱、夜亮。不新增任何光源。

## 6. 碰撞方案

根因（读 §10.2 与代码后的判断）：
1. 旧底盘盒底在地面上 0.66～0.76 m，0.6 m 低柱从车身下面钻过去，只有不带碰撞的轮胎和它重叠 → 穿 9 cm。
2. 悬挂射线会打到任何非传感器碰撞体，包括 28 kg 动态路障和其他车：路障被撞翻到车下时，射线把它当路面，车被顶起（上抬 20 cm 的可能机制，待新版实测）。
3. 旧护轮体跟着悬挂一直伸到轮胎触地点，所以会撞到 18 cm 路缘立面、会在低矮实体上与射线同时承重 → 卡停、上抬。

新方案：
- **车身 = GLB 派生的分块凸包**：Blender 脚本按分组（车厢、座舱、前杠、后杠、四个轮拱／翼子板）取导出前同一几何的顶点，低于离地高度 `clip` 的点夹到 `clip`，求凸包，写入 GLB 根节点 extras 与 `src/components/world/WorldVehicleHulls.json`（同一次生成）。运行时用 JSON 建碰撞（不等 GLB 加载），开发态校验 JSON 与 GLB extras 一致。
- **离地高度**：主车身 clip 为 G25 0.42、G26 0.34、G27 0.38 m（静止）；轮拱块／门槛局部降到约 0.30 m 来挡低柱。18 cm 路缘仍主要由射线处理，30 cm 台阶须用定向过渡实测，不能仅靠主车身 clip 推断。
- **轮拱凸包外沿 ≥ 轮胎外沿**：轮拱凸包覆盖轮胎上半部（clip 到拱顶），固定在车身上，**不跟随悬挂、不伸到触地点**。竖直杆件（低柱、灯柱、树干、墙）在轮胎外沿之外先碰到轮拱，轮胎不会穿入。前轮转向时轮胎前缘会多伸出 r·sinθ，记录为限制。
- **悬挂射线只打固定刚体**（或无刚体的碰撞体），排除动态路障、其他车与人物。
- **质量和惯性不变**：旧底盘盒和座舱盒保留为质量载体（传感器、碰撞组 0，不产生任何接触），凸包质量为 0。总质量与局部惯性张量保留。按 §10.3 机制越野重心下移 0.5 m、轿跑下移 0.2 m。本次货车由 0 改为下移 0.5 m：10 m/s 擦低柱上抬从 35.3 cm 降到 10.5 cm，操控 A/B（旧盒原重心 vs 新凸包＋下移）半径 −0.31%、9 m/s 刹车 +0.45%、固定步响应 −0.11%、加速 0%，侧滑峰值保留 98.1%，俯仰方向正确。发动机、抓地、悬挂和转向上限均未改。
- QA 入口 `?qaVehicleLegacy=1` 恢复旧盒子碰撞与旧射线过滤，只用于 A/B。旧 `qaWheelGuards` 候选保持隔离原样。
- 可见但不入碰撞：后视镜、天线类细件（≤ 15 cm 外伸），写进报告。车身低于 clip 的部分（轿跑前唇 0.17～0.34 m）对路缘可能有几厘米视觉穿插，写为已知限制。

## 7. 验收计划

- 每车：Blender 生成 → Draco GLB → 全新场景回读（包围盒、三角数、材质、凸包）→ 四视图渲染对照正交参考 → 提交。
- 运行：tyre-matrix（低柱/树干/墙 × 2/5/10 m/s）、map-graze、dynamic-roadblock、transition-ab 的路缘台阶（不能被卡停）、handling-ab（旧/新 A/B，半径、侧滑、加速、刹车 ±5%）、drive-route（v4 默认，环岛＋上山）。
- 普通入口 1920×1080：三车停放、驾驶、近景、黄昏／夜间车灯。

## 8. 60 m 远档补齐（本次接续）

保留三份 L0 GLB、原 .blend 与 hull JSON 的 SHA，不改 WorldActors／已过操控参数。远档由原 .blend 的真实车身派生：省略 <14 cm 的非灯／非玻璃独立小壳（螺栓、细装饰等），G25/G27 结构折叠到 22%；G26 按材质边界做 15° 溶解以保住机盖到车顶的蓝条。玻璃与工作灯角色保留。轮子沿用原半径、宽度、轴心与四轮节点，远档改为平滑 16 段胎、简轮辋／五辐或钢盘；轿跑远档去掉次像素轮辐以优先保留蓝条。每车总三角硬断言 ≤L0 的 30%，单独输出 `G2x-lod1.glb`、可编辑来源与回读报告。

运行时按相机到车刚体原点的三维距离：向外到 60 m 切 LOD1，接近到 58 m 恢复 L0（2 m 回差防抖）。仍是同一个车身 mesh 与同一个四轮 InstancedMesh，仅交换几何，材质／灯状态／悬挂和轮子实例矩阵共用，物理不参与切换。主线程 928d578 已使太阳轮组代理每帧同步源 geometry；营火直接投源车网格。仅验证交接、远近画面、预算、轮组与影子跟随，不重跑已过胎矩阵／操控整包。
