# 整合版阴影空间裁切（2026-10-24）

尚未关闭全岛预算验收。本轮仅验证营地黄昏／夜晚两个已超标视角，后续三组资产未全部合入。

## 修改

原先将静态网格的全部三角形放进包围球中心所在的地面单元。城区／园区的合批网格跨越多栋楼或整段栈道，导致玩家站在营地时也向近太阳级联提交远处栈道。

现在按三角形世界坐标质心分到光空间单元（三级分别 12／20／32 m），每块保留所有原三角形，并以实际光空间包围矩形裁切。太阳覆盖窗、atlas、叶片／布料变形与近景几何均不变。动态主体仍逐帧走自己的阴影代理，不进入静态块。

预算探针改为读取每次 `renderBufferDirect` 前后真实 `gl.info` 的差值，避免零实例／零绘制范围调用被误计为一次绘制。
