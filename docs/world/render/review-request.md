# render 会话送审（2026-10-24）

由主线程转审阅模型。不涉及 Bobby 新授权。

## R1. 太阳阴影与营火的三角分配：68k → 110k（总线 50 万不变）

- 实测（`docs/world/render/budget.md` §3.2，提交 1b44e85）：阴影 draw call 从最多 152 降到 86（限 85），三角最多 14.9 万。营地五棵树在近两级级联里约 9 万三角，是按「树叶再翻一倍」做的叶片本身；three 自带 meshoptimizer 在 1–5 cm 误差内只能去掉不到 7%，0.15 m 叶簇凸包反而更多。
- 要达到 6.8 万，只能让近景树影变成团块（丢掉叶隙光斑），这正是 Bobby 批评过的「影子精度低于物件」。
- 申请：阴影分配改为 85 calls / 11 万三角；天空+海从 40k 降到 28k（实测最坏 25.3k），营地主 pass 60k→50k，城区 80k→70k，园区 55k→48k，街道 30k→27k，合计仍 277 / 49.5 万。我负责把阴影压到 11 万以内（下一步：帐篷布料阴影代理、c1 叶簇再调、c0 窗口内远侧裁剪）。
- 如果不批：退路是 c0 也用 0.6 m 叶簇凸包，预计阴影约 9.5 万三角，近景树影会少一些叶隙。
