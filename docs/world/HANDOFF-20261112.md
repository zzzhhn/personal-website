## 新电脑启动

不要搬原电脑的 node_modules、dist、/tmp 预览包、浏览器资料或历史验收录像。254 个 public 文件已在应用提交中，模型与音频使用 Git 正式版本；本机 sparse checkout 的缺文件和 /tmp fallback 不代表远端缺资产。

建议 Node 22.12+（依赖要求仍以锁文件为准），从轻量 checkout 开始：

```sh
git clone --filter=blob:none --no-checkout --single-branch --branch codex/world-handoff-20261112 https://github.com/zzzhhn/personal-website.git personal-world
cd personal-world
git sparse-checkout init --cone
git sparse-checkout set src public scripts tools/world/alpha-mine-data docs/world/phase-2-playground/camp-feedback-20261107 docs/world/phase-2-playground/boardwalk-phrases-v3
git checkout codex/world-handoff-20261112
npm ci
npm run dev -- --host 127.0.0.1 --port 4341
```

端口被占用时先核对归属，别关其它任务。使用 HTTP 的 `/world/`，不要双击 HTML。生产检查用 `npm run build`，其中 prebuild 会检查 Club 资源；需要生产试玩时用 `npm run preview -- --host 127.0.0.1 --port 4341`。不要沿用 `tools/world/*/production.config.mjs` 中原电脑的绝对 /tmp 路径。

以后按任务用 `git sparse-checkout add <目录>` 补取对应模型源文件、参考和制作脚本；不必先下载所有历史 tools/evidence。原生 Blender 工程与脚本多数在 `tools/world/` 对应资产家族目录，正式导出在 `public/assets/world/`。
