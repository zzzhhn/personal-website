## 变化

- `WorldPark` 挂载持有音频所有权，最后一个所有者释放时清理调度器、store 订阅、页面／上下文监听器、活动音源并关闭上下文。未操作 DJ 时不创建上下文或订阅。保留 DJ 曲目、横推子、音量和演出视觉。
- 音频在暂停、隐藏、静音和固定机位状态停止 25 ms 调度并挂起上下文；恢复串行处理异步状态，旧上下文的延迟 Promise 不能启动新计时器。晚到的调度跳过过期节拍。普通 pagehide 释放，缓存 pagehide 挂起并等待 pageshow；HMR 注册清理。
- Cards 提示与新手提示共享一个 UI 手柄采样器。没有连接手柄时不申请 RAF；暂停、提示不需要输入、页面隐藏或最后一个消费者退出时停止。输入提示只在可见交互目标附近采样，新手提示完成后移除采样和收集监听器。人物／车辆输入控制器及现有驾驶 HUD 轮询未改。
- 增加 Node 生命周期回归与可手动构建的轻量浏览器测试页。后者只输出到忽略的 `dist/_qa/resource-lifecycle/`，不属于 Astro 入口，不修改依赖。
