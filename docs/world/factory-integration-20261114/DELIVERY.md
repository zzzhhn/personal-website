## Performance

M5 Pro 48GB，系统 Chrome 生产版，1080p／DPR1／Balanced，A/B 再 B/A：首次 ready 均值 13.59 秒 → 15.966 秒，增加约 2.4 秒；加载完成 14.533 → 16.934 秒。营地单帧 calls 249 → 256、triangles 842075 → 1101412。短测 p95 仍约 16.7–16.8ms。

这是新增工厂内容的成本，不称性能优化。High 设施 16 个昼夜短样本 p95 约 16.7–16.8ms，不等于实际 M3／Safari 60fps 保证。系统长期长帧尚未解决。

## Handoff

`npm ci` 后运行 `npm run dev -- --host 127.0.0.1 --port 4341`。生产版先 build 再 preview。当前网页版本和进程验证见 preview.json。

普通入口从营地沿道路到西侧「机械伙伴工厂」，由磁吊取料开始。直接看工厂可用 `/world/?start=factory`；它只改变初始到达位置，不发材料或解锁。

未验证：真实 M3 Air 16GB／Safari、长时间与所有异常操作组合、手柄工位操作、全岛最终美术接受。工厂原历史审美问题没有在整合中全部重做。无 main 合并、无部署、无 Hy3D。
