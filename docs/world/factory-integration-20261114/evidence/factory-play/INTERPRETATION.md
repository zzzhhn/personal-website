# 首轮工厂实玩

普通/world/，从营地真实W/鼠标走到西侧工厂；吊取三类原料、编组、分流三类原料均完成，全部游戏进度来自可见控制。

首个压机工位等待6秒超时，失败截图和最终状态显示factoryStation=frame、角色已就位，无pageerror。后续脚本仅把UI/工位就绪等待增加到20秒，不改运行时或判定阈值。

factory-play-r2使用本报告最后一次只读观察到的已提交game对象恢复页面存档，保留gameId/原料id/7条history，没有添加新完成项；仅初始抵达使用start=factory。后续仍真实步行/鼠标/E/HUD。两个报告共同证明分阶段流程，不能称不间断的单次完整游玩。
