# Phase 2 首轮可试玩候选

本轮把人物、驾驶、美术三个独立工作线的改动合成到同一版本。运行验证对应 `27e3638`，以 `3cb1f25` 起步／坡地修复为基线。地图与小游戏仍只做方案；这份记录不代表 Phase 2 全部完成或 Bobby 已接受最终效果。

## 可以体验的变化

- 人物坐起完成重心转移后才恢复移动；起身重新寻找脚下支撑。上下车使用 1.15 秒物理时间，暂停一起冻结，入座途中再按 E 会排队退出。跳跃、座姿、跨越和复位之间清掉过期状态。
- 低栏跨越沿真实弹道运动，保留碰撞；仅合适的静止低障碍可触发，飞行及落点包络里的车辆与活动物体也会阻挡。它目前是低障碍跳越，尚无手撑栏杆的攀越动作。
- 轿跑的动力逐渐建立，刹车、反向油门、高速转角、悬挂和侧滑辅助重新调校。X 手刹、Shift 有限氮气、Space 脚刹；其他两车保持原有调校。声音和追尾镜头提供轻量反馈。
- 轿跑速度表旁显示实际氮气余量与状态，中文／英文同步切换。HUD 每 100 ms 读取物理状态，不自行模拟能量消耗。
- 传送门源模型改为同半径圆弧，保留十二段石块与底座。营地石木材质、填光、地标提示和设置面板滚动完成首轮细化。

## 仍然存在的边界

- 完整动作质量尚未通过。带转向起步、原地大角度转身和跑跳落地仍有脚滑与姿态跳变，不能用坐起或复位的成功样本覆盖。本轮完整样本的起步夹带约 45° 转身，未满足同向起步前提；原分类切段后的零值不能作通过依据，保留连续贴地同顶点窗口中的约 120.7 mm 位移。Run、转向、切换原汇总分别仍有 269.4、395.0、173.9 mm 的失败，见 [人物跟进记录](character/phase2-followup-20261025.md)。
- 上下车复用已有坐下／起身片段与舱内淡出，没有开关车门、手握把手的专用动捕。普通走跑调参实验已撤回到已验证基线，避免同时改变过多变量。
- 驾驶目前是带辅助的街机样板。长按手刹后重刹仍可能过转，声音、辅助力度和实际手柄尚需体验；没有把轿跑调校推广到另外两车。
- 美术本轮集中于圆形石门、营地石木细节与提示界面；夜间基座接触感可继续细化。局部暖机帧时间不等于全岛性能认证。
- Safari、其他设备、正式线上资源与 API、实体手柄、用户最终审美和手感均未在本轮全部验收。
