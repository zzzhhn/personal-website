# 人物动作第一轮，2026-10-25

基线 `3cb1f25`，工作分支 `codex/world-phase2-character`。本地开发记录，不代表用户视觉验收、合并或发布。

## 实现与体验路线

沿营地／西侧平路连续移动，Shift 提速后放开，反向移动，再空格跳跃；靠近实际座椅按 E，坐定后按住移动键起身；靠近车辆按 E 上下车。低矮、窄、静止栏杆前按方向键＋空格，空间足够时进入跨越跳，否则保留普通跳跃。

- 保留位移驱动步相、低速起步 8 m/s² 上限、原 StopStep 首次支撑释放、坡地胶囊支撑和地面跟随。
- 冲刺按实际速度进入并保留迟滞，减少起步时慢放冲刺片段；急停减速度上限 12 m/s²，转向动量变化上限 16 m/s²。高速朝向跟随实际速度，反向操作先减速再转身。躯干落地压缩延至 0.24 秒，峰值随实际冲击速度变化。
- 坐起保留完整 CMU 重心转移，再响应持续移动输入。视觉层通过 `onMovementLock` 向人物控制反馈短暂移动锁，避免物理胶囊先跑、身体仍坐着。
- 起身候选落脚点重新向下探测静态地面，检查坡度与水面后再检查胶囊空间，避免从长凳／高处入座后复用旧高度、落回座边并发生水平挤动。
- 上下车 1.15 秒，先走近门、屈髋进舱，反向为起身离车。复用已有 CMU SitDown／StandUp，不宣称是专门拍摄的上下车动捕；未增加车门或手部接触模型。
- 跨越跳复用 CMU RunJump；探测障碍高度 0.25～0.72 米，检查落点、顶部空间和整段真实站立胶囊的抛物线包络。实际飞行保留动力学、重力与碰撞，不瞬移、不临时关闭碰撞。允许固定体与非车辆的休眠物体，拒绝移动障碍、传感器、水面、悬崖和无落脚点。它是跨越跳，**尚不是手撑翻栏**。

2026-10-25 重新查看：[CMU 官方库](https://mocap.cs.cmu.edu/)标注可使用，[100STYLE 官方页](https://www.ianxmason.com/100style/)列出 CC BY 4.0、署名要求、60 fps 和过渡片段类型。单纯增加循环素材不能修复世界位移、支撑与交互时序，因此这一轮先保留已烘焙真人片段、改善运行时连接。专门的车门／手撑翻栏动捕和原始起步 one-shot 仍可后续定向制作。

## 共享触点

- `WorldGuideMotion.vault` 是可选的跨越跳标记；普通跳跃接口不变。
- `GuideVehicleTransition` 内部为 `phase / elapsed / door`，每个物理步开头推进 `elapsed`；传入 Guide 仍为 `phase / t / door`。暂停会停住物理时间和动作。
- 进舱期间按 E 排队一次退出；进舱完成后按原安全落点算法退出，无可用落点则保持驾驶状态。离舱期间拒绝再次上车，避免动作半途切断。
- 驾驶线负责入座期间油门／倒车／氮气门控与驻车保持，依据 `guideTransition.current?.phase === 'enter'`，不另设墙钟。
- WorldActors 改动仅在 Guide 桥接、人物速度／跳跃、进出车交互和其时序部分。车辆动力学与美术未改。
- QA 的原 `wheelFixture(on, z)` 新增可选 `span`，默认仍为 0.12 米；人物测试设为 3 米，生成 60 cm 高的宽测试栏，避免用窄轮胎测试柱代替栏杆而误判按键路径。仅 QA 生效。
