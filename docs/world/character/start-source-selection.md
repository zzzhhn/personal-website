# 真实起步片段来源核对

## 当前缺口

发布版的 Walk、Run 是从已在移动的 CMU take 提取的循环。35_01 和 09_01 的开头半秒根平面速度中位数分别约 1.206、3.628 m/s，不能重命名成静止起步。当前完整同向起步仍有 181.9 mm 滑移；Run-only 的 6.4 mm 不覆盖这个失败窗口。过渡分类修复见 `motion-transition-v2.md`，未将起步判过。

## 已执行的来源扫描

工具：`tools/world/guide/mocap/scan_starts.py`。输入为缓存的四个 100STYLE Neutral BVH，原始数据不入库；输出保存每个文件的 SHA-256 和零基帧范围。

扫描使用 BVH 的 Hips 根 X/Z，按现有 `bvh_motion.py` 的厘米单位换算成米，以前后各 0.1 s 的位移估算速度。候选要求根速低于 0.18 m/s 至少 0.3 s，随后 1.5 s 内达到 0.8 m/s。这个口径仅选择来源，不替代脚接触、重定向、A3、A6 或视觉验收。

未裁剪的四文件扫描找到 10 个根轨迹候选，不能直接用于制作。[作者说明](https://www.ianxmason.com/100style/)要求使用 `Frame_Cuts.csv` 去掉 T-pose 和前后多余动作；本轮从原始数据包补取该文件，SHA-256 为 `e3c1d2beab6486e083622cef6a5402fe9b20edc75a9963ea30675c67ec29ee82`。

Neutral 的作者区间原值：FR 357–4227、FW 327–7445、ID 655–1555、TR1 304–6775。最初提出的 FR 235–292 静止、293 起移动，以及 ID 1719 后、TR1 6915 后均在允许区间外，**已否决**。FR 293–360 的隔离离线候选仅保留为失败证据，未替换生产资产。该候选的正常相似缩放约 0.908 s；初版对照里约 0.324 s 的目标使用线性加速示意，**不是**当前控制器的实测，不能拿来验收。实际控制器使用 response=12 的指数响应，后续须按真实位移测量，不用数倍播放绕过倍率限制。

裁剪后 Neutral_FW 内部仍有 3 个较慢的起步候选。另补取同一数据集 StartStop 风格的 FR/TR1，原包内 425–7131 / 617–14986 区间中分别找到 5 / 30 个内部候选。六文件合计 38 个；这些仍只是根轨迹候选，尚未证明适合默认跑速。扫描严格要求静止与后续移动窗口在作者区间内部留一帧余量，不猜测 CSV 端点是否包含。检查日期：2026-10-24。

原始未裁剪测量保留在 `evidence/motion-followup/start-source-scan.json`；裁剪后的六文件测量为 `start-source-scan-trimmed-6.json`。绝对根目录为 `/Users/bobby/Desktop/3D-personal-world/`。

另对已有 CMU 缓存只读取 root 三列预筛，不做全量 FK：141_03 的零基 0–63 帧低速、64 帧后加速，0.6 s 后约 4.208 m/s；143_03 的 0–111 帧低速、112 帧后加速，0.6 s 后约 4.284 m/s。源帧率按已有管线的 120 Hz 约定做初筛，须在采用前核实。完整候选与源哈希位于同目录 `cmu-root-starts.json`。尚未通过 FK/正常速度预览，不能仅据根速度把它们称为已采用的起步动作。

## 下一步与门

先用 FK 和正常速度预览确认候选确为向前起步及支撑脚时序，再选一个片段重定向。新 StartRun 的接触曲线在制作前按实际源事件固定；不修改旧片段曲线、阈值或已有网格。冻结规格 §1.2 仍要求按髋高比缩放、时间 √s、运行时倍率 0.85–1.2；不能把额外 1.5 倍加速预烘焙后冒称符合。§1.3 允许有记录的作者步幅调整，仍须保持实际腿长、接触和 A6。若真实身体行程与片段无法在这些条件下匹配，应提交具体冲突，而不是改变标定速度名称。

制作后检查新片段的原生与 fresh Draco、完整原起步窗口，以及惯性化和已批准 IK 之后的最终 A6。当前没有新的 StartRun 已通过，也未改变发布版 G24。
