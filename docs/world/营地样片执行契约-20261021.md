## 统一导出契约

- GLB：米，+Y 上，+X 正面，地面接触面 y=0，根在整体水平包围盒中心；Blender Z-up，让 exporter 只转换一次。静态部件为合理连接/埋入，不把 Join 叫焊接。
- 沿用冻结的压缩要求：本批统一 Blender Draco GLB，最终回读检查必须针对压缩产物；记录量化带来的微小包围盒误差。运行时使用现有 three 包自带 decoder 的本地副本，不依赖外部 CDN。
- 独立产物：`public/assets/world/camp/<ID>.glb`。程序与原生源：`tools/world/camp/<组>/`；六视图、机器报告、manifest：`docs/world/camp-slice/<组>/`。每组独立脚本，不能依赖其他会话尚未写的 helper。保留可复现脚本与 .blend，不输出演示地板/灯/相机进 GLB。
- 组名与所有权：shelters 只 C03–C06；props 只 C07–C10；nature 只 G16–G23。不编辑其他组目录或运行时，问题在本组 README 标出，由主会话解决。
- GLB 材质名及 extras 标注 materialRole。可用 canvas/wood/stone/foliage/paper/metal/accent/paint。自然物不发光；火焰由运行时负责。无外部贴图，无透明玻璃。转 linear 后写入 Blender shader 的 baseColor；不要用逐面随机明暗假装低多。
- 三阶树冠 #6F8A3A/#8AA24A/#A9B35A，木干 #5A4634，浅木 #B99469，石材 #8C8276/#B4A896，帆布 #E8803A，奶白 #E6DCCB，石板蓝 #4E647D。自然材质 roughness 以 0.8–1 为起点，metalness 通常 0；奖杯少量哑光金属不能成为高反金。
- 先声明逐件尺寸/预算；面数按四个 skills 的适用方法，不继承果实/狐狸项目的预算或已通过结论。不靠全局细分加面；报告 modifier 后与 GLB 回读的实际 triangles、bounds、材料库存、相对初版倍率。尽量按材质合并静态 mesh，合理组件不强行焊死。
