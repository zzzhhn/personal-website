# Alpha 水车底部接地修复

范围为四个水槽立柱石础及四根石拱第一排。`waterwheel-art.ts` 新增共用 `waterwheelFoundationContacts()`，每处按实际截面采中心、四角、四边中点共 9 点，调用当前 `alphaGroundHeight` 的默认共享物理三角形缓存。不修改 `alpha-terrain`、站点、木柱、水车、上部石块或材质。

只有低于原石础底面的地形才触发下延。新的最低面取采样最低地面，再埋入原圆角半径及 1 cm 余量，防止底部圆角露空。四个水槽石础顶保持 world y=24.56，四个拱底顶保持 24.65。原造型、截面和圆角保留，无新增可见部件或 render topology。

原固定 rotor／arch 包络的底都是 local y=0，未覆盖新增下段。`AlphaWaterwheel.tsx` 在原固定 solid body 内，对实际下延的 7 处增加同截面 Cuboid，只从新底延伸到旧包络底 y=0；现有所有上部 collider 不变。未改变动态水流、旋转、谜题状态、装置交互或通道地板。
