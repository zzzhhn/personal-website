# Club round daybed

Geometry and authored textile/limestone maps created for Bobby’s island.
Wood color and OpenGL normal derive from Poly Haven `wood_table_001`, CC0: https://polyhaven.com/a/wood_table_001.
Runtime uses 2K derivatives with fabrication-aligned UVs; native editable source, frozen baseline, scripts and selected renders are in docs/world/phase-2-playground/djc-daybed-craft-20261101/.
No runtime transmission or extra lights.

The AO runtime derivative preserves the original geometry and PBR image bytes, with one authored geometry-occlusion atlas on UV1. Reproduction, UV allocation and round-trip checks: docs/world/phase-2-playground/djc-render-parity-20261101/asset-ao/ and tools/world/djc-render-parity/.
