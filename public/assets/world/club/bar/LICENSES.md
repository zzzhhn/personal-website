# DJC north bar runtime asset

Created for Bobby's island from the approved 2026-11-01 Blender pilot. The near model retains the approved geometry and PBR definitions; the distant model is a derivative of the same editable source.

Wood base color and OpenGL normal maps derive from Poly Haven `wood_table_001`, distributed under CC0:

- https://polyhaven.com/a/wood_table_001
- https://polyhaven.com/license

Stone color/roughness/normal, teak roughness and palm color/normal maps were authored for this asset. Filenames contain a content hash so both LODs share the same image bytes. The approved native source, derivation script and verification report remain separate from the web-served asset directory.
